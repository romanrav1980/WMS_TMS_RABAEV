# 05 — SSCC, этикетка и физический принтер

Источники: labels.py, domain/sscc_label.py, receiving.html/js. Не устанавливай выдуманный production GS1 prefix; для цифрового dev-кейса допускается явно синтетическая fixture, не выпуск в оборот.

| Case | Действия | Ожидаемый результат |
|---|---|---|
| 01 | Issue без prefix, по закрытому/несуществующему заказу | Отказ, не выдуман SSCC |
| 02 | Issue с настроенной fixture: HTML и ZPL 203/300/600 | SSCC 18 digits/checkdigit, AI00/FNC1 GS1-128, товар/quantity/UoM/batch/expiry читаемы |
| 03 | Повтор issue operation_id и другой payload | Одна этикетка/SSCC; конфликт другого payload |
| 04 | Скан incorrect/correct printed SSCC, включая (00)/00/]C1 | Неверный не подтверждает; правильный CONFIRMED с actor/time |
| 05 | Приём с issued-but-unconfirmed и затем confirmed label | Первая запрещена; вторая USED, payload соответствует факту |
| 06 | Этикетка другого заказа/строки/qty/batch/expiry | Отказ без stock; этикетка поставщика отдельно допустима |
| 07 | API/html/zpl без права; текст со спецсимволами | Нет неавторизованной выдачи, HTML escaped, ZPL данные не становятся командами |
| 08 | Физическая печать и скан реальным устройством при доступности | Реально декодирован AI00/SSCC, размеры/читаемость, отдельный attached-label scan |

Цифровую декодировку SVG можно исполнить отдельным локальным декодером, но не выдавать за case 08. Если принтер/сканер отсутствует — BLOCKED с указанием модели/доступа, который нужен. Не считать Print dialog или скачивание ZPL подтверждённой физической печатью. Сохранить bytes/hash этикетки и скан без секретов.
