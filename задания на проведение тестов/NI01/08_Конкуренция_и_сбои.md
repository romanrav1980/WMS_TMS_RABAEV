# 08 — ограниченные конкурентные сценарии

Это адресные тесты атомарности, не нагрузочный прогон. Две операции/worker, максимум несколько повторов. Оба соединения используют одну собственную fixture; сохраняй timeline и результаты, не вмешивайся в чужие сессии.

1. Две приёмки последнего количества одной строки: суммарный факт не превышает SAP план; проигравший получает отказ.
2. Один operation_id одновременно с одинаковым payload: один fact/stock/task/outbox, второй получает сохранённый результат. С разным payload — conflict.
3. Один canonical CIS в двух поставках; один SSCC на две паллеты: только одна приёмка успешна, нет сирот состава.
4. Две паллеты на последний свободный slot: только один RESERVED. Проверить одновременно общий LIMIT_WEIGHT нескольких слотов.
5. Complete одновременно с complete/cancel/replan: единственный допустимый переход, нет второго event перемещения; source/target сумма сохранена.
6. SAP amendment одновременно с receipt/close: согласованный план≥факт, нет deadlock без обработки/частичного commit. Не считать таймаут успешным отказом без сверки DB.
7. Два gateway worker на своём root, crash только своего процесса после claim; затем restart. Повторный вход не создаёт второй effect.
8. Потеря ответа после commit: повтор stable operation_id возвращает исходный результат.
9. Filesystem недоступен только для своего outbox root: бизнес fact остаётся, экспорт не помечен ложным ACKNOWLEDGED; восстановление позволяет доставить тот же event.
10. Ошибка на середине DB-транзакции через доступный controlled harness: полный rollback. Если точка внедрения недоступна без правки продукта — BLOCKED с требуемым failpoint.

Для crash/rollback сценария заранее фиксируй точку вмешательства и не называй простой остановленный process доказательством конкретной точки commit. Не kill Oracle/API целиком, не отключай DB, не делай нагрузку. После каждого значимого сценария — slow SQL решение из общего README, conservation quantities и полное отсутствие двойных фактов. Итог должен отделять реально наблюдавшиеся гонки от чтения кода.
