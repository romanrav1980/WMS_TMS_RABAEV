# 02 — паллетная приёмка и атомарность

Источники: inventory/infrastructure/receiving.py, receiving_marks.py, установленный RRL_SAP_RECEIPT_API и enabled event trigger. Не вызывать mutating PL/SQL через SELECT.

| Case | Действия | Ожидаемый результат |
|---|---|---|
| 01 | Не маркированный SKU, заказ 100, норма 40; принять 30/50/20 | Предложение по норме редактируется; факт суммарно 100, три паллеты, три PUTAWAY; закрытие только после полного факта |
| 02 | Приёмка по ШК штуки и отдельно коробки | Совпадение SKU обязательно; QR марки не подменяется product barcode |
| 03 | Неверный ШК, нет policy, неверный SSCC/checkdigit, просроченный срок/будущая дата производства | Отказ без stock/fact/marks/task/outbox |
| 04 | Попытка принять 101 по плану 100; приём без SAP основания/по закрытому приходу | Отказ без дополнительных остатков |
| 05 | Частично принять Decimal количество с шестью знаками | Нет округления float, исходная партия/срок/quantity/base UoM сохранены |
| 06 | Повтор operation_id того же и другого payload | Тот же durable результат без дубля; иной payload conflict |
| 07 | Повтор SSCC в другой поставке и внутренний legacy UID обычной паллеты | Дубликат SAP-паллеты отклонён; старые внутренние идентификаторы не стали SSCC-only |
| 08 | Ошибка после сохранения состава, до факта/задачи через контролируемый failpoint собственного harness | Вся транзакция откатывается, нет сирот/двойного stock; не редактировать runtime код продукта |
| 09 | Legacy автоматическая перепаллетизация SAP-прихода | Guard запрещает замену/удаление/изменение количества SAP-паллет; обычная legacy fixture не заблокирована |

Снимай RRL_PALLETS/RRL_REMAINS/RRL_EVENTS/RRL_SAP_PALLET_RECEIPT/RRL_WAREHOUSE_TASK/RRL_SAP_RECEIPT_OUTBOX только по своим PK. Проверь stock появился ровно один раз от event trigger. Supplier batch не должен становиться выдуманным PROD_BATCH_ID. После исторического успешного приёма повтор не должен ломаться из-за последующего истечения срока. Если failpoint без вмешательства в код недоступен, case BLOCKED, а не PASS по чтению.
