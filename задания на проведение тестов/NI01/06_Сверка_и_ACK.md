# 06 — изменения заказа, недостача и подтверждения SAP

Источники: supply_orders.py/supply_amendments.py, reconciliation.py, receipt_outbox.py/receipt_acknowledgements.py, ACK пример. Работай с собственной поставкой и отдельными export/ACK каталогами.

| Case | Действия | Ожидаемый результат |
|---|---|---|
| 01 | Revision 2 после первой паллеты: увеличить план/добавить строку | Факты/ROW_ID принятых строк сохранены, допустимый план изменён |
| 02 | Уменьшить ниже принятого, сменить товар/UoM, удалить принятую строку | Отказ целиком, прежний план не повреждён |
| 03 | Исправить/удалить ещё непринятую строку, повтор старой Revision | Разрешённое изменение; старое сообщение не откатывает план |
| 04 | Close с недостачей/причиной/operation_id, повтор и conflict | План/факт/shortage сохранены, stock не меняется, durable outbox один |
| 05 | Reopen, попытка приёма до новой Revision, затем новая Revision | История сохранена, до SAP ревизии приход закрыт; после допустимой ревизии возобновлён |
| 06 | Два close/reopen цикла и повтор исторической команды | Не затирают историю/не закрывают новый цикл по старому retry |
| 07 | Экспорт события, повтор после сбоя между replace и commit | Стабильные EventId/filename/bytes, не дублируется товарная операция |
| 08 | ACK ACCEPTED с правильными Sender/EventId/hash/ExternalDocumentId | ACKNOWLEDGED + внешний номер/время + raw ACK атомарны |
| 09 | Wrong sender/hash, nonexistent/not-exported event, ACCEPTED без document | Отказ, export не выдаётся за SAP принятие |
| 10 | REJECTED/error → retry → экспорт → ACCEPTED | Видимая диагностика, разрешённая повторная доставка; ACKNOWLEDGED нельзя ухудшить |
| 11 | Повтор ACK MessageId с тем же/иным bytes, новое подтверждение конфликтующего document | Durable повтор либо conflict; подтверждённый внешний номер не перезаписан |

Все ACK в тесте — симуляция шлюза, не реальные документы SAP. Полный end-to-end реальной SAP остаётся BLOCKED до реального согласованного доступа. Доказательства отделять: бизнес commit, публикация файла, ответ шлюза, настоящий SAP posting.
