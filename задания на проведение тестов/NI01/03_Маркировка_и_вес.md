# 03 — уникальные марки, несколько профилей, агрегации

Источники: master_data policy, inventory/domain/mark_identity.py и unit_quantity.py, receiving_marks.py, composition API, RRL_PRODUCTION_API/RRL_REGULATORY_API. Используй синтетические коды только в dev; их принятие не доказывает государственную валидность.

| Case | Действия | Ожидаемый результат |
|---|---|---|
| 01 | Настроить CRPT TOBACCO UNIT; принять два разных compact GTIN14+serial7 | Две физические единицы, совпадающий GTIN, raw сохранён, legacy codes/паллета/агрегация связаны |
| 02 | Одна марка с AIM, HRI AI01/21 и обычным GS1 представлением | Общая canonical identity; повтор одной марки на другом pallet отклонён |
| 03 | Несовпадающий GTIN, неверный digit, неоднозначный serial/crypto tail | Отказ, исходный код не обрезан молча |
| 04 | Одна physical unit с CRPT и EGAIS/другим профилем | Количество учитывается один раз; все версии/raw доступны composition |
| 05 | Пропустить профиль, повторить unit/profile, одну canonical марку дать разным unit_id | Отказ атомарно |
| 06 | EGAIS полный код 68/150; неверная длина/управляющие символы | Валидный технический профиль сохраняется; неверный отклонён; внешнее одобрение отсутствует |
| 07 | BOX/PALLET profile, импорт известного состава, скан агрегата | Только разрешённый scan_mode, все leaf codes/единицы сохранены |
| 08 | Неизвестный состав, неверный уровень, повтор агрегата на другой паллете, partial leaf coverage | Отказ; количество не заменяет уникальные коды |
| 09 | Два профиля одного агрегата и base64 Code с GS | Полный состав профилей/raw в immutable receipt, без двойного количества |
| 10 | KG: физические единицы 0.725+1.275, pallet 2; либо однозначная PCE→KG норма | BASE_QTY сумма 2; UNIT identities две; все профили не удваивают вес |
| 11 | KG без quantity/без нормы, неоднозначная норма, PCE quantity=2, NaN/отрицательное/>6 decimals | Отказ без записи части состава |
| 12 | Composition pagination limit=1/50, несколько профилей одной единицы | Единица не разрезается между страницами, курсор не теряет/дублирует её |

В журнале ожидается физический CAPTURED/NOT_PERFORMED внешний validation, а не успешная государственная проверка. Проверь чужой/preloaded CRPT CIS нельзя присвоить новой паллете. Полный QR и crypto хвост остаются в raw. Эксперимент с реальным CRPT/ЕГАИС без договора/сертификата не выполнять; соответствующее испытание BLOCKED.
