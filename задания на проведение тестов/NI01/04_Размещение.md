# 04 — размещение и управление заданиями

Источники: inventory/infrastructure/placement.py, receiving.py/configuration.py, legacy warehouse_task мост. Собственные ячейки/топология/настройки; сохраняй их исходные значения.

| Case | Действия | Ожидаемый результат |
|---|---|---|
| 01 | DISTANCE: два пригодных адреса на разном расстоянии до отбора | Выбран ближайший; правильный warehouse/pick OTBOR=1, coords не 10000 |
| 02 | TIME: ближний медленный, дальний быстрый; измеренное TRAVEL_SEC | Выбран минимальный score времени, BASIS сохранён |
| 03 | TIME без travel row, заданные scale/speed/lift | Явно NORMATIVE, корректная единица/счёт; не объявлен измеренным |
| 04 | Заблокированная/системная/отборная/чужого склада/занятая ячейка | Исключена из назначения |
| 05 | SKU temp/shelf rule и несовместимая ячейка/короткий срок | Отказ либо другой пригодный адрес, temp диапазон ячейки внутри допустимого SKU |
| 06 | Weight/height/volume ограничение и неизвестные измерения | Неизвестное не проходит ограничение; legacy height и метры слота не смешаны |
| 07 | Опубликованные два STORAGE_SLOT, один занят/зарезервирован | Назначен свободный; два задания не претендуют на один слот |
| 08 | Несколько паллет в ячейке: общая масса вместе с RESERVED превышает LIMIT_WEIGHT | Новая паллета не назначена, чужой occupied slot не запрещает свободный при достаточной ёмкости |
| 09 | Complete с pallet/from/to scans и точным source qty | Type=2, source уменьшается/target растёт на ровно qty, DONE и outbox атомарны |
| 10 | Неверный scan/изменённый stock/блокировка адреса после назначения | Отказ без частичного движения; повтор DONE безопасен |
| 11 | Replan PLANNED/ASSIGNED/CANCELLED с причиной; повтор operation_id | Тот же task, новый пригодный адрес/резерв; повтор не переназначает ещё раз |
| 12 | Cancel и новый replan; попытка replan IN_PROGRESS/DONE | Cancel освобождает RESERVED без движения stock; active/done отклонены |

Проверь стандартные list/assign/start/complete/cancel endpoints и экраны ричтрака на PUTAWAY/SAP_RECEIPT. Серверный actor нельзя подменить updated_by клиента. Ограничь строки SQL своим складом; сортировку placement и correlated capacity запросы отрази в slow_sql.md.
