# C-0034 — ночные операции на существующей диаграмме Ганта (NI08.1)

Исполнитель: Claude Code · 14.10.2026. Проверка авторская. Native, API и данные не менялись; реальных POST/PATCH нет (в тесте 0 изменяющих запросов).

## Было
- Шкала 06:00–22:00 и время по `HH:mm`: рейс 33564 (операции 00:00–01:52) на диаграмме отсутствовал. В C-0032 и C-0033 карточку приходилось открывать на подставленном ответе.
- Интервал через полночь терял дату.
- Линия «сейчас» рисовалась на любой дате.
- `todayIso`/`addDays` брали дату UTC. Около полуночи по Москве «Сегодня» давало вчерашний день, а «◄/►» в UTC+3 перескакивали неверно.
- На mobile страница была 1440 px из-за общего `body{min-width:1440px}`.

## Сделано
- **Новый `TransportGanttTime.ts`** (чистые функции):
  - минуты считаются от 00:00 выбранной даты по полной метке `YYYY-MM-DD HH:MM`; без даты — `null`, это неполные данные;
  - обрезка по границам суток с признаками «до» и «после»;
  - подписи `HH:MM` или `ДД.ММ HH:MM`;
  - операции вне шкалы, цель начальной прокрутки, ближайшие операции по абсолютному времени, локальная дата.
- **Новый `TransportGanttAxis.tsx` + `TransportGantt.css`:**
  - шкала 00:00–24:00 шириной 2160 px;
  - полосы с треугольниками продолжения ◂ ▸ и `aria-label` с полным временем;
  - начальная прокрутка один раз на дату: сегодня — к текущему времени, другая дата — к первой операции суток, пустая — к 06:00; учитывается, к какой дате относятся данные;
  - список «Неполные данные / вне выбранных суток», каждая строка открывает существующую карточку рейса;
  - подпись: «Сутки выбранной даты 00:00–24:00; время как в API, без пересчёта часового пояса. Показаны рейсы даты и пересекающие сутки операции»; ◂ ▸ — продолжение за полночь (см. дополнение C-0045).
- **`TransportGanttPage.tsx`:**
  - шкала и вычисления вынесены в эти два файла;
  - подписи плана и факта в карточке, подсказке, списке ближайших операций и аналитике — с датой, если она не совпадает с выбранной;
  - статус машины считается по абсолютному времени;
  - линия «сейчас» — только на сегодняшней дате;
  - локальная дата для «Сегодня» и «◄/►».
- **Размер `TransportGanttPage`:** файл 853 → 723 строки, функция 534 → 523. Baseline ужат штатным `--tighten-baseline` только по этим двум записям.
- **Mobile:** на странице диаграммы снят общий `min-width` у body (`body:has(.gantt-page)`), шкала прокручивается внутри области диаграммы, левая колонка 120 px.
- **Карточка рейса (C-0041):**
  - своя прокрутка (`max-height: 100%`) и ширина до 960 px;
  - preflight занимает всю ширину, «Закрыть» переносится на следующую строку;
  - содержимое больше не выходит на подложку — серой полосы над текстом нет.

  Правила лежат в локальном `TransportGantt.css`; классы `gantt-card*` используются только на диаграмме.
- **C-0037:** вызов `TransportDeliveryWindows` убран из `TransportRouteInput`. Расчёт показывает только `TransportRouteSchedule` в preflight; других вызовов нет, сам компонент не удалён.
- Существующие маршрутизация, фильтр, факт, контекстное меню и preflight переиспользованы; второй диаграммы нет.

2. **Полуоткрытые сутки** `[00:00, 24:00)` в `clipToDay`: начало в 24:00 и позже — следующие сутки; точка 00:00 — текущие. Адресная проверка `c0034_clip_boundary.json`:
   - точка 24:00 → вне суток; начало 24:00 → вне суток;
   - точка 00:00 → в сутках;
   - интервал вчера 23:00 – 00:00 → вне суток;
   - 23:00 – 24:00 → до конца суток без продолжения;
   - через полночь → обрезка с признаком продолжения.
3. **Подпись шкалы:** «Сутки выбранной даты 00:00–24:00; время как в API, без пересчёта часового пояса. Показаны рейсы даты и пересекающие сутки операции». Прежнее описание backend (выборка только по `SHIPMENT_DATE`) устарело: root C-0043/C-0044 включил пересечения суток.
