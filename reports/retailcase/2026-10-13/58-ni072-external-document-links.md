# 58. NI07.2 — конкретные сообщения ERP и маркировки

14.10.2026. Finance read-only, RABAEV/orcl. Продолжение report56.

Сверка теперь возвращает до20 ID за тремя производными показателями: внешнее подтверждение ERP, сообщения маркировки, неподтверждённая исходная stock-операция сообщения. Используются точно те же ERP_SOURCE/REGULATORY_SOURCE, что в счётчиках; это вынесенные условия прежних запросов, не новая классификация. Пакет выполняется только для ненулевых показателей, одним roundtrip, без повторного COUNT. Общие количества взяты в том же read-only snapshot.

Для EVENT_OUTBOX есть ссылка external-outbox.html?event_id=; существующий журнал читает ровно событие и связанные adapter requests. При прямом открытии вся очередь не загружается. ERP EVENT_ID пока показывается текстом: отдельное досье SAP на этом raw-экране не выдумывается. Статус DONE/EXPORTED не выдаётся за принятие госсистемой.
