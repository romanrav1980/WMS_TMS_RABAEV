# C0023 / NI05.3 — акт приёмки и исправление после отказа

14 октября2026. Передано от Claude (K0024, лимит сессии) ведомому Codex. Подтверждены обе находки Claude и реализован существующий операторский путь без нового движка приёмки.

После успешного /confirm получатель видит акт с точными серверными количествами: отправлено/принято/недостача/отказ/повреждено/излишек, номер операции/разбирательства и следующие действия. Акт берётся из existing accepted_lines/discrepancy_case_id, а не пересчитывается из введённой формы. Неизвестные legacy-поля показываются «Не передано», не придуманным нулём. Досье открывается по RAW_ADMIN_BASE ведущего; требуется отдельный вход диспетчера. Право transport_dispatch_view магазину не добавляется. Возврат/списание/государственный ACK переходом не выполняются.

После достоверного отказа «Исправить данные» перечитывает server preview и при прежнем составе сохраняет смонтированную форму: количества, причину, фото, вес, QR. При изменившихся составе/режиме/marked_unit_control старый ввод остаётся для сверки, проведение блокируется; пользователь явно открывает новую форму. Неизвестный ответ по-прежнему повторяется исходным operation_id/body. Новое сохранение проверяется readback; успешный ответ проверяется по operation_id/load_operation_id/store_address/status/составу акта до удаления pending. Смена actor/рейса/адреса очищает подтверждённый акт и видимый контекст.
