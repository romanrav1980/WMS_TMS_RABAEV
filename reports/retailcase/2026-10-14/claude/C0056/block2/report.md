## Что сделано

`admin/wms_admin_frontend/src/features/platform/access-admin/` (перенесено по C-0061):

- **AccessAdminPage** — вкладки «Назначения / Группы объектов / Роли / Объяснение доступа», переход стрелками.
  - В шапке: пользователь, legacy-группа, действующие назначения, `access_revision`, время чтения.
  - Ошибки чтения показываются текстом и не превращаются в пустые данные.
- **RolesPanel** — список ролей, форма роли с фильтром прав, ROLE_SAVE с `expected_version`.
  - Для не-GLOBAL_ADMIN кнопка объясняет: «в этой редакции роли меняет только глобальный администратор» (C-0057). Решение остаётся за сервером.
- **GroupsPanel** — поиск групп, состав, поиск объектов (`/api/access/objects`), GROUP_SAVE.
  - Перед сохранением обязателен серверный предпросмотр `POST /api/access/groups/preview` для текущего черновика: добавлено/убрано, затронутые назначения, `affected_total`, смена активности, пояснение про снимок. Если состав изменился после расчёта, сохранение блокируется.
- **AssignmentsPanel** — назначения пользователя, ASSIGN и REVOKE с причиной.
  - Области: объект через поиск, GROUP, ORG_BRANCH (`ВИД:КОД`), SELF/NETWORK/PLATFORM. Состав: актуальный или снимок версии.
  - Срок `[с, до)` отправляется с явным часовым поясом браузера.
- **ExplainPanel** — `POST /api/access/explain`: разрешено/запрещено и источник.
- **Команды** (`metadataCommand.ts`, `useMetadataCommands.ts`, `PendingCommandBanner.tsx`):
  - команда сохраняется в браузере до отправки, запись проверяется чтением;
  - потеря ответа → «Незавершённая команда», новые изменения заблокированы;
  - «Проверить квитанцию» → `GET /api/access/commands/{operation_id}`; «Повторить ту же команду» — тот же `operation_id` и то же тело;
  - подтверждённый отказ (`outcome_confirmed:true`) — текст по коду сервера (VERSION_CONFLICT, OPERATION_CONFLICT, DELEGATION_OUTSIDE_MANDATE и др.);
  - повреждённая запись — архив после подтверждения.

  Этот механизм переиспользует редактор знаний.
- **Помощь** (`features/platform/help`, передана C-0056):
  - `HelpButton` с `unavailable`: кнопка остаётся фокусируемой и объясняет причину, штриховка по правилу UI;
  - `HelpHint` «?»: краткая помощь, «Подробнее» → статья, Escape с возвратом фокуса, на mobile — поверх экрана с «Закрыть»;
  - событие `openHelpArticle` открывает KnowledgePanel на нужной статье, не сбрасывая экран.

  `help_id` есть у всех кнопок и полей страницы.
- **Пользовательская статья** `docs/help/authoring/access-admin.md`. Пока не опубликована: «Подробнее» показывает «Статья недоступна или не опубликована». Опубликую через редактор знаний в блоке 3.

## Расхождение с контрактом (для Codex)

`GET /api/access/assignments` возвращает время без часового пояса:
- `valid_from`/`valid_until`, например `2026-10-15T00:14:00`;
- `revoked_at` = `2026-10-14T17:14:16`, хотя фактически отзыв был в 00:14 MSK — время сервера в другом поясе.

Контракт требует ISO8601 с поясом. UI не пересчитывает догадкой и показывает такие значения «как есть (без пояса)».

## Ограничения

- Страница не подключена к App/меню до применения патча.
