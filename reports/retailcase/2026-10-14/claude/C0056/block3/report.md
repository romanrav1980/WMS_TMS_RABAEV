# C0056 · блок 3 — KnowledgeEditorPage и встроенная помощь

Исполнитель: Claude Code · 15.10.2026. Реальный `/api/knowledge/*` и `/api/knowledge/wiki-sources/*` (C-0058, C-0063). Моков в продукте нет. Маршрут в оболочку — патч `proposals/C0056/integration/02_knowledge_editor_entry.patch` в `PlatformEntry` (флаг навигации `knowledge_editor`).

## Сделано

`features/platform/knowledge-editor/`:
- **KnowledgeEditorPage** — список статей с поиском и фильтрами по пространству и статусу; режимы «Статьи» и «Из wiki».
- **ArticleEditor**:
  - поля статьи (article_id, пространство, заголовок, описание, текст, связанные, источники, права чтения, причина);
  - проверки до отправки: формат article_id, обязательные поля, 20000 символов, запрет HTML, не больше 30 связей;
  - ARTICLE_SAVE создаёт черновик; PUBLISH и ARCHIVE — с причиной;
  - «Опубликовать» недоступно, пока форма отличается от сохранённого черновика;
  - вкладки «Как увидит читатель» (абзацы, связанные статьи с пометкой «не найдена», источники и доступ) и «История».
- **Локальный черновик** (`localDraft.ts`) сохраняется в браузере через 0,5 с после правки. После перезагрузки предлагается «Восстановить» или «Удалить копию». Сохранением на сервере это не считается.
- **WikiImportPanel** — разрешённые источники → предпросмотр (редакция sha256, статья-получатель, её текущий статус) → «Создать черновик из wiki» через `POST /import` с `operation_id`, `source_revision`, `expected_version`. Публикация — отдельным действием.
- **Общий механизм команд** (`access-admin/metadataCommand.ts`):
  - команды с отдельным endpoint (импорт): квитанция — повтор того же тела;
  - межвкладочный `navigator.locks` на «журнал + отправка»; без поддержки отправка запрещена с объяснением (C-0068);
  - событие `storage` обновляет баннер незавершённой команды.
- **Права и назначения (C-0067):** строка назначения показывает серверное `assignment_state` (действует / начнёт / истёк / отозвано); клиент права не вычисляет.

Пользовательские статьи созданы и опубликованы через этот редактор:
- `access-admin` — v1 черновик → v2 опубликована;
- `knowledge-editor` — v1 → v2.

Исходники — `docs/help/authoring/{access-admin,knowledge-editor}.md`. «Подробнее» с экранов теперь открывает опубликованную статью.

## Ограничения

- Черновик `ui-help-rules` из wiki оставлен неопубликованным — решение о публикации за владельцем знаний.
- Списки ограничены 100 строками API.
- Права чтения меняет publisher; редактору сервер откажет, экран предупреждает заранее.
