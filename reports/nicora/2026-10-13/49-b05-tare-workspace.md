# NI06.3 — выдача и двухсторонний возврат тары
2026-10-14, dev RABAEV/orcl. Доработан существующий TarePanel, прежний Tare/useTare API и Oracle-журнал сохранены.

## Реализация
История до100 передач рейса показывает направление, тип, пригодность, отправителя, принятую/непринятую часть, подпись получателя, акт повреждения и отмену. Быстрые направления: склад→машина, машина→магазин, магазин→машина, машина→склад. Они не подставляют физические сканы.
Отдельный текущий баланс склада-владельца использует существующий scoped endpoint, до200строк; количество на учёте не выдаётся за свободное с учётом резервов.
Подпись приёмки показывается только текущему получателю и другому пользователю. Сервер остаётся окончательным владельцем проверки.
После подтверждения обновляются прежние список/context. Ошибка последующего чтения не предлагает повторно создавать подтверждённую передачу.
Сохранённая команда удаляется только после совпадения operation_id, допустимого статуса и goods_stock_changed=false; для приёмки проверяются исходное предложение, количество, результат и эффект баланса. Неизвестный ответ сохраняет retry. Добавлены доступные названия select и пояснение отсутствующего срока возврата.
