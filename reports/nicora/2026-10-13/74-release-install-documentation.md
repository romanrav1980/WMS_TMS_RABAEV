# 74. Комплект публикации NICORA — 14.10.2026

## Состав

- Все текущие изменения Oracle/API/UI и документации после предыдущего общего коммита.
- Полный SQL-снимок действующей схемы: 2818 объектов USER_OBJECTS; [manifest](../../../db/releases/2026-10-14/manifest.json).
- Установщик пустой RABAEV с минимальным наполнением; [инструкция](../../../db/releases/2026-10-14/README.md).
- [Описание системы и блоков](../../../wiki/subprojects/nicora_system_reference.md), технический каталог 1149 объектов, 3118 Python-методов и фактический OpenAPI.
- Поручение Claude C0049 по ролям розничной сети и ролевому UX. Его незавершённые рабочие предложения не являются готовой функцией этого релиза.

## Выполненные проверки

Контрольные суммы SQL, разбор границ операторов, сверка обязательных объектов с исходной Oracle, INVALID=0, старый механизм проводки выключен. Схема не изменялась. Проверка UTF-8 пройдена. В публикуемых изменениях не найдено стандартных шаблонов закрытых ключей и API-токенов; локальные SAP-проекты и файлы окружения исключены. Это адресная проверка публикации, не заявление полного security-аудита.

Проверки функционального кода завершённых18 спринтов сохранены в отчёте73. Повторный полный функциональный прогон ради упаковки не выполнялся. Создание новой пустой Oracle и полная установка на неё также не выполнялись; инструкция содержит это ограничение.

## Стартовые данные

58 строк технических каталогов типов, выключенная совместимость старой проводки, GLOBAL_ADMIN, admin с вводимым паролем, исходный склад1, собственный пустой baseline и ключи общей политики блокировок. Товары/адреса конкретного РЦ, заказы, остатки и движения не создаются из тестовых данных. Для работы склада нужен ввод его справочников и настройка обмена SAP.

## SQL

Снимок читает системные словари и пять небольших каталогов. Изменений схемы/индексов не требуется. Действующие индексы с именами BIN$ включены; отбор только по имени был бы ошибочным. Контроль состава/last_ddl_time до и после экспорта исключил незамеченное изменение DDL внутри снимка.

## Публикация

Пользователь прямо разрешил полный commit/push этого комплекта. Целевая ветка — feature/transport-dispatch-phase1 репозитория romanrav1980/WMS_TMS_RABAEV. Фактический SHA и результат push сообщаются по завершении операции. Чужие изменения не удалялись; закрытые локальные SAP/SAP_INTEGRATION не включались.
