# C-0175 — единицы строки заказа при загрузке (первый этап: TRADECASE ORDER, обработанная EA/BOX)

## Что было
- `TradeOrderLine` принимал только EA/BOX, `TradeSku` — base EA.
- Native-приём, привязка, отбор, TRIP и вместимость построены на EA/BOX.
- NI02 (SAP store orders) переводит в базу точно, но запрещённое округление отклоняет всё сообщение.
- Настройки «единственная единица обработки», «шаг» и «разрешено округление» не было.

## Сделано (контракт согласован Codex, K-0177)
- Контракт `contracts_tradecase.py`:
  - `TradeSku` + `processing_uom` (EA|BOX), `processing_step` (явный шаг), `round_to_processing_unit`. Все необязательны и при отсутствии исключаются из хеша, поэтому старые сообщения повторяются без изменений.
  - `TradeOrderLine.uom` = EA, BOX, BLOCK, BLK, G, KG.
- Чистый нормализатор `domain/order_units.py`:
  - коэффициенты реестра, точные дроби, всегда вниз до шага;
  - флаг влияет только на ошибку: выключен и единица другая — ошибка интеграции даже при точном переводе;
  - статусы UNCHANGED / EXACT / CONVERTED / ROUNDED_DOWN / ZERO / COEFFICIENT_MISSING / PROCESSING_UNIT_REQUIRED / PROCESSING_STEP_REQUIRED / SKU_SETTINGS_MISSING;
  - BLOCK и BLK явно сопоставлены коду реестра BLK, исходный код сохраняется.
- Реестр `infrastructure/order_unit_registry.py`: последняя POLICY_VERSION; несколько строк одной версии — нет коэффициента, а не догадка.
- Приём `tradecase_documents.py`, в одной транзакции с native:
  1. сначала проверяется сохранённое сообщение (WARE_ID, SOURCE_ID, EVENT_ID): точный повтор уходит в native с сохранённым запросом без повторной нормализации, права проверяет native;
  2. иначе каждая строка ORDER (кроме BUYOUT, его основа остаётся в штуках) нормализуется по текущему SKU и реестру;
  3. в документе хранится обработанная строка + `normalization`;
  4. ответ ACCEPTED + `line_results` и `loaded_with_integration_error` — из сохранённого тела, поэтому повтор отвечает одинаково.
- Ниже по цепочке работают на обработанной EA/BOX: второго пересчёта нет. Существующая привязка native прошла 2/4/3 BOX.
- Native NOT_APPLIED `db/migrations/2026-10-27_trade_order_units/` (README там же):
  - до: `RRL_TRADE_DOCUMENT_API` 3EBF80AB…A924, `RRL_TRADE_ORDER_API` 2A2924D2…2381;
  - после: DBFE94BF…596A и AC41B2AA…5689;
  - неисполнимые строки (0 / без коэффициента) хранятся с количеством 0, TRIP отказывает `ORDER_LINE_NOT_EXECUTABLE`, привязка их пропускает, документ без исполнимых строк не привязывается;
  - откат защищён от дрейфа и истории.
