# Предложение текста справки (вставить в `public/help/tradecase-documents.html#topup.decide` только после apply и приёмки root)

<p>Товар, который отгружается из общего пула (выдача со склада), добивается так же: заказ SAP на добивку собирается из удержанных при подтверждении коробов, общий пул эти короба второй раз не обещает. Если по строке такого заказа в пуле ещё осталось распределённое количество, запуск волны отклоняется — сначала пересчитайте распределение общего пула. Отменённое предложение не переводит свой заказ на общий пул.</p>
