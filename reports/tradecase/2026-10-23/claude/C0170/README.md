# C-0170 — недостача при сборке TRADECASE (T11/T04)

## Найденный разрыв
Общий процесс недостачи уже есть: отчёт сборщика (Python, без движения запаса) → `CASE_SHORT_APPROVE` (ACCEPT_SHORT / RESTORE / WEIGHT_TOLERANCE / READY)
→ RESTORE: задание инвентаризации → пересчёт → пополнение → READY → сборка. На складе TRADECASE решение отклоняется стражем
`RRL_TRADE_STOCK_GUARD.assert_command_stock` с кодом `TRADE_ORDER_BINDING_REQUIRED`, потому что этой команды нет в его списке.
Подтверждено вживую в режиме READ ONLY (`guard-probe.json`, все три решения отклонены; INVENTORY_COUNT и WAVE_RESERVE_SOURCES разрешены).

## Изменение
- Новый неизменяемый комплект `db/migrations/2026-10-23_trade_short_guard_v2/` (NOT_APPLIED, см. README в комплекте). Первый комплект v1 опубликован root и оставлен без изменений с пометкой «НЕ ПРИМЕНЯТЬ».
- Привязка к плану операции: UID берётся только из списков reservations, carrier (лот тары того же CASE) и chunks в RESOLVED_PLAN_JSON. Произвольная строка RRL_REMAINS не используется.
- Права текущего владельца: менять RRL_CASE_TASK_ACCESS не нужно. Резерв на это тело не использовался. `owner-probe.json`: задача 1161, актёр STM3 получает TRADE_OWNER_ACCESS_DENIED и в RRL_TRADE_CASE_ACCESS, и в RRL_CASE_TASK_ACCESS (проверка идёт до кэша); admin проходит.
- Откат защищён: изменение тела или зависимостей → отказ, принятая история недостач TRADECASE → отказ (`rollback-guard-dry.json`: история PASSED, до apply ожидаемо AFTER_SOURCE_DRIFT_REFUSED).
- UI `wiki-raw/wms_admin_ui_reference/case-pick-management.js`: торговые коды отказа показываются понятным текстом, сохранённое решение не теряется (повтор с тем же телом), у кнопок решений есть title и help id.
- Сценарий для root `tests/tradecase/live_trade_pick_shortage.py` (не запускался): новый изолированный склад, лоты A/B по 10; сначала собраны 4, затем 6 заявлены как недостача; самоутверждение отклоняется; RESTORE; отзыв прав → повтор даёт 403 → возврат прав → та же квитанция; изменённое тело даёт 409; инвентаризация 0; пополнение; READY; сборка оставшихся 6.
