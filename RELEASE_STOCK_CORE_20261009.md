# Важное изменение: переход на единое ядро проводки остатков

09.10.2026 — RABAEV/orcl переключена на **ACTIVE**, baseline **B0-20261009-STOCK-V2**. Совместимость старого event-trigger по умолчанию отключена: **STOCK_LEGACY_TRIGGER_ENABLED=0**.

Изменение запасов выполняется явной командой Oracle; P/H, состав маркировки, существующие документы/задания, журнал и обязательный outbox фиксируются одной транзакцией. Прямые изменения остатка запрещены. Повтор operation_id безопасен; другое содержимое с тем же ID отклоняется. Старые таблицы WMS/TMS сохранены.

Закрыты 31 известный источник проводок: 25 адаптированы, 6 выведены из исполнения. Обновлены API, ТСД CASE и WinForms. Добавлены помарочный захват inventory/MES birth и атомарный возврат целого CASE carrier.

Реальные Oracle cases подтвердили проводку, replay, конкуренцию одного stock/version, полный rollback после исполненного DML и запрет прямого UPDATE. 24 локальных теста прошли, WinForms собран и обновлён, рабочий API перезапущен. После тестовых случаев P=H=0, история 8 операций/8 движений сохранена.

После первой операции запрещён возврат к старому исполнителю путём сброса release: используйте обратные/корректирующие команды. Специальный cutover runner предназначен для уже очищенной dev-базы и отвергает непустой запас.

Полная запись SQL, B0, восстановления, принятых решений по slow SQL и границ проверок: [wiki/database/nicora_stock_posting_cutover_20261009.md](wiki/database/nicora_stock_posting_cutover_20261009.md). Это завершение переключения проводок; промышленная нагрузка, государственное подтверждение кодов и весь проект NICORA не объявляются принятыми.
