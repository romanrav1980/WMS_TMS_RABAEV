





1) Списание из ячейки отбора происходит в момент подтверждения качества сборки паллета.

СПИСАНИЕ: 
	1.1)
для каждой строчки СТ: 
 Товар списывается из ячейки отбора по ФИФО. при этом, если по ФИФО строке товара соответствует более 1 партии,
	 в строку загрузки заносится партия с худшим сроком.
	Если товара в ячейке не хватает, то 
		Формируем событие о нехватке товара в паллете, 
		Проводим списание товара с указанием на несуществующую партию ( MINUS )
		
СТОРНИРОВАНИЕ СПИСАНИЯ:		
	1.2) Товар возвращается в ячейку отбора с номером партии (паллета), с которым его отгрузили, 
	если только номер паллета <> MINUS: событие стирается ( удаляется ), во время удаления события 
	срабатывает триггер, действующий обратно действию события.
		

ИЗМЕНЕНИЯ В ПРОЦЕДУРЕ ПЕРЕВОДА ПАЛЛЕТА В ЯЧЕЙКУ ОТБОРА: 
если есть строки накладных, с датой ст более 3 дней от текущей, с номером паллеты =  MINUS, 
Для каждой:
	делаем списание паллеты в ячейку,  
	указываем номер паллета (партии) = текущий спущенный, 
	делаем списание количества данного паллета на строку отгруженного паллета.



2) Списание из ячейки отбора можно сторнировать
