# Sprint 57 — Usability Checklist: Быстрое добавление СТ в рейс по номеру

## Feature: Quick-add ST input field in trip detail panel

### Видимость
- [ ] Строка «+ СТ №: [input] [Добавить]» видна в панели рейса
- [ ] Строка видна на вкладке «Заявки» при открытом рейсе
- [ ] Строка скрыта для закрытого рейса («Отгружен»)
- [ ] Строка скрыта для рейса с выставленным счётом (PAY_ORDER_ID)

### Ввод и отправка
- [ ] Ввод номера СТ в поле + Enter → СТ добавляется в рейс
- [ ] Ввод номера СТ в поле + кнопка «Добавить» → СТ добавляется в рейс
- [ ] После успешного добавления поле очищается
- [ ] Toast «СТ N добавлен в рейс #ID» показывается
- [ ] Состав рейса (нижняя таблица) обновляется

### Состояние кнопки
- [ ] Кнопка «Добавить» неактивна при пустом поле
- [ ] Кнопка «Добавить» неактивна во время выполнения запроса (loading)
- [ ] Кнопка активна при любом непустом тексте в поле

### Обработка ошибок
- [ ] Если СТ не существует — API возвращает ошибку, она показывается
- [ ] При ошибке поле не очищается (можно исправить номер)
- [ ] Если СТ уже в этом рейсе — API предупреждает через warnings

### Не мешает другим функциям
- [ ] Нажатие Enter в поле не закрывает диалоги
- [ ] Нажатие Escape не срабатывает внутри поля (Sprint 44 guard)
