### 2. Слой кластеров (по RAION)

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Чекбокс «Слой кластеров» в левой панели | Видима; по умолчанию выключена | |
| 2.2 | Включить чекбокс | На карте появляются полупрозрачные полигоны по RAION | |

| 2.6 | Повторный клик на кластер | Снимает выделение | |
| 2.7 | Отключить чекбокс | Кластерный слой исчезает | |
