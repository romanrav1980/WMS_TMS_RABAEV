# Sprint 54 — Usability Checklist: Экспорт выделенных СТ в CSV

## Feature: «⬇ CSV» button in sticky selection bar

### Видимость кнопки
- [ ] Кнопка «⬇ CSV» видна в sel-bar при наличии выделенных СТ
- [ ] Кнопка исчезает вместе с sel-bar при снятии всех выделений
- [ ] Кнопка расположена перед кнопкой «✕» и после кнопки «Добавить в #ID»

### Функциональность
- [ ] Клик → браузер скачивает файл `selected-sts-YYYY-MM-DD.csv`
- [ ] Файл открывается в Excel без кракозябр (BOM UTF-8)
- [ ] Разделитель — точка с запятой «;»
- [ ] Первая строка — заголовок: «СТ №;Адрес;Регион;Район;Паллет;Вес кг;Объём м³;% сборки;Тип ТС;Рейс»

### Содержимое файла
- [ ] Каждый выделенный СТ — отдельная строка
- [ ] «% сборки» — «100%» / «50%» / пусто (если null)
- [ ] «Рейс» — «#ID» если назначен, пусто если нет
- [ ] Null-поля (ADDR, REGION, RAION) — пустая строка в CSV
- [ ] Последняя строка — «ИТОГО» с суммой паллет и весом

### Итоговая строка
- [ ] Количество паллет = сумма всех выделенных
- [ ] Вес кг = сумма всех выделенных
- [ ] Остальные поля в ИТОГО — пустые

### Взаимодействие
- [ ] Экспорт не снимает выделение
- [ ] Экспорт не открывает никаких диалогов
- [ ] Можно экспортировать 1 СТ, работает корректно
