# Sprint 15 — Usability Checklist
## Биллинг: создание счёта

**Scope:** `TransportDispatchPage` · вкладка «Маршруты» · кнопка «Выставить счёт» · диалог · бейдж

---

### 1. Список рейсов — биллинг-колонка

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Колонка 💰 в таблице рейсов (вкладка Маршруты) | Видна последней колонкой | |
| 1.2 | Рейс без биллинга | «—» в колонке 💰 | |
| 1.3 | Рейс с биллингом | Эмодзи 💰 в колонке | |

---

### 2. Кнопка «Выставить счёт»

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Рейс в статусе «Отгружен», водитель наёмный | Кнопка «Выставить счёт» видна в заголовке | |
| 2.2 | Рейс в статусе «Спланирован» | Кнопка «Выставить счёт» не видна | |
| 2.3 | Рейс с собственным водителем (IS_OWN_DRIVER = 1) | Кнопка «Выставить счёт» не видна | |
| 2.4 | Рейс уже включён в счёт | Кнопка «Выставить счёт» заменяется на бейдж «💰 Счёт #N» | |

---

### 3. Диалог «Выставить счёт»

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Клик на «Выставить счёт» | Открывается диалог | |
| 3.2 | В диалоге: номер рейса и машина | Верные данные | |
| 3.3 | Транспортная компания в диалоге | Имя ТК из TK_NAME | |
| 3.4 | Дата периода | Дата отгрузки рейса | |
| 3.5 | Цена рейса | Показана или «—» | |
| 3.6 | Текст-предупреждение о необратимости | Видно | |
| 3.7 | Кнопка «Отмена» | Закрывает диалог, рейс не изменяется | |
| 3.8 | Кнопка «Создать счёт» | Активна, не задизейблена | |

---

### 4. После создания счёта

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 4.1 | Диалог закрывается | Сразу после успешного ответа | |
| 4.2 | Бейдж «💰 Счёт #N» в заголовке рейса | Виден с номером заказа | |
| 4.3 | Кнопка «Отменить» задизейблена | Нельзя отменить счёт | |
| 4.4 | Кнопки снятия СТ задизейблены | Нельзя редактировать состав | |
| 4.5 | Колонка 💰 в таблице маршрутов | Эмодзи 💰 появилось | |
