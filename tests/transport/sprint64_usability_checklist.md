# Sprint 64 — Usability Checklist: Выделить несобранные СТ (клик по значку)

## Feature: Click-to-select not-ready STs via the badge button

### Поведение кнопки
- [ ] Клик по значку «⚠ N не собрано» добавляет все несобранные СТ в выделение
- [ ] Уже выделенные СТ остаются выделены (SET union, не замена)
- [ ] Готовые СТ (VERIFY_PERC = 100) и null-СТ в выделение не добавляются
- [ ] После клика sel-bar показывает обновлённый счётчик выбранных

### Фильтр склада
- [ ] При активном фильтре склада выделяются только несобранные СТ этого склада

### Внешний вид
- [ ] Курсор меняется на pointer при наведении
- [ ] Hover: чуть темнее янтарный фон (#fde68a)
- [ ] Tooltip: «Кликни, чтобы выделить все несобранные СТ»

### Пограничные случаи
- [ ] Если все СТ собраны — значок отсутствует, кнопки нет
- [ ] Повторный клик — не снимает выделение (only additive)
