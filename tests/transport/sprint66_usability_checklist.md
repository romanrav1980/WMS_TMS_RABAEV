# Sprint 66 — Usability Checklist: VERIFY_PERC в таблице состава рейса

## Сценарий: Таблица состава рейса (вкладка «Заявки»)

- [ ] Заголовок столбца «%» отображается между «Вес» и «Зона»
- [ ] Для СТ с VERIFY_PERC=100 показывается зелёная полная полоска VerifyBar
- [ ] Для СТ с VERIFY_PERC=0 показывается пустая красная полоска
- [ ] Для СТ с VERIFY_PERC=null показывается «—»
- [ ] Для СТ с VERIFY_PERC=50 показывается полоска до половины
- [ ] Пустой рейс: строка-заглушка тянется на все 12 колонок (нет сдвига)
- [ ] Ширина колонки % не ломает компоновку таблицы
- [ ] VerifyBar в таблице рейса визуально совпадает с VerifyBar в таблице доступных СТ

## Регрессия

- [ ] Вкладка «Маршруты» — ПРОВ-колонка работает как раньше
- [ ] Shift-click выделение строк работает
- [ ] Кнопки «Добавить в рейс», «Снять СТ» работают
- [ ] Печать маршрутного листа работает
