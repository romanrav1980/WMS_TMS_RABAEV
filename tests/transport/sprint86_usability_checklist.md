# Sprint 86 — Usability Checklist: CSV экспорт таблицы маршрутов

## Кнопка «⬇ CSV»

- [ ] Кнопка «⬇ CSV» присутствует в тулбаре вкладки «Маршруты» рядом с «⬇ Excel»
- [ ] Кнопка недоступна (disabled) когда нет видимых рейсов (searchedRouteTasks.length === 0)
- [ ] Клик по кнопке скачивает файл `routes-YYYY-MM-DD.csv`
- [ ] CSV открывается в Excel без проблем с кириллицей (BOM UTF-8)

## Содержимое CSV

- [ ] Строка заголовка: ID, Дата, Время, Машина, Водитель, ТК, Пал., Вес кг, Объём м³, Регионы, Цена ₽, Статус, % сборки, ДОК, Логист
- [ ] Количество строк данных = количество видимых рейсов
- [ ] Экспортируются только ВИДИМЫЕ (отфильтрованные) рейсы, не все

## Регрессия

- [ ] Excel-экспорт «⬇ Excel» работает (Sprint 28)
- [ ] Фильтр статуса и поиск влияют на экспортируемые данные
