# Sprint 82 — Usability Checklist: Фикс dispatch-st-ready + Persist stDate/dateTo

## Фикс зелёной рамки для полностью собранных СТ

- [ ] СТ с VERIFY_PERC = 100 в таблице доступных СТ имеет зелёную левую рамку
- [ ] СТ с VERIFY_PERC = 50 не имеет зелёной рамки
- [ ] СТ с VERIFY_PERC = null не имеет зелёной рамки
- [ ] При выборе (checked) зелёная рамка уступает синему фону выделения

## Персистентность даты СТ

- [ ] «Дата СТ» сохраняется после перезагрузки страницы
- [ ] Изменение «Дата СТ» не сбрасывается при переключении вкладок
- [ ] «Дата до» сохраняется после перезагрузки страницы
- [ ] «× Сбросить» очищает «Дата до» и она не восстанавливается на пустой

## Регрессия

- [ ] Даты фильтра рейсов (filterDate) работают независимо от stDate
- [ ] Зелёная рамка не исчезла со строк, у которых VERIFY_PERC был 100 до перехода
