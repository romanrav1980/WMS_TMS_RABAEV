# Sprint 90 — Usability Checklist: Копирование номера СТ по клику

## Копирование в буфер обмена

- [ ] Ячейка номера СТ в таблице «Состав рейса» (вкладка Задания) кликабельна
- [ ] Ячейка номера СТ в таблице «Состав рейса» (вкладка Маршруты) кликабельна
- [ ] Курсор меняется на pointer при наведении на номер СТ
- [ ] При наведении номер подчёркивается пунктиром (underline dotted)
- [ ] Клик по номеру СТ копирует его в буфер обмена (Ctrl+V → должен вставить номер)
- [ ] После копирования рядом с номером кратко появляется зелёный «✓»
- [ ] Значок «✓» исчезает через ~1.5 с

## UX-детали

- [ ] Клик по ячейке НЕ снимает выделение строки (checkbox не затронут)
- [ ] Копирование работает и для отгруженных рейсов (disabled mode)
- [ ] Функция корректно работает при быстрых повторных кликах (таймер сбрасывается)

## Регрессия

- [ ] Остальные ячейки строки СТ кликабельны как прежде (чекбокс, ПОР, ✕ и т.д.)
- [ ] CSV-экспорт состава рейса работает без изменений
- [ ] Фильтр «⚠ Несобр.» (Sprint 89) работает без изменений
