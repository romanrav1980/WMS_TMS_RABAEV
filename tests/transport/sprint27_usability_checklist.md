# Sprint 27 — Usability Checklist
## Биллинг: Excel-экспорт реестра счетов

**Scope:** кнопка «⬇ Excel» в тулбаре реестра счетов · скачивает XLSX с текущим фильтром · строки = все счета в фильтре

---

### 1. Кнопка «⬇ Excel» в тулбаре реестра

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Открыть вкладку «Биллинг» | Тулбар содержит кнопку «⬇ Excel» и кнопку «⬇ CSV» | |
| 1.2 | Нажать «⬇ Excel» (при наличии данных) | Скачивается файл billing_registry.xlsx | |
| 1.3 | Кнопка показывает «…» во время загрузки | Индикатор активен | |
| 1.4 | Кнопка неактивна (disabled), если список пуст | Нельзя скачать пустой файл | |
| 1.5 | После скачивания кнопка возвращается в нормальное состояние | Не зависает | |

---

### 2. Фильтрация в экспорте

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Установить фильтр «Компания» → нажать «⬇ Excel» | В файле только счета нужной компании | |
| 2.2 | Установить фильтр «Статус: Выставлен» → экспорт | Только открытые счета в файле | |
| 2.3 | Установить период → экспорт | Только счета с датами в периоде | |
| 2.4 | Без фильтров → экспорт | Все счета реестра | |

---

### 3. Содержимое файла

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Открыть xlsx в Excel | Файл открывается без ошибок | |
| 3.2 | Первая строка — заголовок «Реестр биллинг-заказов» | Виден | |
| 3.3 | Вторая строка — информация о фильтрах | Указан примерный фильтр | |
| 3.4 | Строка заголовков столбцов присутствует | «№ счёта», «Компания», «Период с», «Период по», «Рейсов», «Сумма ₽», «Статус» | |
| 3.5 | Данные счетов совпадают с таблицей на экране | Одинаковое число строк | |
| 3.6 | Последняя строка — итоговая сумма | «Итого:» + число | |
| 3.7 | Числа форматированы как числа (не текст) | Excel суммирует без ошибок | |
