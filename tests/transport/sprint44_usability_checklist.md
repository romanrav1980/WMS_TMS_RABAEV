# Sprint 44 — Usability Checklist: Клавиша Escape

## Feature: Global Escape key handler

### Приоритетная цепочка (каждое нажатие — одно действие)
- [ ] Escape закрывает диалог «Создать маршрут» (если открыт)
- [ ] Escape закрывает диалог «Создать рейс из кластера» (если открыт)
- [ ] Escape отменяет режим редактирования рейса (если активен)
- [ ] Escape снимает выделение со всех СТ в таблице заявок
- [ ] Escape снимает выделение со всех СТ внутри рейса (чекбоксы состава)

### Корректность
- [ ] Escape в активном input/select/textarea — НЕ срабатывает как глобальный хэндлер
- [ ] Второе нажатие Escape выполняет следующее действие по приоритету
- [ ] Если ничего не выделено и нет открытых диалогов — Escape ничего не делает
- [ ] После закрытия диалога через Escape — форма сбрасывается

### UX
- [ ] Диспетчер может быстро «очистить» состояние страницы несколькими нажатиями Escape
- [ ] Не требует фокуса на конкретном элементе — работает глобально
