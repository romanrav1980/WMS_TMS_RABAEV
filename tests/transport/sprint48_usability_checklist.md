# Sprint 48 — Usability Checklist: Кнопка «Сегодня»

## Feature: Reset date to today

### Видимость
- [ ] Кнопка «Сегодня» НЕ видна когда фильтр уже стоит на сегодня
- [ ] Кнопка появляется при переходе на другой день (◄ / ► / ручной ввод)
- [ ] Кнопка работает независимо на вкладке «Заявки» и «Маршруты»

### Функциональность
- [ ] Клик устанавливает дату в поле = сегодня
- [ ] После клика данные немедленно перезагружаются
- [ ] Кнопка исчезает после сброса к сегодня

### Стиль
- [ ] Синий/голубой акцент, отличается от серых ◄ ► кнопок
- [ ] Hover — более тёмный фон
