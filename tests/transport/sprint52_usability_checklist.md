# Sprint 52 — Usability Checklist: Сортировка таблицы СТ

## Feature: Click-to-sort on available-STs table columns

### Видимость сортировки
- [ ] Заголовки колонок показывают курсор-указатель при наведении
- [ ] Заголовки имеют hover-подсветку (`.dispatch-sortable-th`)
- [ ] Отсортированная колонка показывает стрелку ▲ (asc) или ▼ (desc)
- [ ] Неактивные колонки без стрелок

### Колонки со сортировкой
- [ ] Скл (WARE_ID) — клик сортирует по складу
- [ ] Пал. (PALLETS_COUNT) — клик сортирует по паллетам
- [ ] Вес (WEIGHT_KG) — клик сортирует по весу
- [ ] Объём (VOLUME_M3) — клик сортирует по объёму
- [ ] Регион (REGION) — клик сортирует по региону
- [ ] Адрес (ADDR) — клик сортирует по адресу
- [ ] СТ № (ST_NUMBER) — клик сортирует по номеру СТ
- [ ] В рейсе (TRANSTASK_ID) — клик сортирует; без рейса = null → в конце
- [ ] Дата СТ (STDATE) — клик сортирует по дате
- [ ] % (VERIFY_PERC) — клик сортирует по проценту готовности
- [ ] Район (RAION) — клик сортирует по району
- [ ] Тип ТС (TRANSPORT_TYPE) — клик сортирует по типу
- [ ] Полнопалетная отборка (`SUGAR` legacy field) — клик сортирует по признаку полнопалетной отборки
- [ ] Стол, Прим. — несортируемые (без стрелок)

### Поведение сортировки
- [ ] Первый клик по колонке → сортировка по возрастанию (▲)
- [ ] Второй клик по той же колонке → по убыванию (▼)
- [ ] Клик по другой колонке → сортировка по возрастанию по новой колонке
- [ ] NULL-значения всегда в конце (и asc и desc)
- [ ] Сортировка не сбрасывается при scroll таблицы
- [ ] Сортировка применяется к flat-режиму; в clusters-режиме не влияет

### Взаимодействие с Shift-click
- [ ] Shift-click после сортировки выделяет диапазон в порядке отображения
- [ ] Checkbox «выделить все» работает корректно при активной сортировке

### Производительность
- [ ] Сортировка 400+ строк без заметного лага (< 50 мс)
