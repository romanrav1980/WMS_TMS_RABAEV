# Sprint 72 — Usability Checklist: Фильтр внутри состава рейса

## Сценарий: Фильтрация СТ по тексту

- [ ] Поле «Фильтр по СТ/адресу» видно в тулбаре над таблицей состава рейса
- [ ] Ввод части номера СТ → таблица фильтруется, остаются только совпадающие СТ
- [ ] Ввод части адреса → аналогично
- [ ] Ввод части региона → аналогично
- [ ] Фильтрация case-insensitive (строчные и прописные буквы)
- [ ] Счётчик «N / M СТ» показывает отфильтрованное / всего
- [ ] Кнопка × появляется при наличии текста и сбрасывает фильтр
- [ ] При пустом фильтре — счётчик «N СТ» (без дроби)
- [ ] Если нет совпадений — «Нет СТ, совпадающих с фильтром.»
- [ ] При переходе к другому рейсу фильтр сбрасывается

## Кнопка «Все» в режиме фильтра

- [ ] «Все» выделяет только отфильтрованные СТ (не скрытые)

## Регрессия

- [ ] Быстрый поиск по маршрутам (routes tab) не затронут
- [ ] Пагинация доступных СТ (Sprint 60) — без изменений
