# Sprint 45 — Usability Checklist: «Перейти к рейсу» из таблицы СТ

## Feature: Goto-trip button in available STs table

### Видимость
- [ ] Кнопка «#ID →» отображается в колонке «ТранспортноеЗадание» для назначенных СТ
- [ ] Кнопка НЕ отображается для СТ без рейса (TRANSTASK_ID = NULL)
- [ ] Кнопка видна когда фильтр «НЕ РАСПРЕДЕЛЁННЫЕ» выключен (unassignedOnly = false)

### Функциональность
- [ ] Клик на кнопку переключает вкладку на «Маршруты»
- [ ] Рейс с соответствующим ID выделяется в таблице маршрутов
- [ ] Если рейс уже в загруженном списке — выбирается без повторного запроса
- [ ] Если рейс на другую дату — дата фильтра обновляется и рейс загружается
- [ ] Клик на кнопку НЕ переключает чекбокс СТ (stopPropagation)

### Стиль
- [ ] Кнопка — маленькая, синяя, с рамкой
- [ ] Hover — более тёмный синий фон
- [ ] Текст: «#ID →» (номер рейса + стрелка)

### Граничные случаи
- [ ] Если рейс недоступен (удалён) — нет ошибки, тихий fail
- [ ] Несколько СТ в одном рейсе — каждый показывает кнопку с одинаковым ID
