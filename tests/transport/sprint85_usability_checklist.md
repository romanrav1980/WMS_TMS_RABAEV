# Sprint 85 — Usability Checklist: Сводка вкладки «Маршруты»

## Отображение сводки

- [ ] Строка сводки видна под таблицей маршрутов при наличии рейсов
- [ ] «Рейсов: N» — отображает количество ВИДИМЫХ (с учётом поиска и фильтра) рейсов
- [ ] «Пал.: N» — сумма паллет всех видимых рейсов
- [ ] «Вес: N кг» — суммарный вес всех видимых рейсов
- [ ] «Отгружено: N» — количество рейсов со статусом «Отгружен»
- [ ] При изменении поискового фильтра сводка обновляется сразу

## Поведение при пустых данных

- [ ] Строка сводки не показывается, если нет рейсов (searchedRouteTasks.length === 0)

## Регрессия

- [ ] Сводка дня Sprint 40 (над таблицей заявок) не затронута
- [ ] Таблица маршрутов прокручивается без конфликтов со сводкой
