# Sprint 4 — Чеклист юзабилити-тестов

**Тестовая среда:** Frontend :3000, API :8088, Oracle с seed «Добра Цен»  
**Тестовые данные:** рейсы на завтра, ~385 СТ со складов 9201–9203  
**Проводит:** тестировщик или диспетчер

---

## 1. Добавление СТ в существующий рейс

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U1.1 | Открыть «Диспетчер», вкладка «Заявки» | Таблица СТ и список рейсов видны одновременно | |
| U1.2 | Кликнуть на рейс в нижней таблице | Рейс подсвечивается, детальная панель раскрывается ниже | |
| U1.3 | Выделить 2–3 СТ чекбоксами | Строка итогов P/M/V обновляется мгновенно. Кнопка «Добавить в рейс #ID» появляется | |
| U1.4 | Нажать «Добавить в рейс» | Загрузчик кратко мигает. СТ исчезают из списка (если «НЕ РАСПРЕДЕЛЁННЫЕ» включён). Состав рейса обновляется | |
| U1.5 | Проверить, что выделение сброшено | Чекбоксы пустые, итоги P=0 M=0 V=0 | |

## 2. Удаление СТ из рейса

## 3. Редактирование реквизитов рейса (edit mode)

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U3.1 | Кликнуть «Редактировать» в заголовке рейса | Поля ТС, Водитель, Докст., Время, **Дата**, **Тип ТС**, Примечание переключаются в edit-виджеты | |
| U3.2 | Изменить Тип ТС с «10» на «15» через dropdown | Dropdown заполнен значениями из справочника | |
| U3.3 | Изменить Дату отгрузки через date-picker | Поле date отображает текущую дату рейса как начальное значение | |
| U3.4 | Изменить ТС (dropdown из списка ТС) | Список ТС содержит номер, марку, тип, кол-во паллет | |
| U3.5 | Нажать «Сохранить» | Все поля сохраняются. В заголовке рейса новые значения. Режим редактирования закрывается | |
| U3.6 | Нажать «Отмена» без сохранения | Поля возвращаются к старым значениям. Изменения не сохранены | |
| U3.7 | Кнопки «Редактировать» нет на закрытом рейсе | Рейс «Отгружен» показывает «только чтение» метку | |

## 4. Inline-редактирование Типа ТС в таблице маршрутов

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U4.1 | Перейти на вкладку «Маршруты» | Верхняя таблица рейсов, колонка «Тип» содержит подчёркнутые значения | |
| U4.2 | Навести на ячейку «Тип» любого открытого рейса | Курсор меняется на pointer, подсветка синим | |

| U4.6 | Кнопка недоступна для «Отгружен» | У закрытого рейса ячейка Тип не кликабельна (нет cursor:pointer) | |

## 5. Закрытие рейса

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U5.1 | Попытаться закрыть пустой рейс (0 СТ) | Кнопка «Закрыть рейс» disabled или API возвращает ошибку — пользователь видит понятный текст | |
| U5.2 | Попытаться закрыть рейс с VERIFY_PERC < 100% | Красный баннер с конкретным текстом от can_print (напр. «Не все паллеты собраны») | |

| U5.5 | Закрытый рейс сохранён в истории | Вкладка «Маршруты» показывает рейс со статусом «Отгружен» (затемнён) | |
