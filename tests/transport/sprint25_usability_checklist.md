# Sprint 25 — Usability Checklist
## Биллинг: Снять рейс с биллинга

**Scope:** кнопка «Снять с биллинга» в карточке рейса · кнопка ✕ в детальном просмотре счёта · защита от снятия с закрытых/оплаченных счетов

---

### 1. Кнопка «Снять с биллинга» в карточке рейса

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Открыть вкладку «Диспетчер», выбрать рейс с PAY_ORDER_ID | Видна карточка «Счёт» с кнопкой «Снять с биллинга» | |
| 1.2 | Кнопка видна только если счёт не закрыт и не оплачен | Для Закрыт/Оплачен — кнопки нет | |
| 1.3 | Нажать «Снять с биллинга» | Появляется confirm-диалог с названием счёта | |
| 1.4 | Подтвердить в диалоге | Рейс отвязывается, секция «Счёт» исчезает | |
| 1.5 | Отменить в диалоге | Ничего не происходит | |

---

### 2. Кнопка ✕ в детальной панели счёта

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Открыть вкладку «Биллинг», нажать на строку счёта | Справа появляется панель с таблицей рейсов | |
| 2.2 | У каждого рейса в открытом (не закрытом) счёте есть ✕ | Кнопка видна справа в строке | |
| 2.3 | В закрытых/оплаченных счетах кнопки ✕ нет | Только в открытых | |
| 2.4 | Нажать ✕ на строке рейса | Confirm-диалог с номером рейса и счёта | |
| 2.5 | Подтвердить | Строка исчезает из списка, счётчик рейсов уменьшился на 1 | |
| 2.6 | Отменить | Ничего не происходит | |

---

### 3. Защита от некорректных действий

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Попытка снять с закрытого счёта (через диспетчер) | Кнопки нет — интерфейс защищён | |
| 3.2 | Попытка снять с оплаченного счёта | Кнопки нет | |
| 3.3 | Кнопка заблокирована (disabled) во время операции | Не дважды нажать | |

---

### 4. Регрессия

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 4.1 | Остальные кнопки в карточке счёта работают | «Закрыть счёт», «Оплачен» — без регрессий | |
| 4.2 | Вкладка «Биллинг» открывается корректно | Таблица счетов грузится | |
| 4.3 | Детальная панель показывает правильный список рейсов | Количество совпадает с task_count | |
| 4.4 | После отвязки, повторный клик на счёт показывает обновлённый список | Рейс больше не значится | |
