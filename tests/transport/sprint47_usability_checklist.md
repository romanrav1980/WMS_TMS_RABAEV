# Sprint 47 — Usability Checklist: localStorage — сохранение состояния

## Feature: Persistent UI state across page reloads

### Что сохраняется
- [ ] `filterDate` — дата фильтра на вкладке «Заявки»
- [ ] `routeShipDate` — дата фильтра на вкладке «Маршруты»
- [ ] `viewMode` — режим просмотра «flat» / «clusters»
- [ ] `activeTab` — активная вкладка («tasks» / «routes» / «billing»)

### Сценарии
- [ ] После перезагрузки страницы диспетчер видит ту же дату и вкладку
- [ ] После навигации назад/вперёд по браузеру — состояние сохраняется
- [ ] Если localStorage недоступен (приватный режим) — нет ошибок, используются дефолты
- [ ] Новая сессия в другом браузере — начинается с сегодняшней даты (нет совместного стейта)

### Поведение
- [ ] Изменение даты немедленно записывается в localStorage (через useEffect)
- [ ] Изменение вкладки немедленно записывается
- [ ] Смена viewMode немедленно записывается

### Не сохраняется (правильно)
- [ ] Выделение СТ (чекбоксы) — сбрасывается при перезагрузке
- [ ] Открытые диалоги — сбрасываются при перезагрузке
- [ ] Текстовые маски фильтров — сбрасываются при перезагрузке
