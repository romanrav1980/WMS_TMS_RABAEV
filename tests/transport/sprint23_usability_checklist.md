# Sprint 23 — Usability Checklist
## Биллинг: детальный просмотр счёта

**Scope:** клик на строку реестра → панель рейсов счёта · экспорт CSV по счёту

---

### 1. Открытие детальной панели

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Открыть вкладку «Биллинг» | Реестр счетов загрузился | |
| 1.2 | Навести мышь на строку счёта | Курсор меняется на pointer, строка подсвечивается синим | |
| 1.3 | Кликнуть на строку счёта | Правая панель открылась с деталями счёта | |
| 1.4 | Панель показывает: номер счёта, статус, компанию, период | Все 4 элемента присутствуют | |
| 1.5 | Строка счёта выделена синим фоном | Подтверждение выбора | |

---

### 2. Список рейсов в счёте

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Счёт с рейсами — панель показывает таблицу | Колонки: ID, Авто, Дата, Сумма ₽ | |
| 2.2 | ID рейса отображается с # | Например «#1234» | |
| 2.3 | Сумма рейса отформатирована с разделителем тысяч | «15 000 ₽», не «15000» | |
| 2.4 | Счёт без рейсов | Сообщение «Рейсов нет» | |
| 2.5 | Итого под таблицей | Сумма всех рейсов | |

### 3. Закрытие панели

| # | Проверка | Ожидание | ✓/✗ |

### 4. Экспорт CSV

| # | Проверка | Ожидание | ✓/✗ |
