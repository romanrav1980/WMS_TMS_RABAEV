# Sprint 39 — Usability Checklist: Активные фильтры + «× Сбросить»

## Feature 1: Заголовок панели фильтров с badge

### Заголовок «Фильтры»
- [ ] В верхней части правой панели (вкладка «Заявки») отображается строка «Фильтры»
- [ ] Строка выровнена с кнопкой «× Сбросить» по горизонтали (space-between)

### Badge — счётчик активных фильтров
- [ ] Когда нет активных фильтров — badge не отображается
- [ ] При активации любого фильтра (маска адреса, СТ, тип ТС, дата, вес, объём, артикул, чекбоксы) — badge появляется с числом
- [ ] Badge обновляется мгновенно при изменении любого фильтра
- [ ] Снятие «НЕ РАСПРЕДЕЛЁННЫЕ» (unassigned_only = false) тоже учитывается в счётчике
- [ ] Badge имеет синий цвет (var(--blue)) и круглую форму

## Feature 2: Кнопка «× Сбросить»

### Видимость
- [ ] Кнопка не отображается когда нет активных фильтров
- [ ] Кнопка появляется сразу при активации любого фильтра
- [ ] Кнопка имеет красный/розовый стиль (отличается от других кнопок)

### Поведение
- [ ] Клик сбрасывает АДР → пустая строка
- [ ] Клик сбрасывает СТ (маска) → пустая строка
- [ ] Клик снимает чекбокс «НЕ эти СТ»
- [ ] Клик снимает «Только собранные»
- [ ] Клик снимает «Только НЕ собранные»
- [ ] Клик восстанавливает «НЕ РАСПРЕДЕЛЁННЫЕ» → включён (true)
- [ ] Клик сбрасывает Дата до → пустая строка
- [ ] Клик сбрасывает V< → пусто
- [ ] Клик сбрасывает M< → пусто
- [ ] Клик сбрасывает Тип ТС → «Все»
- [ ] Клик сбрасывает Артикул → пустая строка

### После сброса
- [ ] Badge исчезает после нажатия «× Сбросить»
- [ ] Кнопка «× Сбросить» исчезает после нажатия
- [ ] Таблица СТ автоматически обновляется (debounce срабатывает)
- [ ] Число строк возвращается к максимальному значению
