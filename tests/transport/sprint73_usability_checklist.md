# Sprint 73 — Usability Checklist: Логист в таблице рейсов (задки-вкладка)

## Сценарий: Колонка «Логист» в таблице рейсов

- [ ] Колонка «Логист» присутствует последней в заголовке таблицы рейсов (вкладка «Заявки»)
- [ ] Для рейсов с LOGIST ≠ null — показывает логин/имя логиста
- [ ] Для рейсов с LOGIST = null — показывает «—»
- [ ] Клик по заголовку «Логист» сортирует рейсы по логисту
- [ ] Пустой список рейсов — заглушка тянется на 14 колонок (нет сдвига)
- [ ] Таблица не переполняется по ширине при наличии всех 14 колонок

## Регрессия

- [ ] Вкладка «Маршруты» — колонка «Логист» без изменений
- [ ] Сортировка по другим колонкам работает
- [ ] Выбор рейса кликом — работает
