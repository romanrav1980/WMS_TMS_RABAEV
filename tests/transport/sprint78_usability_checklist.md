# Sprint 78 — Usability Checklist: Сохранение фильтров в localStorage

## Сценарий: Перезагрузка страницы

- [ ] Включить «Только нераспределённые» → обновить страницу → фильтр остался включённым
- [ ] Выключить «Только нераспределённые» → обновить страницу → фильтр остался выключенным
- [ ] Включить «Только собранные» → обновить → сохранён
- [ ] Включить «Только НЕ собранные» → обновить → сохранён
- [ ] Взаимоисключающие фильтры (собранные / не собранные) — при обоих включённых поведение корректное

## Дефолты (первый запуск)

- [ ] При первом запуске «Только нераспределённые» = включён (дефолт = true)
- [ ] «Только собранные» = выключен (дефолт)
- [ ] «Только НЕ собранные» = выключен (дефолт)

## Регрессия

- [ ] Остальные localStorage-значения (дата, вкладка, viewMode) без изменений
