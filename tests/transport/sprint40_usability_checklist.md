# Sprint 40 — Usability Checklist: Сводка дня над таблицей рейсов

## Feature: Day summary strip

### Видимость
- [ ] Полоска сводки отображается над таблицей рейсов (вкладка «Заявки»), когда есть хотя бы один рейс на дату
- [ ] Полоска НЕ отображается когда рейсов нет (пустой список)
- [ ] Полоска обновляется при смене даты фильтра

### Содержимое
- [ ] «Рейсов: N» — общее число рейсов в текущем фильтре
- [ ] «Паллет: N» — суммарное количество паллет по всем рейсам
- [ ] «Вес кг: N» — суммарный вес (округлён до целых)
- [ ] «Отгружено: X / N» — количество закрытых рейсов из общего числа

### Точность
- [ ] Паллеты складываются правильно при добавлении/удалении СТ в рейс (без перезагрузки страницы не меняется — только при следующем reload)
- [ ] Значение «Отгружено» увеличивается после закрытия рейса
- [ ] Вес NULL трактуется как 0 (не ломает суммирование)

### Стиль
- [ ] Полоска имеет голубоватый фон (отличается от основного фона)
- [ ] Метки (Рейсов, Паллет, Вес кг, Отгружено) — приглушённого цвета
- [ ] Значения — жирным
- [ ] Разделители «·» между блоками
