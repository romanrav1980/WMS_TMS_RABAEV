# Sprint 70 — Usability Checklist: «Все» / «Нет» в составе рейса

## Сценарий: Тулбар выделения всех СТ рейса

- [ ] Тулбар «Все | Нет | N СТ в рейсе» виден над таблицей состава рейса
- [ ] Клик «Все» → все чекбоксы в таблице отмечены
- [ ] Клик «Нет» → все чекбоксы сняты, кнопка «Нет» задизейблена
- [ ] После «Все» → появляется bulk-bar «N СТ выбрано / Снять выбранные»
- [ ] Тулбар не показывается для рейса с 0 СТ (пустой рейс)
- [ ] Тулбар не показывается для отгруженного рейса (CONDITION=Отгружен)
- [ ] Тулбар не показывается для оплаченного рейса (PAY_ORDER_ID ≠ null)
- [ ] Счётчик «N СТ в рейсе» правильно показывает количество

## Регрессия

- [ ] Delete (Sprint 69) работает для всех выбранных через «Все»
- [ ] Escape снимает выделение
- [ ] Таблица «Маршруты» не затронута
