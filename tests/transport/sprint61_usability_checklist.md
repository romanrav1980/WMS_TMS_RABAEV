# Sprint 61 — Usability Checklist: Быстрый фильтр по складу

## Feature: Warehouse selector in ST toolbar

### Видимость
- [ ] Выпадающий список складов виден в тулбаре таблицы СТ
- [ ] Список НЕ отображается, когда все СТ из одного склада
- [ ] Первый пункт: «Все склады» (пустое значение = без фильтра)
- [ ] Опции перечислены в порядке возрастания ID склада: «Скл. 1», «Скл. 2», …

### Фильтрация
- [ ] Выбор конкретного склада — в таблице остаются только его СТ
- [ ] Счётчик меняется: «N / M СТ» (отфильтровано / всего)
- [ ] PMV-итоги (П/кг/м³) пересчитываются по отфильтрованным СТ
- [ ] Сброс на «Все склады» показывает все СТ обратно

### Взаимодействие
- [ ] Смена склада сбрасывает выделение (selectedStNums = {})
- [ ] Смена склада сбрасывает страницу (stPage = 0)
- [ ] Сортировка работает поверх фильтра склада
- [ ] Пагинация работает поверх фильтра склада

### Производительность
- [ ] Фильтрация мгновенна (клиентская, без запроса к API)
