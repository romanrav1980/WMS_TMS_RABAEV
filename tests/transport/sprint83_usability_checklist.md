# Sprint 83 — Usability Checklist: Amber-рамка для несобранных доступных СТ

## Визуальный индикатор

- [ ] СТ с VERIFY_PERC < 100 (но != null) в таблице доступных СТ имеет amber (оранжевую) левую рамку
- [ ] СТ с VERIFY_PERC = null не имеет amber рамки
- [ ] СТ с VERIFY_PERC = 100 имеет зелёную рамку (Sprint 50), не amber
- [ ] Выбранное СТ (checkbox checked) — amber рамка не показывается, только синий фон

## Взаимодействие с цветами складов

- [ ] Amber рамка видна поверх красного фона склада 5
- [ ] Amber рамка видна поверх зелёного фона склада 7
- [ ] При кластерном режиме (isChild) рамки отображаются корректно

## Регрессия

- [ ] Зелёная рамка Sprint 50 для 100% СТ не исчезла
- [ ] Остальные стили строк (hover, selected) работают
