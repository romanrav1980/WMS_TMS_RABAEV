# Sprint 50 — Usability Checklist: Подсветка полностью собранных СТ

## Feature: Green left border for VERIFY_PERC = 100%

### Видимость
- [ ] Строки СТ с VERIFY_PERC = 1.0 (100%) получают зелёную полоску слева
- [ ] Строки с VERIFY_PERC < 1.0 — без зелёной полоски
- [ ] Строки с VERIFY_PERC = null — без зелёной полоски

### Взаимодействие с другими классами
- [ ] Выделенная строка (selected): зелёная полоска НЕ показывается
- [ ] Цвет склада (ware-5, ware-7) и зелёная полоска совместимы
- [ ] В кластерном режиме (child-строки) подсветка тоже работает

### Стиль
- [ ] Полоска: левая граница 3px зелёного цвета (var(--green))
- [ ] Не перекрывает текст в первой ячейке

### UX
- [ ] Диспетчер сразу видит «готовые» СТ, не читая процент
- [ ] При быстром сканировании таблицы зелёные строки бросаются в глаза
