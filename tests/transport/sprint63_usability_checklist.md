# Sprint 63 — Usability Checklist: Счётчик «N не собрано»

## Feature: Not-assembled badge in ST toolbar

### Видимость
- [ ] Значок «⚠ N не собрано» отображается справа от счётчика СТ
- [ ] Значок виден только когда есть СТ с VERIFY_PERC < 100
- [ ] Значок скрыт, когда все СТ собраны (VERIFY_PERC = 100 для всех)
- [ ] Значок скрыт, когда у всех СТ VERIFY_PERC = null (данные не загружены)

### Точность
- [ ] Число в значке = количество СТ с неполной сборкой (VERIFY_PERC < 100)
- [ ] СТ с VERIFY_PERC = null не считаются
- [ ] Счётчик учитывает фильтр склада (wareFilteredSts, не весь availableSts)

### Взаимодействие
- [ ] Tooltip при наведении: «СТ с неполной сборкой (VERIFY_PERC < 100%)»
- [ ] Число обновляется при обновлении списка СТ (авто-refresh или ⟳)
- [ ] Число обновляется при смене фильтра склада

### Внешний вид
- [ ] Жёлтый фон (#fef3c7), янтарная рамка (#fbbf24), тёмно-янтарный текст
