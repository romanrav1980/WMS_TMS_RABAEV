# Sprint 7 — Usability Checklist
## Планировщик маршрутов: карта заказов

**Scope:** `TransportPlannerPage` · `/api/admin/transport/planner/orders` · `/api/admin/transport/routing/status`

---

### 1. Навигация и доступность страницы

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Кнопка `⊕` в левой панели (sidebar) | Открывает Планировщик маршрутов | |
| 1.2 | Кнопка `◄` (назад) | Возвращает на страницу «Двойник» без перезагрузки | |
| 1.3 | Заголовок «Планировщик маршрутов» | Виден сразу, под-заголовок «Карта заказов · Sprint 7» | |
| 1.4 | При ошибке загрузки данных | Отображается предупреждение `⚠` с кратким текстом ошибки; клик закрывает | |
| 1.5 | ErrorBoundary при краш-рендере | Страница показывает «Ошибка интерфейса», кнопка «Вернуться» восстанавливает | |

| # | Проверка | Ожидание | ✓/✗ |

### 3. Статистическая панель

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | «Всего СТ» | Совпадает с длиной массива из API | |
| 3.2 | «На карте» | Только СТ с LAT и LON (геокодированные) | |
| 3.3 | «Паллет» | Сумма PALLETS_COUNT по геокодированным СТ | |

| 3.5 | «Без координат» | Отображается только если > 0; цвет предупреждения (amber/red) | |

### 4. Карта (Leaflet)

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 4.1 | Карта отображается | Тайлы OpenStreetMap загружаются | |
| 4.2 | При наличии данных | Маркеры появляются без ручного зума | |
| 4.3 | Auto-bounds | При загрузке/обновлении данных карта центруется на видимых маркерах | |
| 4.4 | Размер маркера | Пропорционален PALLETS_COUNT: маленький (~6px) / большой (~22px) | |
| 4.5 | Цвет маркера | Совпадает с легендой складов (ware_id → цвет) | |
| 4.6 | TW_STRICT=1 | Маркер имеет пунктирную границу (dashArray) и утолщённую обводку (weight=3) | |
| 4.7 | Нет геокодированных СТ | Показывается сообщение «Нет данных. Проверьте дату и фильтры.» | |
| 4.8 | Колёсико прокрутки | Зум карты работает (scrollWheelZoom) | |
