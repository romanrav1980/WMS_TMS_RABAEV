# Sprint 62 — Usability Checklist: Прилипающий заголовок таблицы СТ

## Feature: Sticky `<thead>` in the available STs table

### Видимость
- [ ] При прокрутке таблицы СТ вниз заголовки колонок остаются видны в верхней части секции
- [ ] Фон заголовков непрозрачный (строки данных проходят под заголовком, не сквозь него)
- [ ] Стрелки сортировки видны на закреплённом заголовке

### Поведение
- [ ] Прилипание работает в стандартном («По СТ») режиме
- [ ] Прилипание НЕ нарушает кластерный режим «По районам»
- [ ] При изменении ширины колонки заголовок и данные выровнены
- [ ] Стрелки сортировки (`▲`/`▼`) кликабельны на закреплённом заголовке

### Кроссбраузерность
- [ ] Chromium (Chrome / Edge)
- [ ] Firefox
