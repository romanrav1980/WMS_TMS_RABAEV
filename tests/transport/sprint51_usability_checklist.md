# Sprint 51 — Usability Checklist: Закреплённая панель выделения

## Feature: Sticky selection bar below STs table

### Видимость
- [ ] Панель НЕ видна когда нет выделенных СТ
- [ ] Панель появляется при первом выделении СТ
- [ ] Панель исчезает после снятия всех выделений
- [ ] Панель остаётся видна при прокрутке таблицы СТ вниз

### Содержимое
- [ ] «N выбр.» — количество выделенных СТ
- [ ] «P=N» — суммарное число паллет
- [ ] «M=N кг» — суммарный вес
- [ ] «V=N м³» — суммарный объём

### Кнопки
- [ ] «+ Создать маршрут» — открывает диалог создания рейса
- [ ] «Добавить в #ID» — показывается только если выбран рейс
- [ ] «Добавить в #ID» — добавляет СТ в текущий рейс
- [ ] «✕» — снимает все выделения

### Стиль
- [ ] Янтарный фон (#fffbeb), граница янтарного цвета
- [ ] «N выбр.» жирным тёмно-янтарным
- [ ] «+ Создать маршрут» — синяя кнопка
- [ ] «Добавить» — зелёная кнопка
- [ ] «✕» — серый, при hover красный
