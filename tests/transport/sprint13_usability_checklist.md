# Sprint 13 — Usability Checklist
## Умный подбор машины и конфликты

**Scope:** `GET /vehicles/available` · `CreateTaskDialog` · Gantt click → task card

### 1. Диалог создания рейса — доступность машин

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Открыть диалог «Создать маршрут» | Поле «Дата отгрузки» и «Время» видны | |
| 1.2 | По умолчанию время отгрузки | 09:00 | |
| 1.3 | Изменить дату/время | Выпадающий список машин обновляется | |
| 1.4 | Машина с 🟢 | Свободна к нужному времени; «Свободна» | |
| 1.5 | Машина с 🟡 | Освободится через < 60 мин; «Освободится в HH:MM» | |
| 1.6 | Машина с 🔴 | Занята или недостаточно паллет | |
| 1.7 | Выбрать 🔴 машину | Показывается красное предупреждение ⚠ | |
| 1.8 | Выбрать 🟡 машину | Показывается жёлтое информирование ℹ | |
| 1.9 | Список машин сортирован | Сначала 🟢, потом 🟡, потом 🔴 | |
| 1.10 | При отсутствии API | Список машин доступен без индикатора (graceful degradation) | |

### 2. Gantt — клик на блок операции

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Клик на синий блок (склад) | Открывается карточка рейса | |
| 2.2 | Карточка: номер рейса и гос. номер | «Рейс #123 · А123ВС77» | |
| 2.3 | Карточка: список всех операций | 12 строк с цветными точками | |
| 2.4 | Каждая операция: план HH:MM–HH:MM | Формат без даты | |
| 2.5 | Если есть факт — зелёная галочка с временем | «✓ 06:05» | |
| 2.6 | Если есть δ — цветное отклонение | Зелёный/жёлтый/красный по порогам | |
| 2.7 | Кнопка «Закрыть» | Карточка закрывается | |
| 2.8 | Клик вне карточки (на overlay) | Карточка закрывается | |
