# Sprint 89 — Usability Checklist: Фильтр «Только несобранные» в составе рейса

## Кнопка «⚠ Несобр.»

- [ ] Кнопка «⚠ Несобр.» отображается в тулбаре состава рейса только если в рейсе есть хотя бы одна СТ с VERIFY_PERC < 100 (и не null)
- [ ] Кнопка не отображается, если все СТ собраны (VERIFY_PERC >= 100 или null)
- [ ] Кнопка не отображается для пустого рейса (нет СТ)
- [ ] Кнопка получает класс `active` при включении фильтра (amber glow)
- [ ] Повторный клик снимает фильтр (toggle)

## Фильтрация

- [ ] При включении фильтра в таблице остаются только СТ с VERIFY_PERC < 100 (и не null)
- [ ] СТ с VERIFY_PERC = null НЕ попадают в фильтр (нет данных ≠ несобранные)
- [ ] СТ с VERIFY_PERC = 100 не отображаются при активном фильтре
- [ ] Текстовый фильтр и фильтр несобранных работают совместно (AND-логика)

## Счётчик СТ

- [ ] При активном фильтре счётчик показывает «X / N СТ» (отфильтровано из общего)
- [ ] При снятом фильтре счётчик показывает «N СТ» (без дроби)

## Переключение рейсов

- [ ] При выборе другого рейса фильтр «Только несобранные» сбрасывается
- [ ] При смене вкладки (Tasks ↔ Routes) фильтр сбрасывается

## Регрессия

- [ ] Текстовый фильтр (tripStFilter) работает без изменений
- [ ] CSV-экспорт использует отфильтрованный список (`filteredTaskSts`)
- [ ] Кнопки «Все» / «Нет» (bulk-select) работают с отфильтрованным списком
