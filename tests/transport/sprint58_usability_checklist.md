# Sprint 58 — Usability Checklist: Развернуть/свернуть все кластеры

## Feature: «⊞ Все» / «⊟ Нет» buttons in clusters toolbar

### Видимость
- [ ] Кнопки «⊞ Все» и «⊟ Нет» видны в тулбаре ТОЛЬКО в режиме «По районам»
- [ ] Кнопки НЕ видны в режиме «По СТ»

### Поведение «⊞ Все»
- [ ] Клик — все районы разворачиваются (таблицы СТ внутри кластеров видны)
- [ ] Tooltip «Развернуть все районы»
- [ ] После нажатия кнопка «⊟ Нет» становится функциональной

### Поведение «⊟ Нет»
- [ ] Клик — все районы сворачиваются (таблицы СТ внутри кластеров скрыты)
- [ ] Tooltip «Свернуть все районы»

### Кластер с районом NULL
- [ ] «⊞ Все» разворачивает и кластер без района
- [ ] «⊟ Нет» сворачивает и кластер без района

### Взаимодействие с ручным управлением
- [ ] После «⊞ Все» можно вручную свернуть отдельный кластер
- [ ] После «⊟ Нет» можно вручную развернуть отдельный кластер
- [ ] «⊞ Все» снова разворачивает все, включая вручную свёрнутые
