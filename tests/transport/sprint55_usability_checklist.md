# Sprint 55 — Usability Checklist: Итоги по всем видимым СТ

## Feature: All-visible STs totals strip in toolbar

### Отображение
- [ ] Строка «П=N · M кг · V м³» видна в тулбаре таблицы СТ
- [ ] Число паллет = сумма ВСЕХ видимых СТ (не только выбранных)
- [ ] Вес и объём = суммы по всем видимым СТ
- [ ] Стиль: приглушённый цвет, мельче чем кнопки (11px, muted)

### Обновление при изменении фильтров
- [ ] При смене фильтра «АДР» числа пересчитываются моментально
- [ ] При смене склада числа пересчитываются
- [ ] При смене даты СТ числа пересчитываются
- [ ] При изменении «НЕ РАСПРЕДЕЛЁННЫЕ» числа пересчитываются

### Пустое состояние
- [ ] При пустой таблице показывает «П=0 · 0 кг · 0.0 м³»

### Взаимодействие с sel-bar (Sprint 51)
- [ ] Sel-bar по-прежнему показывает статистику только ВЫБРАННЫХ СТ
- [ ] Итоги в тулбаре НЕ изменяются при выделении/снятии выделения СТ
- [ ] Два набора чисел не путают пользователя (разные стили)

### Взаимодействие с сортировкой (Sprint 52)
- [ ] При смене сортировки итоги не меняются (sort не фильтрует)
