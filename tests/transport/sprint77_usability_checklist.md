# Sprint 77 — Usability Checklist: ⬇ CSV — экспорт состава рейса

## Сценарий

- [ ] Кнопка «⬇ CSV» видна в тулбаре над таблицей состава рейса
- [ ] Клик — браузер скачивает файл `trip-{ID}-sts.csv`
- [ ] Файл содержит заголовок: #;СТ №;Адрес;Регион;Паллет;Вес кг;Объём м³;% сборки;Зона;Тип погр.
- [ ] Файл содержит строку ИТОГО в конце
- [ ] При активном фильтре (Sprint 72) в CSV попадают только отфильтрованные СТ
- [ ] CSV открывается в Excel без ошибок кодировки (BOM UTF-8)
- [ ] Кнопка правее счётчика «N СТ» (margin-left: auto)

## Регрессия

- [ ] Sprint 54 — «⬇ CSV» для выделенных в таблице доступных СТ — без изменений
