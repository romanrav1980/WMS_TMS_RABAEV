# Sprint 53 — Usability Checklist: Сворачивание панели фильтров

## Feature: Collapse/expand toggle for the right filter panel

### Кнопка свёртывания
- [ ] Кнопка «‹» видна в правом углу заголовка панели при развёрнутой панели
- [ ] Кнопка «›» видна при свёрнутой панели
- [ ] Hover: синяя подсветка кнопки
- [ ] Title-тултип «Свернуть панель фильтров» / «Развернуть панель фильтров»

### Состояние: развёрнуто (по умолчанию)
- [ ] Заголовок «Фильтры» виден
- [ ] Все поля фильтрации видны (Тип ТС, АДР, СТ, Артикул, чекбоксы, Дата до, V<, M<)
- [ ] Badge с числом активных фильтров виден (если > 0)
- [ ] Кнопка «× Сбросить» видна (если есть активные фильтры)

### Состояние: свёрнуто
- [ ] Панель сужается до ~30px
- [ ] Все поля фильтрации скрыты
- [ ] Заголовок «Фильтры» скрыт
- [ ] Только кнопка «›» остаётся видимой
- [ ] Badge с числом активных фильтров показывается над кнопкой (если > 0)
- [ ] Остальные секции страницы расширяются, заполняя освободившееся место

### Persistence (localStorage)
- [ ] После свёртывания и обновления страницы панель остаётся свёрнутой
- [ ] После разворачивания и обновления страницы панель остаётся развёрнутой
- [ ] Ключ `tms_fpCollapsed` в localStorage

### Взаимодействие с фильтрами
- [ ] Фильтры продолжают работать когда панель развёрнута снова
- [ ] При свёрнутой панели активные фильтры продолжают фильтровать таблицу
- [ ] Reset через кнопку «× Сбросить» не сбрасывает collapsed-состояние
