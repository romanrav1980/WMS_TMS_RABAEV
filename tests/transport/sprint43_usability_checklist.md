# Sprint 43 — Usability Checklist: Сортировка таблицы рейсов

## Feature: Sortable column headers (tasks tab)

### Видимость
- [ ] Все заголовки колонок таблицы рейсов (вкладка «Заявки») кликабельны
- [ ] Курсор меняется на pointer при наведении на заголовок
- [ ] При наведении заголовок подсвечивается

### Поведение
- [ ] Первый клик на заголовок сортирует по возрастанию (▲)
- [ ] Второй клик на тот же заголовок — сортировка по убыванию (▼)
- [ ] Клик на другой заголовок — сортировка по новой колонке по возрастанию
- [ ] NULL/пустые значения при сортировке идут в конец списка
- [ ] Выбранный рейс остаётся выделенным после смены сортировки

### Индикатор
- [ ] Активная колонка показывает стрелку ▲ (asc) или ▼ (desc)
- [ ] Неактивные колонки — без стрелки

### Колонки
- [ ] Сортировка по: Время, ID, СТ, Пал., Тип, Машина, Дата, Водитель, Докст., Районы, Цена, Статус, %

### Граничные случаи
- [ ] При смене даты фильтра сортировка сохраняется
- [ ] Пустая таблица (0 рейсов) — нет ошибок при клике на заголовок
- [ ] Один рейс — сортировка не ломает отображение
