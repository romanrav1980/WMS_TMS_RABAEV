# Sprint 5 — Чеклист юзабилити-тестов

**Цель:** диспетчер видит готовность СТ к погрузке и требования ТС без перехода в другие экраны.  
**Тестовые данные:** seed «Добра Цен» — 385 СТ, 15 ТС, VERIFY_PERC варьируется от 0% до 100%.

---

## 1. VerifyBar — прогресс-бар готовности сборки (колонка «%» в таблице СТ)

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U1.1 | Открыть вкладку «Заявки» | В колонке «%» каждой строки СТ виден цветной прогресс-бар | |
| U1.2 | СТ с VERIFY_PERC = 0 | Красный бар, подпись «0%» | |
| U1.3 | СТ с VERIFY_PERC = 50–99 | Жёлтый бар, подпись «50%» (или другое значение) | |
| U1.4 | СТ с VERIFY_PERC = 100 | Зелёный бар, подпись «100%» | |
| U1.5 | Ширина бара пропорциональна значению | Бар на 50% — ровно половина ширины колонки | |
| U1.6 | Включить фильтр «Только собранные» | Все строки показывают зелёный бар ≥ 50% | |
| U1.7 | Включить фильтр «Только НЕ собранные» | Все строки показывают красный бар = 0% | |
| U1.8 | Навести мышь на бар | Тултип: «Сборка: X%» | |

## 2. TransportTypeBadge — бейдж типа ТС (колонка «Тип ТС» в таблице СТ)

|---|-----|---------------------|------|
| U2.1 | Колонка «Тип ТС» в таблице СТ | Вместо «10» / «15» / «20реф» — цветные бейджи | |
| U2.2 | TRANSPORT_TYPE = «10» | Синий бейдж «Тент 10т» | |
| U2.3 | TRANSPORT_TYPE = «15» | Фиолетовый бейдж «Тент 15т» | |
| U2.4 | TRANSPORT_TYPE = «20реф» | Голубой бейдж «Реф 20т» | |

## 5. «Свой» / «Наёмный» бейдж (таблица рейсов и таблица маршрутов)

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U5.1 | Рейс с собственным водителем (IS_OWN_DRIVER = 1) | Рядом с именем — зелёный бейдж «Свой» | |
| U5.2 | Рейс с наёмным водителем (IS_OWN_DRIVER = 0) с TK_NAME | Рядом с именем — оранжевый бейдж с названием ТК (напр. «ООО Транс-Авто») | |
| U5.3 | Рейс с наёмным водителем без TK_NAME | Оранжевый бейдж «Наёмный» | |
| U5.4 | Рейс без назначенного водителя | Имя «—», бейджей нет | |
| U5.5 | Вкладка «Маршруты» — те же бейджи | В таблице маршрутов колонка «Водитель» тоже показывает «Свой»/«Наёмный» | |
| U5.6 | Панель детали рейса — «Водитель» в meta-row | Бейдж виден рядом с именем и телефоном | |

## 6. Общий UX

| # | Критерий | ✅/❌ |
|---|---------|------|
| U6.1 | Бейджи ТИПТС не обрезаются в таблице СТ | «Тент 15т» читается полностью без overflow | |
| U6.2 | VerifyBar не выбивается за ширину колонки «%» | Бар помещается в отведённое пространство | |
| U6.3 | Цветовая схема согласована: зелёный = хорошо, красный = плохо | READY_PERC 100%=зелёный, VERIFY_PERC 0%=красный — одна логика | |
| U6.4 | «Свой» бейдж: зелёный, «Наёмный» бейдж: оранжевый — интуитивно | Без инструкции ясно что зелёный = лучше | |
| U6.5 | Страница не перегружена визуально | Новые элементы не создают «цветового шума» | |
| U6.6 | Тултипы на всех интерактивных/информационных элементах | VerifyBar, ♿, TransportTypeBadge имеют title | |
