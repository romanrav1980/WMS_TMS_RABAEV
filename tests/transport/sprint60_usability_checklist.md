# Sprint 60 — Usability Checklist: Пагинация таблицы доступных СТ

## Feature: Pagination bar below the flat-mode STs table

### Видимость
- [ ] Панель пагинации не отображается, если все СТ помещаются на одну страницу (≤ 100)
- [ ] Панель пагинации появляется при 101+ СТ
- [ ] В кластерном режиме панель пагинации не отображается

### Навигация
- [ ] Кнопка «◄◄» (первая страница) — отображается, неактивна на странице 1
- [ ] Кнопка «◄» (предыдущая) — отображается, неактивна на странице 1
- [ ] Кнопка «►» (следующая) — отображается, неактивна на последней странице
- [ ] Кнопка «►►» (последняя) — отображается, неактивна на последней странице
- [ ] Отображается счётчик «Стр. N из M · K СТ»
- [ ] Счётчик обновляется при смене страницы

### Сброс страницы
- [ ] При изменении фильтров страница сбрасывается на 1
- [ ] При смене сортировки страница сбрасывается на 1
- [ ] При обновлении списка СТ (auto-refresh / ⟳) страница сбрасывается на 1

### Выделение и сдвиг
- [ ] Shift-click выделяет правильный диапазон с учётом текущей страницы и глобальных индексов
- [ ] «Выделить все» (checkbox в шапке) выделяет все СТ (все страницы), а не только текущую
- [ ] Счётчик выбранных (N выбр. в sel-bar) показывает сумму по всем страницам

### Производительность
- [ ] Навигация между страницами мгновенна (только slice — без запросов к API)
- [ ] 300+ СТ разбиваются на 3 страницы без заметного лага
