# Sprint 22 — Usability Checklist
## Биллинг: справочник компаний + поле NUM_PLAT

**Scope:** `GET /billing/companies` · поле `num_plat` в реестре и карточке счёта · автодополнение в диалоге «Выставить счёт»

---

### 1. Справочник транспортных компаний (GET /billing/companies)

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Открыть реестр счетов | Список загружается без ошибок | |
| 1.2 | Нажать кнопку «Выставить счёт» для рейса с ТК | Диалог открывается | |
| 1.3 | В диалоге видно поле «Транспортная компания» | Название ТК из рейса отображено | |

---

### 2. Поле «№ платёжного» (num_plat)

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Реестр счетов — наличие колонки «№ платёжного» | Колонка присутствует в таблице | |
| 2.2 | Счёт без num_plat — колонка «№ платёжного» | Отображается «—» | |
| 2.3 | Счёт с num_plat — колонка «№ платёжного» | Отображается реальный номер | |
| 2.4 | Карточка счёта (в правой панели рейса) — счёт с num_plat | Строка «№ платёж.: XXX» видна | |
| 2.5 | Карточка счёта — счёт без num_plat | Строка «№ платёж.» отсутствует | |
| 2.6 | Экспорт CSV — открыть файл | Последняя колонка «№ платёжного» присутствует | |

---

### 3. Регрессия реестра счетов

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Фильтр по компании + кнопка ⟳ | Список перефильтровывается | |
| 3.2 | Фильтр «Выставлен» / «Закрыт» / «Оплачен» | Соответствующие статусы в таблице | |
| 3.3 | Итоги по ТК под таблицей | Суммы корректны | |
| 3.4 | Колонка «Сумма ₽» — числа с разделителем тысяч | Нет сырых цифр без форматирования | |
