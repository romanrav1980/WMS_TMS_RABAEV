# Sprint 59 — Usability Checklist: Быстрый поиск по маршрутам

## Feature: Search input in routes-tab toolbar

### Видимость
- [ ] Поле поиска видно в тулбаре вкладки «Маршруты»
- [ ] Кнопка «×» появляется только при непустом запросе
- [ ] Placeholder: «Поиск: ID, авто, водитель, регион…»
- [ ] Счётчик «N/M рейс(ов)» обновляется при поиске

### Поиск по полям
- [ ] По ID рейса (число)
- [ ] По номеру авто (частичное совпадение)
- [ ] По имени водителя
- [ ] По регионам (REGIONS)
- [ ] По транспортной компании (TK_NAME)
- [ ] Регистронезависимый поиск

### Пустой запрос
- [ ] Пустая строка → показываются все рейсы (с учётом фильтра статуса)
- [ ] Пробелы считаются пустым запросом

### Взаимодействие с другими фильтрами
- [ ] Поиск применяется ПОВЕРХ фильтра статуса (Все/Активен/Отгружен/Отменён)
- [ ] Изменение фильтра статуса не сбрасывает поиск
- [ ] Кнопка «×» сбрасывает только поиск, не фильтр статуса

### Производительность
- [ ] Поиск по 300+ рейсам без заметного лага
