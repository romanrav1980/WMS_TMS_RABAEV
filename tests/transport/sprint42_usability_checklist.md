# Sprint 42 — Usability Checklist: Toast-уведомления

## Feature: Non-blocking success toasts

### Появление
- [ ] Toast появляется после успешного создания рейса («Рейс #ID создан»)
- [ ] Toast появляется после создания рейса из кластера
- [ ] Toast появляется после закрытия рейса («Рейс #ID закрыт»)
- [ ] Toast появляется после отмены рейса («Рейс #ID отменён»)
- [ ] Toast появляется после добавления СТ в рейс («N СТ добавлено в рейс #ID»)
- [ ] Toast появляется после массового снятия СТ («N СТ снято с рейса #ID»)
- [ ] Toast появляется после копирования рейса («Рейс #ID создан как копия #sourceID»)
- [ ] Toast НЕ появляется при ошибке API (вместо него — error banner)

### Поведение
- [ ] Toast автоматически исчезает через 3 секунды
- [ ] Клик по тосту закрывает его немедленно
- [ ] Новый toast перезаписывает предыдущий (не накапливаются)
- [ ] Toast не блокирует взаимодействие с таблицей

### Стиль
- [ ] Зелёный фон (var(--green))
- [ ] Белый жирный текст
- [ ] Фиксированная позиция: правый нижний угол
- [ ] Плавное появление (fade-in)
- [ ] Тень под тостом для визуального отрыва от контента
