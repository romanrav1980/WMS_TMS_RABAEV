# Sprint 11 — Usability Checklist
## Модель операций и нормативы (база ARM)

**Scope:** `POST /tasks/{id}/plan-operations` · `GET /tasks/{id}/operations` · `PATCH /operations/{id}/fact` · `GET /vehicles/gantt`

---

### 1. Авто-создание операций при создании рейса

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Создать новый рейс через POST /tasks | Рейс создаётся без ошибок | |
| 1.2 | GET /tasks/{id}/operations сразу после создания | Возвращает 12 операций | |
| 1.3 | Первая операция — DOCK_ASSIGN | code = "DOCK_ASSIGN", ord = 1 | |
| 1.4 | Последняя операция — CLEAN_RETURNS | code = "CLEAN_RETURNS", ord = 12 | |

---

### 2. Расчёт плановых времён

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | DOCK_ASSIGN duration_min = 15 | Соответствует нормативу | |
| 2.2 | WAIT_LOAD duration_min = 10 | Соответствует нормативу | |
| 2.3 | LOADING duration_min = 3 × N паллет | PER_UNIT учитывается | |
| 2.4 | UNLOAD duration_min = 3 × N паллет | PER_UNIT учитывается | |
| 2.5 | DEPART и DRIVE — 0 мин | Нулевые по умолчанию | |
| 2.6 | RETURN_HANDOVER = 20, CLEAN_RETURNS = 20 | Соответствует нормативам | |
| 2.7 | plan_end каждой операции == plan_start следующей | Цепочка непрерывна | |

---

### 3. Повторный расчёт (POST plan-operations)

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Вызвать POST /plan-operations дважды | Старые операции заменяются новыми | |
| 3.2 | Количество операций после пересчёта | Ровно 12 | |
| 3.3 | Операции существующего рейса не переходят на другой рейс | GET по другому task_id не затронут | |

### 4. Фиксация факта

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 4.1 | PATCH /operations/{id}/fact с fact_start | Возвращает {"updated": true} | |
| 4.2 | PATCH с fact_start и fact_end | Оба поля сохраняются | |
| 4.3 | GET /operations после PATCH | fact_start отображается | |
| 4.4 | delta_min при наличии fact_end | Рассчитывается: fact_end - plan_end | |
| 4.5 | PATCH с пустым телом | HTTP 400 | |
| 4.6 | PATCH несуществующей операции | HTTP 404 | |
