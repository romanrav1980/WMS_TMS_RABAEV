# Sprint 19 — Usability Checklist
## Биллинг: привязка рейса к существующему счёту

**Scope:** `TransportDispatchPage` · вкладка «Маршруты» · диалог «Выставить счёт»

---

### 1. Диалог без существующих счетов

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Для ТК без открытых счетов — диалог открывается | Штатный вид: «Будет создан новый биллинг-заказ» | |
| 1.2 | Кнопка «Создать счёт» | Видна и активна | |
| 1.3 | Нет секции выбора счёта | Секция не отображается | |

---

### 2. Диалог с существующими счетами

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Для ТК с открытыми счетами | Появляется секция «Привязать к счёту:» | |
| 2.2 | Загрузка списка | Показывается «Загружаю существующие счета…» | |
| 2.3 | Первая опция: «Создать новый счёт» | Выбрана по умолчанию | |
| 2.4 | Существующие счета | Каждый отображается как радио-опция с номером и датами | |
| 2.5 | Кнопка при выборе «Создать новый» | «Создать счёт» | |
| 2.6 | Кнопка при выборе существующего | «Добавить к счёту» | |

---

### 3. Создание нового счёта (через диалог)

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Опция «Создать новый» → «Создать счёт» | Создаётся новый счёт | |
| 3.2 | После создания | Рейс получает бейдж «💰 Счёт #N» | |
| 3.3 | Карточка биллинга появляется | Содержит данные нового счёта | |

---

### 4. Привязка к существующему счёту

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 4.1 | Выбрать существующий счёт | Радио-кнопка переключается | |
| 4.2 | «Добавить к счёту» | Рейс добавляется к выбранному счёту | |
| 4.3 | После добавления | Рейс получает бейдж «💰 Счёт #N» (существующий) | |
| 4.4 | Карточка биллинга | Показывает данные выбранного счёта | |
