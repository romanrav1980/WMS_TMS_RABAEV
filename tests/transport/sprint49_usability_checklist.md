# Sprint 49 — Usability Checklist: Компактный режим таблицы СТ

## Feature: Dense mode toggle

### Видимость
- [ ] Чекбокс «Компактно» виден в тулбаре таблицы СТ (вкладка «Заявки»)
- [ ] По умолчанию — выключен (обычный режим)

### Функциональность
- [ ] При включении чекбокса строки таблицы СТ уменьшаются в высоте
- [ ] В компактном режиме видно больше строк без прокрутки
- [ ] При отключении чекбокса — таблица возвращается к нормальному виду
- [ ] Компактный режим не влияет на таблицу рейсов (только таблица СТ)

### Стиль
- [ ] Компактный режим: padding строки 1px 4px, font-size ~10.5px
- [ ] Нормальный режим: стандартные отступы
- [ ] Чекбокс — маленький, в стиле autorefresh-toggle

### Граничные случаи
- [ ] В компактном режиме кнопки действий (чекбоксы, «→ рейс») остаются кликабельны
- [ ] При переключении режимов выделение СТ сохраняется
