# Sprint 8 — Usability Checklist
## VRP-оптимизатор: кнопка «Авто-план», полилинии, правая панель рейсов, метрики

**Scope:** `TransportPlannerPage` (Sprint 8 additions) · `/planner/solve` · `/planner/apply` · `/planner/metrics` · `/distance-matrix/rebuild`

---

### 1. Кнопка «Авто-план»

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Кнопка «⚡ Авто-план» видна в левой панели | Ниже кнопки обновления | |
| 1.2 | Кнопка активна только при наличии СТ на карте | При 0 геокодированных СТ — кнопка disabled | |
| 1.3 | Нажать «⚡ Авто-план» | Спиннер `●` появляется в topbar; надпись «Решаем... Xс» | |
| 1.4 | Таймер решения | Счётчик секунд обновляется каждую секунду пока идёт расчёт | |
| 1.5 | После завершения расчёта | Спиннер исчезает; метрики появляются в левой панели | |
| 1.6 | При ошибке сервера | Предупреждение `⚠` с текстом ошибки в topbar; кнопка снова доступна | |

### 2. Полилинии маршрутов на карте

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | После расчёта плана | На карте появляются цветные линии маршрутов | |
| 2.2 | Разные цвета маршрутов | Каждый рейс имеет свой цвет (из палитры 8 цветов) | |
| 2.3 | Маркеры СТ остаются | Кружки заказов видны поверх полилиний | |
| 2.4 | Обновление при новом плане | Старые полилинии заменяются новыми | |
| 2.5 | При отсутствии плана | Полилиний нет (карта чистая) | |

### 3. Правая панель рейсов

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Правая панель появляется | Только когда есть план с маршрутами | |
| 3.2 | Заголовок панели | «Рейсов: N» — совпадает с числом маршрутов | |
| 3.3 | Для каждого рейса: гос. номер | Видно (например, «Е715ТТ97») | |
| 3.4 | Цветная точка рейса | Совпадает с цветом полилинии на карте | |
| 3.5 | Тип ТС | Отображается рядом с номером | |
| 3.6 | Загрузка: «X пал / Y» | Фактическое / максимальное паллетмест | |
| 3.7 | Пробег и время | «XX км», «Xч Yм» | |
| 3.8 | Прогресс-бар утилизации | Зелёный ≥85%, жёлтый ≥60%, красный <60% | |
| 3.9 | Число адресов | «N адресов» под баром | |
| 3.10 | Если есть нераспределённые СТ | В заголовке «· N без рейса» (amber-цвет) | |

### 4. Метрики плана (левая панель)

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 4.1 | Блок «Метрики плана» появляется | После успешного расчёта | |
| 4.2 | «Рейсов»  | Число маршрутов в плане | |
| 4.3 | «Пробег, км» | Целое число | |
| 4.4 | «Утилизация парка» | X.Y% (например «82.5%») | |
| 4.5 | «Нарушений окон» | 0 или число красным цветом | |
| 4.6 | «Score» | Число с одним знаком после запятой | |
| 4.7 | «Решатель» | Бейдж `clarke-wright` или `ortools-cvrptw` | |
| 4.8 | «Время расчёта» | Xмс — реальное время работы решателя | |
| 4.9 | «Не распределено СТ» | Только если > 0; amber-цвет | |

### 5. Кнопка «Применить план»

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 5.1 | Кнопка «✓ Применить план (N рейсов)» | Появляется после расчёта, только если plan_id есть | |
| 5.2 | Нажать «Применить план» | Появляется диалог подтверждения с числом рейсов | |
| 5.3 | Подтвердить | Кнопка переходит в «⏳ Создаём...» | |
| 5.4 | После применения | Появляется «✅ Создано рейсов: N» | |
| 5.5 | После применения кнопка пропадает | Повторное нажатие невозможно | |
| 5.6 | Отмена диалога | Ничего не происходит, план остаётся | |
