# Sprint 69 — Usability Checklist: Delete — снять выбранные СТ с рейса

## Сценарий: Keyboard shortcut в таблице состава рейса

- [ ] Отметить 1+ чекбоксов в составе рейса → нажать Delete → появляется confirm-диалог
- [ ] Confirm «ОК» → СТ сняты с рейса, таблица обновилась
- [ ] Confirm «Отмена» → ничего не произошло
- [ ] Delete не срабатывает при фокусе в INPUT/SELECT/TEXTAREA
- [ ] Delete не срабатывает если нет выделенных СТ в рейсе
- [ ] Delete не срабатывает на вкладке «Маршруты»
- [ ] Кнопка «Снять выбранные» имеет tooltip «Delete»
- [ ] Escape очищает выделение в рейсе — без конфликта с Delete
