# Sprint 74 — Usability Checklist: Свернуть/развернуть состав рейса

## Сценарий: Кнопка ▲/▼ в заголовке рейса

- [ ] Кнопка ▲ видна слева от «Рейс #ID» в заголовке деталей рейса
- [ ] Клик ▲ → кнопка меняется на ▼, таблица состава скрывается
- [ ] Заголовок рейса (машина, водитель, статус) остаётся виден при свёрнутом состоянии
- [ ] Таблица рейсов выше теперь занимает больше места
- [ ] Клик ▼ → состав разворачивается обратно
- [ ] Tooltip ▲ = «Свернуть состав», ▼ = «Развернуть состав»
- [ ] При переходе к другому рейсу состав раскрывается автоматически

## Регрессия

- [ ] Панель паллет (PalletPanel) скрывается при свёрнутом состоянии (не торчит)
- [ ] Bulk-bar «N СТ выбрано» скрывается при свёрнутом состоянии
- [ ] Фильтр по СТ (Sprint 72) не ломается
