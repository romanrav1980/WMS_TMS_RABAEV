# Sprint 2 — UI / UX checklist

Среда: frontend `http://127.0.0.1:3000/?page=transport`, API `http://127.0.0.1:8088`.

## Выделение СТ

| # | Шаг | Ожидаемый результат | Статус |
|---|---|---|---|
| U1.1 | Кликнуть чекбокс одной СТ | Строка выбрана, счетчик показывает `1 выбр.` | |
| U1.2 | Shift+Click по другой СТ | Выделен диапазон строк | |
| U1.3 | Кликнуть район/регион в строке | Выделяются все видимые СТ того же района/региона | |
| U1.4 | Проверить PMV totals | `P/M/V` равны сумме выбранных строк | |

## Создание маршрута

| # | Шаг | Ожидаемый результат | Статус |
|---|---|---|---|
| U2.1 | Выбрать 1-3 СТ | Кнопка `+ Создать маршрут (N)` показывает количество выбранных | |
| U2.2 | Открыть диалог создания | В диалоге есть тип ТС, дата, машина, водитель, док | |
| U2.3 | Нажать `Создать (N)` | Создается рейс, выбранные СТ назначаются в него | |
| U2.4 | При включенном `НЕ РАСПРЕДЕЛЕННЫЕ` | Назначенные СТ исчезают из таблицы свободных | |
| U2.5 | После создания | Выделение сброшено, новый рейс выбран в таблице рейсов | |

## Бизнес-инварианты

| # | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| B1 | `GET /tasks/{id}/sts` после создания | Все выбранные СТ присутствуют в составе рейса | |
| B2 | `GET /available-sts?unassigned_only=true` после назначения | Выбранных СТ там нет | |
| B3 | Cancel созданного рейса | СТ возвращаются в свободные | |
