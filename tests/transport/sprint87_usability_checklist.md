# Sprint 87 — Usability Checklist: Предупреждение о несобранных СТ при закрытии рейса

## Подтверждение закрытия

- [ ] При закрытии рейса без несобранных СТ — стандартный confirm: «Закрыть рейс #N как отгруженный?»
- [ ] При закрытии рейса с 1+ несобранными СТ — расширенный confirm: «⚠ X из N СТ не полностью собраны. Закрыть рейс #ID как отгруженный?»
- [ ] «СТ не полностью собраны» означает VERIFY_PERC != null и VERIFY_PERC < 100
- [ ] СТ с VERIFY_PERC = null не считаются «несобранными» (нет данных = не обработано)
- [ ] «Отмена» в диалоге — рейс остаётся открытым, данные не изменяются
- [ ] «OK» в диалоге — рейс закрывается как обычно

## Регрессия

- [ ] Оба экземпляра кнопки «Закрыть рейс» (tasks tab и routes tab detail) используют новый confirm
- [ ] Перечёркнутая кнопка «Закрыть рейс» недоступна для рейсов без СТ (disabled)
