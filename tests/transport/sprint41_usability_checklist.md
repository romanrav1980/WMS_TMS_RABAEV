# Sprint 41 — Usability Checklist: Фильтр рейсов по статусу

## Feature: Routes-tab status filter

### Видимость
- [ ] Кнопки «Все / Активен / Отгружен / Отменён» видны в тулбаре вкладки «Маршруты»
- [ ] Кнопки НЕ отображаются на вкладках «Заявки» и «Биллинг»
- [ ] Счётчик на кнопке отображается только если N > 0

### Функциональность
- [ ] По умолчанию выбрана кнопка «Все» — таблица показывает все рейсы
- [ ] Клик «Активен» — таблица показывает только рейсы не в статусе «Отгружен» / «Отменён»
- [ ] Клик «Отгружен» — таблица показывает только рейсы с CONDITION = 'Отгружен'
- [ ] Клик «Отменён» — таблица показывает только рейсы с CONDITION = 'Отменён'
- [ ] Повторный клик по активной кнопке не ломает фильтр
- [ ] Счётчик рейс(ов) в тулбаре показывает «X/Y рейс(ов)» (отфильтровано / всего)

### Взаимодействие с другими фильтрами
- [ ] Статус-фильтр комбинируется с фильтром по дате (routeShipDate)
- [ ] Статус-фильтр комбинируется с масками машины / компании / ID рейса
- [ ] При смене даты таблица обновляется и счётчики пересчитываются

### Стиль
- [ ] Активная кнопка выделена синим (Все / Активен), зелёным (Отгружен), серым (Отменён)
- [ ] Неактивные кнопки — приглушённый стиль
- [ ] Счётчик на активной кнопке — белый на цветном фоне
- [ ] Счётчик на неактивной кнопке — тёмный на сером фоне
- [ ] Строки отменённых рейсов в таблице — приглушённые (grid-cancelled)

### Граничные случаи
- [ ] Если нет рейсов по выбранному статусу — отображается «Нет рейсов по фильтрам»
- [ ] Если нет отменённых рейсов — кнопка «Отменён» без счётчика (не скрыта)
- [ ] Выбор рейса через клик работает при любом активном фильтре
