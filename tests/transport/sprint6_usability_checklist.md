# Sprint 6 — Чеклист юзабилити-тестов

**Цель:** диспетчер видит детализацию паллет по выбранному СТ прямо в составе рейса.  
**Тестовые данные:** seed «Добра Цен» — 385 СТ, каждое СТ содержит 3–5 паллет с 8–12 артикулами.

---

## 1. Кнопка 📦 в таблице состава рейса

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U1.1 | Открыть вкладку «Заявки» → выбрать рейс | В таблице состава рейса появился столбец «📦» | |
| U1.2 | Кнопка 📦 для каждой строки СТ | Кнопка отображается в каждой строке состава | |
| U1.3 | Нажать 📦 на первой строке СТ | Под таблицей появилась панель «Паллеты СТ {номер}» | |
| U1.4 | Кнопка 📦 стала подсвеченной (голубой фон) | Видно, для какого СТ открыты паллеты | |
| U1.5 | Нажать 📦 на той же строке ещё раз | Панель закрывается | |
| U1.6 | Нажать 📦 на другой строке | Панель обновляется с паллетами нового СТ | |

## 3. Панель паллет — структура

| # | Шаг | Ожидаемый результат | ✅/❌ |
|---|-----|---------------------|------|
| U3.1 | Открыть панель паллет для СТ с 3–5 паллетами | Видны строки-заголовки паллет с UID, зоной, типом борта, ПОР | |
| U3.2 | Под каждым заголовком паллеты — строки артикулов | Отображаются: артикул, вес, кол-во упак., объём | |

| U3.4 | СТ без паллет в базе | Показывается «Нет данных о паллетах» | |
| U3.5 | Кнопка ✕ в заголовке панели | Панель закрывается | |

## 4. Данные в панели паллет

| # | Шаг | Ожидаемый результат | ✅/❌ |

| U4.1 | Строка-заголовок паллеты | Показаны: UID паллеты, зона (ЗОНА-А/Б/В), тип борта (Г/П/—), ПОР | |

| U4.3 | Строки артикулов | Код артикула в моноширинном шрифте, вес строки, кол-во упак., объём | |

| U4.5 | Несколько паллет в разных зонах | Каждая зона видна в строке-заголовке | |

## 5. Общий UX

| # | Критерий | ✅/❌ |
|---|---------|------|
| U5.1 | Панель паллет не перекрывает состав рейса | Состав выше, панель ниже — оба видны без скролла | |
| U5.2 | При смене рейса панель паллет сбрасывается | Не остаётся «чужих» данных | |
| U5.3 | Артикулы читаемы без горизонтального скролла | Код «ДЦ-МОЛ-0001» виден полностью | |
| U5.4 | Числовые колонки выровнены вправо | Вес, упаковки, объём — по правому краю | |
| U5.5 | Заголовок панели: «Паллеты СТ 0441» — номер СТ виден | Пользователь понимает для какого СТ данные | |
| U5.6 | Кнопка 📦 не мешает кнопке ✕ (снять с рейса) | Иконки не накладываются, легко попасть мышью | |
