# Sprint 56 — Usability Checklist: Печать маршрутного листа

## Feature: «🖨 Печать» button in trip panel

### Видимость кнопки
- [ ] Кнопка «🖨 Печать» видна в панели рейса (вкладка «Заявки»)
- [ ] Кнопка «🖨 Печать» видна в панели рейса (вкладка «Маршруты»)
- [ ] Кнопка неактивна (disabled) если в рейсе нет СТ
- [ ] Кнопка активна при наличии хотя бы одного СТ в рейсе

### Открытие маршрутного листа
- [ ] Клик открывает новую вкладку браузера
- [ ] В новой вкладке открывается диалог печати (window.print вызывается автоматически)
- [ ] При отмене печати вкладка остаётся открытой для ручного просмотра

### Содержимое маршрутного листа
- [ ] Заголовок: «Маршрутный лист — Рейс #ID»
- [ ] Мета-блок: Дата, Машина (с типом ТС), Водитель, Докт, Статус
- [ ] Таблица: #, Пор., Адрес, Район, Пал., Вес кг, Подпись
- [ ] Строки нумеруются с 1
- [ ] «Пор.» = порядковый номер из ORD (или «—» если null)
- [ ] NULL-поля (Адрес, Район) — пустые ячейки
- [ ] Итоговая строка: «ИТОГО», суммарные паллеты и вес
- [ ] Нет лишних HTML-элементов (только нужное для печати)

### Форматирование для печати
- [ ] A4 Portrait, поля 15mm (CSS print media)
- [ ] Шрифт Arial 12px (читаемо на бумаге)
- [ ] Без блока стилей страницы (нет nav, sidebar)
- [ ] Кодировка UTF-8 с BOM — кириллица корректна

### Не меняет состояние приложения
- [ ] После открытия печати выделение СТ не сбрасывается
- [ ] Состояние рейса не меняется
