# Sprint 28 — Usability Checklist
## Диспетчер: кнопка «⬇ Excel» в таблице маршрутов (ТЗ §3)

**Scope:** кнопка «⬇ Excel» во вкладке «Маршруты» · скачивает XLSX с текущими фильтрами · содержит все строки таблицы

---

### 1. Кнопка «⬇ Excel» во вкладке «Маршруты»

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Открыть вкладку «Маршруты» | В тулбаре появилась кнопка «⬇ Excel» справа | |
| 1.2 | Таблица содержит рейсы → нажать «⬇ Excel» | Скачивается .xlsx файл | |
| 1.3 | Имя файла содержит дату (из фильтра даты) | transport_tasks_YYYY-MM-DD.xlsx | |
| 1.4 | Кнопка показывает «…» во время загрузки | Индикатор виден | |
| 1.5 | Кнопка disabled, если рейсов 0 | Нельзя скачать пустой файл | |

---

### 2. Фильтры учитываются в экспорте

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Изменить дату → нажать «⬇ Excel» | Файл содержит рейсы новой даты | |
| 2.2 | Фильтр «Авто» → экспорт | Только нужные машины | |
| 2.3 | Флажок «Без оплат» → экспорт | Только рейсы без биллинга | |
| 2.4 | Без фильтра даты (все) → экспорт | Все рейсы | |

---

### 3. Содержимое файла

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Первая строка — заголовок с датой | «Рейсы: YYYY-MM-DD» | |
| 3.2 | Строка заголовков таблицы присутствует | «Дата», «#», «Пал.», «Вес кг», «Машина», «Статус» и т.д. | |
| 3.3 | Число строк данных равно числу рейсов в таблице | Совпадает | |
| 3.4 | Колонка «Цена ₽» форматирована как число | Можно суммировать | |

---

### 4. Регрессия

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 4.1 | Вкладка «Маршруты» загружается корректно | Таблица рейсов без ошибок | |
| 4.2 | Клик на строку рейса открывает детали | Правая панель | |
| 4.3 | Кнопка «⟳ Обновить» не сломана | Перезагружает список | |
| 4.4 | Вкладки «Заявки» и «Биллинг» не затронуты | Работают как раньше | |
