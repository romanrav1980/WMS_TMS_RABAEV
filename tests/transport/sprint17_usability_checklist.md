# Sprint 17 — Usability Checklist
## Биллинг: реестр счетов

**Scope:** `TransportDispatchPage` · вкладка «Биллинг» · `BillingRegistryTab` · фильтры · таблица · итоги · CSV

---

### 1. Вкладка «Биллинг»

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Кнопка «Биллинг» в панели вкладок | Видна рядом с «Маршруты» | |
| 1.2 | Клик на вкладку «Биллинг» | Правая панель фильтров скрывается | |
| 1.3 | Содержимое вкладки | Заголовок «Реестр счетов» виден | |

| 1.5 | Возврат на «Маршруты» | Правая панель маршрутов снова видна | |

### 2. Фильтры реестра

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Поле «С» (дата от) | Тип date, корректно введённая дата фильтрует список | |
| 2.2 | Поле «По» (дата до) | Тип date, сужает период | |
| 2.3 | Поле «Компания (ТК)» | Текстовый ввод, частичное совпадение | |
| 2.4 | Выпадающий список статусов | 4 варианта: Все / Выставлен / Закрыт / Оплачен | |
| 2.5 | Кнопка «⟳» | Перезагружает список, не меняет фильтры | |
| 2.6 | Кнопка «⬇ Скачать CSV» | Отключена когда список пуст | |

---

### 3. Таблица счетов

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 3.1 | Колонка «Счёт» | Формат БТ-NNNN жирным | |
| 3.2 | Колонка «Компания» | Название ТК | |
| 3.3 | Колонка «Дата от» | YYYY-MM-DD | |
| 3.4 | Колонка «Дата до» | YYYY-MM-DD | |
| 3.5 | Колонка «Рейсов» | Количество привязанных рейсов | |
| 3.6 | Колонка «Сумма ₽» | Сумма с разрядами, «—» если 0 | |
| 3.7 | Колонка «Статус» | Бейдж с цветом | |

### 5. Итоги по ТК

### 6. CSV-экспорт

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 6.1 | Клик «⬇ Скачать CSV» | Файл скачивается как `billing-YYYY-MM-DD.csv` | |
