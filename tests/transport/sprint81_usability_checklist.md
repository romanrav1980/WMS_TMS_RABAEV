# Sprint 81 — Usability Checklist: Клавиатурная навигация по рейсам (↑/↓)

## Вкладка «Заявки» (tasks tab)

- [ ] Нажатие ↓ при выбранном рейсе переходит к следующему рейсу в таблице
- [ ] Нажатие ↑ при выбранном рейсе переходит к предыдущему рейсу в таблице
- [ ] Нажатие ↓ на последнем рейсе переходит к первому (обход по кругу)
- [ ] Нажатие ↑ на первом рейсе переходит к последнему (обход по кругу)
- [ ] Выбранная строка рейса автоматически прокручивается в поле зрения (scrollIntoView)
- [ ] При нахождении фокуса в поле ввода (дата, поиск) стрелки не перехватываются
- [ ] Правая панель детали обновляется при смене рейса стрелками

## Вкладка «Маршруты» (routes tab)

- [ ] ↑/↓ работает и в таблице маршрутов
- [ ] Навигация учитывает текущий фильтр (searchedRouteTasks, не все рейсы)

## Регрессия

- [ ] Ctrl+Enter для добавления СТ в рейс работает (Sprint 68)
- [ ] Delete для снятия СТ работает (Sprint 69)
- [ ] Escape закрывает диалоги (Sprint 44)
- [ ] Нажатие стрелок в поле «Дата СТ» или поиске не меняет выбранный рейс
