# Sprint 75 — Usability Checklist: V= (объём) в заголовке рейса

## Сценарий

- [ ] В заголовке рейса рядом с «P=N M=N» отображается «V=N.NN»
- [ ] V= показывается на вкладке «Заявки» (tasks tab)
- [ ] V= показывается на вкладке «Маршруты» (routes tab)
- [ ] Для пустого рейса V=0.00
- [ ] Для рейса с несколькими СТ значение соответствует сумме VOLUME_M3

## Регрессия

- [ ] P= и M= значения не изменились
