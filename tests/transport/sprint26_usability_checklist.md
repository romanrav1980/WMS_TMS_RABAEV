# Sprint 26 — Usability Checklist
## Биллинг: Excel-экспорт счёта (DoD §12 #7)

**Scope:** кнопка «⬇ Excel» в детальной панели счёта · скачивается XLSX-файл · содержит метаданные счёта и все рейсы с суммой

---

### 1. Кнопка «⬇ Excel» в детальной панели

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 1.1 | Открыть вкладку «Биллинг», нажать на строку счёта | Справа появляется детальная панель | |
| 1.2 | Под таблицей рейсов видна кнопка «⬇ Excel» | Зелёная кнопка присутствует | |
| 1.3 | Рядом с «⬇ Excel» видна кнопка «⬇ CSV» | Обе кнопки | |
| 1.4 | Нажать «⬇ Excel» | Начинается скачивание файла | |
| 1.5 | Кнопка показывает «…» во время загрузки | Индикатор виден | |
| 1.6 | После скачивания кнопка возвращается в норму | Нет зависания | |

---

### 2. Содержимое XLSX-файла

| # | Проверка | Ожидание | ✓/✗ |
|---|----------|----------|-----|
| 2.1 | Открыть скачанный файл в Excel / LibreOffice | Файл открывается без ошибок | |
| 2.2 | Верхний блок содержит метаданные счёта | Номер счёта, компания, период, статус | |
| 2.3 | Таблица рейсов имеет заголовки | «№ рейса», «ТС», «Дата отгрузки», «Статус», «Сумма, ₽» | |
| 2.4 | Данные рейсов совпадают с тем, что видно в панели | Одинаковое количество строк | |
| 2.5 | Последняя строка — итоговая сумма | «Итого:» + число | |
| 2.6 | Числа в колонке «Сумма, ₽» форматированы как числа | Не текст, можно суммировать | |
