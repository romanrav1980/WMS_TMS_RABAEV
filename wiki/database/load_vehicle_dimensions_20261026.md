# Проверка габаритов при погрузке — 26.10.2026

На тестовом складе 223214750 погрузка 33 паллет прошла через HTTP и Oracle: 6600 единиц, 33 факта LOADED, остаток 0/H0. Повтор первой команды не создал второго списания. Однако API принял высоту паллеты 2,5 м при высоте кузова 2 м. Этот результат подтверждает движение товара, но не подтверждает физическую вместимость. После штатной выгрузки всех 33 паллет восстановлены 6600/H6600; повтор первой выгрузки проверен.

Комплект `db/migrations/2026-10-26_load_vehicle_dimensions/` добавляет проверку в существующий нативный обработчик погрузки. Для настроенного профиля обработчик сравнивает высоту места с высотой кузова и проверяет два положения основания: исходное и повёрнутое на 90 градусов. Он также сравнивает сумму внешних объёмов погруженных мест с внутренним объёмом кузова. Эти условия необходимы для погрузки, но не доказывают возможность разместить все места без геометрического пересечения; раскладку паллет проверяет существующий профиль вместимости.

Проверка выполняется при подготовке и перед проводкой, после захвата существующих блокировок конфигурации и машины. Обработчик сохраняет измерения в подготовленном намерении. Ненастроенный профиль сохраняет прежнее поведение; профиль с изменённой основой требует повторного подтверждения. Существующие факты погрузки и квитанции не переписываются.

На момент подготовки комплект НЕ ПРИМЕНЁН. До приёмки нужны применение/пустой откат/повтор, живой отказ для места выше кузова, допустимое место, проверка повтора и неизменности количества после отказа. Измерения тестового набора введены программно и не подтверждают работу оборудования.
