# Захват уже существующих защитных строк товара

## Причина и изменение

Запуск отдельного набора из 660 мест остановился при подготовке блокировок. Переход с 6 на 8 секунд не помог: запрос снова получил HTTP 503, товар остался 6600, жёсткий резерв — 0. Диагностика без исполнения остановилась в подготовке за 13,27 секунды. Общий предел HTTP не менялся и составляет 30 секунд.

Для всех 6600 физических единиц этого набора уже существуют защитные строки ранга 60. Кандидат `2026-10-26-existing-unit-guards` пропускает отдельный native mutex только для таких строк. Строчная блокировка NOWAIT каждой единицы, её регистрация в текущей транзакции и все последующие проверки сохраняются. Новые защитные строки по-прежнему создаются под native mutex.

Кандидат сохраняет native mutex всех остальных рангов, включая STOCK: пакет дел качества использует эту блокировку напрямую. Если защитная строка исчезла после формирования списка, операция получает `CLOSURE_CHANGED` и повторяется целиком; код не создаёт такую строку без mutex. Кандидат возвращает предел одной попытки с 8 до 6 секунд. Спецификация пакета, права, товарные записи и формат команды не меняются.

## Проверка до применения

Прототип исполнил анонимные копии старого и нового тела на Oracle; рабочий пакет пока не изменён. Один сравнительный захват 6600 существующих защитных строк занял 5026,04 мс у прежнего кода и 964,60 мс у кандидата. Это измерение компонента, не скорость HTTP и не нагрузочная приёмка склада.

Пары старый/новый, новый/старый и новый/новый сохранили исключительность существующей единицы: второй сеанс получил ORA-00054. Для новой строки старый/новый и новый/старый сохранили ожидание native mutex и ограниченный отказ. Инъекция удаления строки после формирования списка дала ORA-20890 вместо пропуска защиты. Прямой STOCK mutex пакета качества продолжил блокировать кандидата.

Прототип создал и удалил одну собственную техническую защитную строку; товарные строки не записывались. Остаток после проверки — 6600, жёсткий резерв — 0. Независимая проверка другим исполнителем не проводилась.
