# Root-HU binding to one shipment, 29.10.2026

## Правило

Корневая паллета или короб может содержать несколько закрытых CASE. Все CASE одного корня привязываются к одному подготовленному ST. ST содержит ровно по одному плановому исполнению для каждого заказа CASE и один адрес получателя. Система отказывает до записи, если адреса различаются, CASE уже связан с другим ST, состав дерева не совпадает с носителями CASE или версия корня изменилась.

Повтор с тем же `operation_id`, телом и исполнителем возвращает сохранённый результат. Изменённый запрос с тем же идентификатором получает конфликт. Привязка не отсоединяет CASE, не перепаковывает дерево и не меняет складской остаток.

## Oracle

Миграция `2026-10-29-root-hu-shipment-bind` применена в `RABAEV@orcl`. Уникального ограничения на `RRL_CASE_PICK_TASK.LEGACY_SBORKA_PALLET_ID` нет. Индекс `RRL_CASE_SHIPMENT_IX` существует, не уникален и валиден. На момент проверки 49 CASE ссылались на 41 ST, поэтому rollback откажется, пока есть ST с несколькими CASE.
