# Oracle: комплект установки и справочник 14.10.2026

По поручению владельца подготовлен полный снимок действующей RABAEV для публикации вместе с исходниками приложения.

[Установка и состав](../../db/releases/2026-10-14/README.md) · [manifest](../../db/releases/2026-10-14/manifest.json) · [Каталог объектов](release_20261014/README.md) · [Работа системы](../subprojects/retailcase_system_reference.md).

Состав по живому USER_OBJECTS: 405 таблиц, 1086 индексов (включая связанные с ограничениями/LOB), 170 LOB, 139 последовательностей, 274 спецификации и 274 тела пакетов, 198 функций, 16 процедур, 249 триггеров, 7 представлений. Действующие BIN$-индексы/триггеры включены по связи с живыми таблицами. Их нельзя отбрасывать только по префиксу. Jobs, scheduler jobs, DB links, synonyms, materialized views отсутствуют.

Экспорт выполняет только чтение. За время снимка состав/last_ddl_time объектов не изменился. Контрольные суммы и границы SQL проверены. Сверка с исходной RABAEV: missing=[], invalid=[], STOCK_LEGACY_TRIGGER_ENABLED=0. Целевая пустая установка на отдельном экземпляре не выполнялась; исходная база не перестраивалась.

Установщик создаёт стартового администратора с заданным при установке паролем, группу GLOBAL_ADMIN, склад1, технические каталоги, пустой baseline и CONFIG/RELEASE policy keys. Установка на непустую схему отклоняется до DDL. Режим старого триггера выключен. Секреты и деловые данные не включены.

В исходных комментариях обнаружены 6 повреждённых значений — они не переносятся как осмысленное описание; список в manifest. Имя одного поля SFERA_EAN состоит из U+FFFD; SQL сохраняет фактическое имя, справочник показывает Unicode escape. Исправление legacy-имени требует отдельного изменения зависимостей и не входит в упаковку релиза.

SQL-решение: чтение словарей сгруппировано, бизнес-таблицы не сканируются, кроме пяти небольших технических каталогов (58 строк суммарно). Индексы ради одноразовой выгрузки не добавлялись. Методы получают описание по имеющемуся docstring/метаданным, отсутствие подтверждённого бизнес-описания отмечено явно.
