# СНС/BLC: погрузка отдельных коробов

Статус: подготовка, Oracle миграция ещё не применена; настоящая погрузка короба не проверена. Основание — программа Drive revision27, раздел6/пункт2: работник разбирает паллету, сканирует каждый загружаемый короб, непогруженные короба остаются в экспедиции; скан исходной паллеты не включает их в машину.

## Выбранное изменение

Действие `POST /api/transport/loading/confirm-bulk-box` использует существующий HU_SHIP/transport loading writer и добавляет в неизменяемую команду серверный признак `bulk_box_scan=true`. Отдельного количественного регистра и нового формата SAP не создаётся. Обычная команда погрузки сохраняет прежние параметры. Маркер не принимается из пользовательского тела; пять offline HTTP проверок подтвердили выбор действия и восстановление после403/конфликта/503.

Миграция `2026-10-22-bulk-box-loading` меняет только body RRL_TRADE_STOCK_GUARD: для этого явного действия требует самостоятельный CONTAINER/BOX без родителя и прежней отгрузки. Native компилятор продолжает проверять замыкание, версии, товар, заказы, рейс, собственника, контроль, маркировку и вместимость. Паллетная команда остаётся отдельным действием. Снятие BOX с исходной паллеты выполняется штатной распаковкой, не скрытой частью скана.

## Следующие проверки

1. Сохранить checkpoint и выполнить apply/rollback/reapply/INVALID0 с native отрицательным сканом паллеты.
2. Подготовить отдельный retained набор: два физических короба с кодами, связанные с заказами/рейсом; исходная паллета не является строкой загрузки.
3. Освободить и погрузить один короб. Проверить, что второй сохранил адрес, количество, собственника и резерв в экспедиции; повтор не увеличивает загрузку.
4. Проверить физический скан исходной паллеты, чужой рейс, старую версию/контроль, владельца и конкурентный повтор. Скорректировать назначения непогруженного заказа штатным действием перед выездом; не удалять груз или резерв напрямую.
5. Проверить UI1440/390, потерю ответа и локальную инструкцию. Проанализировать самые долгие SQL и сверить коды, а не только сумму.

Внешнее подтверждение нового состава СКМ и транспортные документы остаются отдельной приёмкой с реальным подключением. Синтетические ответы будут помечены в протоколе. Наличие новой API-команды не означает выполнения T07.
