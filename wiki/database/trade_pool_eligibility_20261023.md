# Торговый остаток в общем пуле

Пакет Claude C0160, checkpoint `620cbd75`, устраняет отказ распределения обычного торгового заказа без ослабления проверки товарного источника. До проверки root на Oracle миграция `2026-10-23-trade-pool-eligibility` остаётся NOT_APPLIED.

Снимок группирует допущенный запас по собственнику, товару, МРЦ и сроку годности. Для каждой строки проверяет совместимость источника с действующими условиями заказа. Распределение указывает количество каждого класса; native повторно проверяет совместимость и запрещает обещать больше свободного остатка. Запись требует действующего права на собственника. Собственное удержание добивки не распределяется повторно.

Root проверяет свежие исходные SHA, применение/откат/повторное применение, затем настоящий заказ на существующем запасе склада210564699. Новых приходов не создавать. После проверки отменить только собственные документы и восстановить настройку пула. Текущие количества250/H0 и коды единиц сохранить.

## Проверки и ограничения

Автор проверил неизменность неторговых снимков и модель распределения. Эти проверки не заменяют запуск настоящей волны, конкуренцию и отзыв доступа. Предел снимка —500 источников,2000 строк и2000 пар класс×строка; стоимость последнего объёма ещё не измерена. Внешний SAP этим пакетом не проверяется.
