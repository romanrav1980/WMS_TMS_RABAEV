# NI06.2 — размещение обычного возврата, 097

Миграция `2026-10-10-097-store-return-existing-putaway` APPLIED в RABAEV; пять изменённых пакетов/spec+body VALID. Используется существующее MANUAL/PUTAWAY с SOURCE_DOC_TYPE STORE_RETURN, исходным документом складской приёмки и собственным SOURCE_TASK_ID. Существующая уникальность заданий сохранена.

## Реализовано
Раздельные места поставщика/утилизации настраиваются по складу, отдельно от приёмки. Они блокируют отбор/пополнение. Планирование через Root фиксирует полное исходное количество, актуальные версии остатка/политики, ёмкость, ресурсы. Исполнение через прежние assign/start/complete и TransferCore QUARANTINE. Частичный перенос/другая паллета запрещены. История планов сохраняется; новый план допустим после отмены прежнего при сохранном остатке в приёмке.

Тот же commit записывает движение, остатки, DONE/SYNCED, неизменяемое размещение, CONDITION=2 типового STORE_RETURN и обязательный STORE_RETURN_PLACED в существующий SAP outbox. Сообщение содержит исходный возврат/заказ/партию/срок/количество и отдельно placement_confirmed=true, supplier_transfer_confirmed=false, external_sap_ack=false.

API `/api/inventory/store-return-putaway`; отдельная страница [Размещение возвратов](../../wiki-raw/wms_admin_ui_reference/store-return-putaway.html). Сохранённый идентификатор повторяется после неопределённого результата; исполнение открывается в существующих складских заданиях.
