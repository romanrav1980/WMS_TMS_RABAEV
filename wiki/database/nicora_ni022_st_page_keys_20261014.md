# NI02.2 — ограниченная выборка СТ и покрывающий индекс

14.10.2026. MIGRATION_ID: 2026-10-14-1381-st-page-keys. Подготовлено по прямому поручению владельца оптимизировать запросы, индексы и объём выборок.

Причина: старый API получал все строки и обрезал в Python; SQL сначала агрегировал сотни тысяч паллет с товарными строками. Страница теперь ограничивается в Oracle. Для запросов без HAVING сначала выбираются узкие ключи СТ, затем рассчитываются товарные итоги только этих групп. HAVING требует прежней агрегации до ограничения, семантика не меняется.

Существующие индексы: WARE_ID/STDATE/ID, ST_NUMBER/PALLET_NUMBER, PALLET_UID/ARTICUL, уникальный ADDR. Новый RRL_ST_PAGE_KEYS_I(ST_NUMBER,ADDR,WARE_ID,CONDITION,PALLET_UID) покрывает чтение заголовков без товарных данных и широких строк таблицы. Влияние на запись: один дополнительный B-tree на изменение ключевых полей паллеты. Не дублирует индекс склада/даты.

До применения сохранён checkpoint1381 в reports/nicora/2026-10-13; recovery — только DROP этого индекса из rollback.sql, без копии БД и удаления данных. Применение и измерения пока не подтверждены. DDL: db/migrations/2026-10-14_ni022_st_page_keys/.
