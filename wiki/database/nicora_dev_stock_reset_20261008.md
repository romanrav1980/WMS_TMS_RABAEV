# Нулевая исходная точка тестового запаса

08.10.2026. Владелец явно разрешил удаление остатков и движений: «база тестовая. можешь сносить остатки и движения».

## Выполнено

В существующей RABAEV сервиса orcl применён [061_dev_reset.sql](../../db/migrations/2026-10-08_stock_posting_core/061_dev_reset.sql).
Удалены 1 986 строк RRL_REMAINS и 3 082 строки RRL_EVENTS. Паллеты и бизнес-документы сохранены.
Копия базы и архив удалённых строк для этого reset не создавались; после commit данные не восстанавливаются данным rollback.

Migration ID: 2026-10-08-024-dev-stock-movement-reset, APPLIED.
Непосредственная проверка Oracle после удаления: остатки 0, движения 0, новые stock operations 0, активные HARD в RRL_STOCK_RESERVATION 0, RRL_WMS_RECEIPT_UNIT 0.

Удаление выполнено одной транзакцией после проверки пользователя/сервиса, PREPARED, отсутствия новых операций, текущих физических единиц и активных HARD. Таблицы движений и остатков блокировались EXCLUSIVE WAIT 3 перед удалением.

## Граница результата

Это очистка тестового запаса, а не завершение перехода. RRL_STOCK_RELEASE остаётся PREPARED, B0 пока отсутствует, legacy writers ещё переводятся.
Сохранённые паллеты не означают наличие товара; наличие определяется остатком.
Сохранённые документы и старые статусы не являются новыми фактами исполнения.
