# NI06.3 ticket099 — сроки магазинной тары
Процесс11: срок задаётся магазину или клиенту; NEXT_DELIVERY, DAYS, SAME_DAY. STORE override имеет приоритет над CUSTOMER через существующий RRL_CUSTOMER_STORE_MAP; неоднозначная привязка клиента запрещена. Часовой пояс задаётся явно, не выводится из часового пояса компьютера.
Snapshot действующей политики записывается в той же Root приёмке VEHICLE→STORE, срок считается по фактическому ACCEPTED_AT. SAME_DAY — до следующей местной полуночи; DAYS — до конца N-го дня после дня передачи. NEXT_DELIVERY наступает при подтверждённой следующей доставке этого магазина другим рейсом, не по неподтверждённому плану.
Восстановимый read-only FIFO долг: оригинальные immutable ACCEPT доставки минус только фактические STORE→VEHICLE ACCEPT возвраты по тому же owner/type/condition/store. Перемещение возврата машина→склад не закрывает магазин второй раз. Исторические передачи098 без политики показываются UNCONFIGURED_LEGACY; новая политика не меняет прежние сроки задним числом.
Не создавать плановый P/пригодную тару из долга. Разрешённый возврат уменьшает долг только фактическим количеством; повреждения/потери требуют отдельного решения, а не молчаливого удаления.
