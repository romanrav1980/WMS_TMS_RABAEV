# Предварительная проверка прав транспортного контекста

Чтение истории дополнительного заезда от назначенной роли заняло932мс. Предварительный native запрос проверял право по всему справочнику складов, прежде чем проверять фактические склады рейса.

На362складах шесть чередующихся измерений одного текущего права дали одинаковый результат; медиана пяти повторных чтений249.35мс для прежнего запроса и2.83мс для прямой проверки текущего склада. Отзыв назначения дал одинаковый отказ. Evidence `T09/TS23*.json`; тестовый QA отключён. Это сравнение запроса, не обещание такого же ускорения всего API.

Кандидат [2026-10-23-transport-scope-precheck](../../db/migrations/2026-10-23_transport_scope_precheck/apply.sql) меняет только предварительную проверку в body RRL_TT_TIME_API. CASE сначала проверяет администратора, затем существующий текущий склад сотрудника. Если права там нет, выполняется прежний поиск по всем складам. Все последующие проверки фактических складов рейса, пустого рейса и активного сотрудника сохранены. Права между запросами не кешируются. Количественных изменений нет.

Свежий источник и SHA сохранены с откатом и проверками. До применения остаются: полный native контекст до/после, назначение на другом текущем складе, чужой рейс и отзыв, применение/откат/повтор и INVALID=0. Внешние дорожные провайдеры эта доработка не восстанавливает.
