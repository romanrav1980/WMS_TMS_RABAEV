# Заводская паллета с коробами при приёмке

23.10.2026. C0168 проверен Codex после перезапускаAPI. Версионный XML-шлюз заказа поставки принимает ссылку паллеты на короба той же строки, системы и профиля. Состав паллеты раскрывается в единицы; состав каждого короба сохраняется в прежней таблице поставщика. Формат не объявляется стандартнымDESADV.

Новый изолированный склад225687965 получил паллету с коробами6+4 одним сканомSSCC через существующую приёмку. Oracle содержит10физических единиц/10кодов,2коробных и1паллетный состав источника. Точный повтор вернул ту же квитанцию; APPLIED один. Привязка к торговому остатку сохранилаСНС,МРЦ200 и годность01.01.2030.

Отклонены: короб в двух паллетах, неизвестныйSSCC, одновременный скан паллеты и её короба, неверное количество, неполный скан одного короба, изменённый повтор, повторная приёмкаSSCC, привязка без права собственника и чужой склад. Тестовый пользователь отключён, назначение отозвано; состояние сценарияCLEANED,INVALID0. Повторный запуск со старым файлом состояния не создаёт новый набор.
