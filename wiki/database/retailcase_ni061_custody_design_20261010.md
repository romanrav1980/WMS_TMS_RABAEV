# NI06.1 — завершение перевозочной ответственности первого плеча,121
Факт DEPARTED сохраняется навсегда с временем выезда, исходным рейсом/СТ/составом. Отдельная явная Root-команда на основании состоявшихся119 unload+receipt завершает текущую ответственность этого плеча за физический UID. Остаток не меняет.
Добавить CUSTODY_RELEASED_AT/CUSTODY_RELEASE_OPERATION_ID в существующий load fact и immutable proof. Активная уникальность UID учитывает отсутствие этой отметки. Исключение только для подтверждённой приёмки второго склада, с исходными фактическими документами, current receiver and warehouse binding. Новая отгрузка с тем же UID допустима после этого; старый факт остаётся историей и не теряет DEPARTED.
Не освобождать историю СТ первого плеча для её повторного назначения. Второе плечо будет новой транспортной СТ, связанной с оригинальным клиентским исполнением, через прежний конструктор/назначение/погрузку. Custody release не означает окончательную доставку магазину.
