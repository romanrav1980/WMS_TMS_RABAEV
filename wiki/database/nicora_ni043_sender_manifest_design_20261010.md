# NI04.3 — манифест агрегации вне SAP,124
В текущем ReceivingMarks агрегаты читаются только из RRL_SAP_TRACE_AGG с ORDER_ID/LINE_NUMBER. INVENTORY/MES обращаются туда с STOCK.BIRTH, поэтому реального несаповского источника состава нет. Отдельный импорт исходного WmsTraceManifest.v1 JSON связывает источник INVENTORY revision или MES FG movement, склад, SKU, физическую паллету, BASE, версию WMS-политики и всех профилей.
Документ содержит точные единицы и коды каждого применимого профиля; вложенные BOX/PALLET раскрываются в подтверждённый состав. Не создавать второй реестр физических единиц: манифест — входное доказательство, RRL_WMS_RECEIPT_UNIT/CODE остаются единственными каноническими записями.
Импорт не проводит запас и не является государственным ACK. Карточка SKU разрешает уровень сканирования; каждая профилированная единица учитывается один раз. Исходный JSON/UTF8 SHA/актёр/область/immutable result сохранены; идентичный retry возвращает результат, иной raw текст под тем же OP отклоняется.
Root INVENTORY_REGISTER_LOT/MES_MOVEMENTS повторно сверяет текущие версии профилей и источника. Atomic stock+units+regulatory journal+manifest use+existing mandatoryoutbox. Требуемый профиль/неизвестный состав/иная паллета или склад/документ/перекрытие/цикл/устаревшая версия отклоняются без товарного эффекта. SAP путь сохраняется.
