# ASM FINAL: отдельный снимок физического CASE, версия3

Статус: APPLIED — root10 statements/0 errors; независимый readback6 sources EXACT, USER_ERRORS0/global INVALID0/ledger APPLIED. Kit: db/migrations/2026-10-15_assembly_final_snapshot. Новый pure `RRL_ASM_FINAL_SNAPSHOT` доступен только трём native пакетам ASM/warehouse capture/warehouse request. Никаких stock writers, COMMIT или изменений blocked/system cell здесь нет.

Причина: shipping QC composition выполняет отгрузочный compiler и правильно не допускает blocked CPT. Пока CASE остаётся на посту сборки, его финальный GROSS нужен для сверки ASM. Перемещение CASE только ради QC меняет content version, поэтому нельзя ослаблять shipping admission или выдавать ASM mass за разрешение отгрузки.

Снимок `signature_domain=ASM_FINAL`, `composition_signature_version=3` включает текущий OPEN own ASM, closed/bound CASE/current content version/carrier, ordered lines/actual positive carrier UID/cell/article/baseqty/stockversion, точные собственные ACTIVE PICKING HARD reservations/order/wave/source task/quantity/version, bound ST rows/UOM policies и текущий fulfillment CASE/version/composition. Updated timestamps и прочая несвязанная metadata не входят в hash. Детерминированный JSON → DBMS_CRYPTO SHA256; количества через общий decimal_text. Read-only guards не открывают blocked cells для отгрузки.

Только own OPEN ASM branch request/capture/context выбирает этот снимок. Legacy FINAL вне ASM сохраняет прежний QC алгоритм. ASM finish требует domain+version3 в immutable archive и равенство актуальному helper signature, кроме уже успешно FINALIZED exact replay. Shipping final-scale admission явно отказывает только domain ASM_FINAL; существующая legacy SMALL_HU signature version3 сохраняется вместе с прежними1/2/отсутствующим domain.

Raw capture DTO и evidence1.0 не меняются: domain/version находятся в native archive/result/snapshot, не добавляются как неизвестные поля measurement packet. Atomic capture/raw local journal сохраняет прежние исходные тела. Измерение FINAL должно заново увидеть фактический пустой ноль после claim, затем стабильный полный GROSS; исходная EMPTY_TARE не подменяет этот ноль.

Приёмка после root apply: actual current context возвращает domain/version/signature; отрицательные read-only/caller-rollback изменения CASE version, bound fulfillment quantity/version, carrier membership/reservation исключают сохранённый hash; чужой/отозванный operator не получает снимок. Затем отдельный разрешённый encrypted TEST OPC FINAL zero→1.5/native capture/raw MATCHED и native finish; количество Stockop остаётся1. Это программная TEST приёмка, физических весов/подбора не подтверждает.
