RRL_STORE_SCALE_DEVICE хранит явный адрес, отдельного sender RUSERS, active/version/capacity/resolution/calibration reference/срок. CONFIG X/optimistic update, dedicated sender с store_scale_ingest, GLOBAL_ADMIN не назначается оборудованием. В legacy RUSERS.ID нет пригодного unique/PK: sender reference проверяется как единственная действующая учётная запись, новый искусственный PK на legacy не вводится.

RRL_STORE_SCALE_API принимает typed gateway contract: KG/GROSS/no preset tare, zero confirmation/recent zero check, current device version/calibration, 5–25 bounded samples ≥2с и ≤10с. Stability max-min≤resolution, capacity и кратность resolution, последнее значение без усреднения. Zero check допускает signed величину в пределах resolution. Source должен быть фактическим committed departed load с frozen single store. Это оборудование отдельно от RUSERS receiver permission.

RRL_STORE_SCALE_CAPTURE сохраняет immutable canonical исходный packet JSON/hash, sender/server first receipt, версию calibration и полный RESULT_JSON. Exact device/capture ID replay возвращает прежний результат даже после деактивации; источник/тело другого содержания конфликтует; текущая авторизация sender всё равно обязательна. Данные защищены private TX-bound context и append-only guard. Отправка вне stock transaction, device-row serialization, нет ожидания оборудования внутри Oracle/stock. Capture может быть дополнительным evidence уже принятой поставки; оно не переписывает её исходный результат.

API /api/delivery/store-scales: devices PUT только warehouse_settings_edit, captures POST только связанный store_scale_ingest, list/content only store_receipt_confirm/current receiver address. Packet incoming cap32000 bytes в audit до parsing, namespace nonreplayable. При неизвестном исходе ответ указывает exact device/capture ID и retry_same_capture. Водительская платформа показывает bounded50 последних оригинальных показаний для выбранного получателя/места; старые доступны по key. Shared store_receipt_read исключает fake posting adapter для чтения.
