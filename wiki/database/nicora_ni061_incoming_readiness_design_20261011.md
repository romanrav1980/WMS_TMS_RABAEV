# NI06.1: готовность нескольких подвозов одному рейсу
Для существующего рейса показывать полный ограниченный список его текущих межскладских обещаний, оба источника, приёмку, размещение, СТ и фактическую погрузку. Текущий пользователь и склад ворот рейса проверяются в одном read-only snapshot. Искать кандидатов по исходному и текущему target TT через индексы239, затем выбрать текущую редакцию; максимум200 поставок, overflow явно отклонять.
Готовность относится только к межскладским обещаниям: не заменяет разрешение native выезда, QC, вместимость, водителя и другие СТ рейса. HOLD и отсутствие действующей физической LOADED/APPLIED записи делают обещание неготовым. Количество суммировать по артикулу и базовой единице Decimal, не смешивать разные товары/единицы. Самостоятельные исходные паллеты не превращаются в одно физическое место от отображения общего рейса. Для двух источников использовать готовые приёмку/задания/конструктор СТ/назначение/QC/load/depart; не создавать новый allocator или quantity writer.
