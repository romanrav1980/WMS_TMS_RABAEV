# NI08.1 — идемпотентное создание исходного кластера, 139

Вход: operation_id, район, исходная дата/тип/машина/водитель/док/складской фильтр. Права: transport_dispatch_edit и актуальный склад каждого исходного ST. Идентификатор обязателен для нового вызова; прежний поиск района и native writers сохраняются.

Один внешний UOW: уникальная операция → текущая машина → новый приватный TT → упорядоченные исходные строки → прежнее назначение/валидация → неизменяемый результат. Конкурентный повтор ждёт уникальный ключ операции. После commit возвращает исходный TT/source snapshot; другое тело/актор с тем же ID отклоняется. Ошибка любой проверки откатывает и операцию, и созданный рейс, и назначения. Native-пакет не commit и не меняет P/H.

Состав СТ выбирается прежним поиском доступности перед транзакцией. Native assignment повторно проверяет каждую заблокированную строку. Повтор операции не захватывает появившиеся позже свободные СТ: возвращает первый сохранённый состав. При повторе текущие права/склады проверяются заново. Отменённый позднее рейс остаётся историческим результатом операции, новый ID требуется для нового рейса.

Таблица содержит request hash/body, actor, original TT FK, immutable result/source/warehouse scope. Placeholder существует только внутри UOW, никогда не должен фиксироваться при ошибке. Guard разрешает insert/единственное заполнение только private package operation+transaction context. Без автоматического удаления истории. Не требуется копия базы.

Авторский кейс: существующие136 частные СТ/машины; отказ перегрузки не сохраняет ни результат, ни TT; два конкурентных одинаковых запроса создают один TT; changed payload409; repeat after cancellation returns history; direct proof mutation denied. Реального грузового проведения нет. Полный NI08.1 остаётся открытым до окон времени, согласованных изменений волны/рейса и независимой приёмки.
