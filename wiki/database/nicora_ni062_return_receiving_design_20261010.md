# NI06.2 ticket096 — физическая приёмка возврата на складе
Первый bounded slice: обычный SUPPLIER/DISPOSAL возврат, уже принят водителем095 и имеет original approval092/SAP-return093/plan094. Не использовать INVENTORY_REGISTER_LOT с фиктивной ревизией и не создавать новую закупку. Новая Root команда STORE_RETURN_RECEIVE, inventory module owner, warehouse_return_receive право. Существующие BalanceCore.apply_delta/write_leg остаются единственными исполнителями P/journal; дополнить их ACL только конкретным private return receive CMD.

Для каждого склада configure separate return receiving cells через существующий CONFIG fence. Cell belongs to SAP recipient warehouse, BLOCKED_FOR_ACCEPT=0, BLOCKED_FOR_REMAINS=1 и BLOCKED_FOR_POPOLNENIE=1. Quarantine действует через ячейку согласно решению владельца; товар возвращается физически, но недоступен для wave/reserve/replenishment. Не менять глобальную обычную зону приёмки склада. GOOD/REUSE отдельно требует full-box/source batch/expiry/same-batch picking placement и пока не разрешается этим slice.

Receive whole approved BASE qty, current actual scan pallet/vehicle/cell, exact original article/expiry, observed batch reference сохранён с provenance (supplier batch из исходной SAP receipt если имеется, unknown legacy batch не объявлять verified), actual gross и net KG. SKU current marking/profile requires exact units: ordinary slice denies. Fresh pallet UID fits legacy50char/150byte, preserves STOCK_ORIGIN_UID original lot, original order/receipt immutable. One pickup may be received once, even if driver account subsequently retired: historical committed custody remains proof; current warehouse actor checks separately.

Short Root transaction: fresh PP metadata+blocked receiving P/H0+one journal leg+immutable warehouse return receipt+required business outbox. Use declared original/fresh PP, pickup/source/receipt, CELL/SKU/config/HU/stock/unique fences and locked source recheck; target existing UID refused. No financial ERP completion at receiving alone: placement and direction confirmation separate next slice through existing warehouse tasks/Root. No Gov/SAP external ACK fabricated.
