# NI08.1 — расчёт прежней ARM-цепочки без удаления фактов,141

Существующий TransportService.plan_operations сначала DELETE всех RRL_TT_OPERATIONS рейса, затем вставляет заново. Это стирает FACT_START/FACT_END и IDs даже при обычном повторе. Результат оператора сохраняем: прежние12 нормативных этапов, но один native UOW и update/insert существующих плановых строк вместо удаления цепочки.

Вход старый task_id/авторизация transport_dispatch_edit; реальный authenticated actor передавать в native API. Порядок: текущая машина→TT→операции по ID; существующие TT/ST/native capacity rules и актуальная WARE остаются основой. Закрытый/оплаченный/погруженный/выехавший рейс или цепочка с фактом не перепланировать. Не добавлять фиктивную паллету при нулевом составе. DATE+TIME плана брать из исходного рейса, без молчаливой даты из time-only Oracle DATE или defaults06:00.

Конфигурационные нормы считывать одним SQL snapshot, Decimal/Oracle NUMBER; missing norm не превращать в0, настроенный0 допустим. DRIVE/DRIVE_BACK0 остаются явным configured estimate, не proof сроков или real routing. Одинаковый повтор с теми же исходными данными сохраняет IDs; если актуальные нормы изменились, новое планирование меняет только незапущенный план. Это не durable operation replay и не полное NS60 time-window acceptance.

Глобальный guard не позволяет удалить фактическую строку, стереть заполненный fact или изменить её план/ключи. Он не блокирует штатную запись/исправление фактического времени и примечания. Товарного триггера/движения/резерва нет. Нативный генератор не commit; error/savepoint оставляет исходную цепочку. Конфликтная дублированная/нестандартная цепочка требует явного разбора, не автоматического удаления.

Авторский case: только прежние136 частные ST/машины; один свежий metadata TT, нормальная цепочка12/повторIDs unchanged; отдельный fact записать штатным интерфейсом, повтор расчёта и прямой DELETE должны быть denied/fact unchanged. Не создавать товарный stock fixture. Независимая приёмка и joint wave-TT/real travel/driver/tare remain open.
