# Отдельный короб как класс грузового места

При подготовке реального рейса660мест API принял класс BOX и вернул503 после отказа Oracle2290. Ограничение RRL_PALLET_TYPE_CHK1 допускает только паллету, тележку и контейнер. Строка нового типа не создана; после отбора склад225290508 сохраняет6600/H6600. Подменять короб паллетой для обхода ограничения нельзя.

Комплект `2026-10-26-box-load-class` добавляет BOX в существующее ограничение. Новое ограничение устанавливается до удаления прежнего и затем получает его имя: таблица не остаётся без проверки класса. Значения старых строк не меняются. Пакет RRL_PALLET_TYPE_API уже нормализует класс и не требует изменения.

Контракт API нормализует регистр и отсекает неизвестный класс до записи. Форма справочника получает пункт «Короб» и русские подписи прежних классов; кнопки получают подсказки.

Состояние: **NOT_APPLIED**, перед применением требуется checkpoint. Пустой откат восстанавливает прежнее ограничение. Если BOX уже используется, откат отказывается с BOX_ROWS_EXIST_KEEP_ADDITIVE_CLASS; удалять действующие типы и грузовые места нельзя. После применения проверить пустой откат, повтор, INVALID0 и создание короба через прежний API.
