# retailcase: имя продукта и установщик

Публичное имя продукта — retailcase. Перенесены имена каталогов/файлов и ссылки. В исходниках, конфигурации и текущей документации используется новое имя; Git-история прошлых выпусков сохраняется.

Установщик: [инструкция](../../docs/install-retail-case.md). Oracle XE загружается с официального сервера, структура приложения ставится только в новую RABAEV. Текущая база не является целью автоматического установщика.

Миграция `2026-10-14-retailcase-wave-name`: меняет только WAVE_NAME двух существующих minimax-волн, сохраняет ID, состав, статус, количество и историю операций. SQL: [apply/rollback/verify](../../db/migrations/2026-10-14_retailcase_wave_name/). Для восстановления нужно вернуть прежнее имя через rollback; история товарных фактов не меняется.

При смене имени browser storage переносится исходная сохранённая команда, включая operation_id. Различающиеся значения старого и нового ключа останавливают работу до разбора. Перенос не отправляет HTTP-команду и не создаёт новую операцию.

Применено: apply5/0, verify1/0; волны230/231, склады9809/9810, статусDONE сохранены, INVALID0. Адресное чтение8.882мс; новый индекс не требуется. Desktop pending-команда также переносится без изменения ID и не перезаписывает конфликт.
