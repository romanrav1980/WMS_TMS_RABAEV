# Вложенный измеренный BOX в погрузочном manifest

Статус dev APPLIED/8SHA/ERROR0/INVALID0. Migration `2026-10-16-nested-box-manifest`; frozen SHA `de9cc39d0eca9ecb48a78e17fc57ab14654b92b24a8172a7ea0608c7ca3e7197`.

Изменяется только body `RRL_STOCK_LOAD_BOX_CORE`. Ранее вложенная CASE с текущим QC покрывала листья, а внешняя измеренная BOX без собственных ближайших листьев считалась лишней. Новая схема сохраняет ближайшее физическое покрытие листьев, но допускает измеренную внешнюю BOX вокруг измеренных CASE/BOX.

Нижняя граница массы каждого измеренного узла складывается из собственной тары, массы KG-листьев и gross ближайших измеренных детей. Gross ребёнка входит в родителя один раз. Для внешнего грузового места суммируются только верхние измеренные узлы и упаковка вне их покрытия. Тара неизмеренного промежуточного контейнера относится к ближайшему измеренному предку либо внешней упаковке, без потери/двойного учёта.

Пустые/чужие/повторные измерения, отсутствие массы ближайшей BOX, несоответствие скана/версии и нижней границы отклоняются. CASE QC, ASM_FINAL provenance, температурный допуск, ST/fulfilment/отгрузочная проводка и электронные интерфейсы не меняются. Это проверка непротиворечивости ручных масс; не объявляет расчётную массу аппаратно измеренной.

Native read-only probe дал6 проверок точного кандидата над историческим замороженным TEST деревом: масса без двойного счёта, нижние границы/дубли/чужие узлы и промежуточная тара. Это вычислительная проверка, историческое дерево не менялось.

Новый отдельный бизнес-проход OC16.3151980d02: CASE1148 BOX24+EA1/25EA → измеренная BOX → PALLET, ручной CASE QC25,5кг/wrapper25,7кг/outer26кг. LOAD/replay/DEPART и магазин PAPER_COUNT приняли25EA/2строки; повторного списания нет, custody освобождена после приёмки.13HTTP packing/loading плюс `ordinary-flow/store-race.json`. Этот новый проход — обычная сборка; смешанный ASM+обычный26EA подтверждён отдельным прежним interWARE кейсом.

Read-only subtree не является частичной физической выдачей.
