## Временная шкала журнала

Oracle host возвращает SYSTIMESTAMP с−04:00, session timezone+03:00. RRL_SQL_SLOW_LOG.CREATED_AT — TIMESTAMP без зоны со временем host. Для окна журнала используем `CREATED_AT >= cast(systimestamp as timestamp) - interval '90' minute`. Неявное сравнение с zoned SYSTIMESTAMP ошибочно дало0строк; это измерение не засчитано и исправлено в evidence. Время остановки рабочего цикла берётся из UTC→Europe/Moscow, не из наивного CREATED_AT.
