## Свежая проверка

[Скрипт](../../wiki-raw/nikora_analysis_20260915/probe.py) и [JSON результата](../../wiki-raw/nikora_analysis_20260915/probe-result.json).

- 11/11 XML-примеров проходят; 8/8 отрицательных примеров отклоняются.
- Хеши 61 vendor-файла совпали с manifest внутри комплекта. Это проверка целостности пакета, не независимая сертификация происхождения каждого XSD.
- Дополнительный DISAGGREGATED 1→2 проходит XSD, но отклоняется выбранными правилами валидатора.
- Savings назначил несовместимый тип ТС при заданном жёстком окне 0–1 мин и обслуживании 30 мин; сообщил ноль нарушений и длительность 0. В ветке _can_add нет проверки типа и окон.
- Заказ с нулевой координатой пропал и из маршрутов, и из unassigned. Для NIKORA неизвестный адрес должен попадать в исключения.
- Повтор apply одного plan_id дважды вызвал создание рейса дважды в fake-gateway. Инъекция ошибки назначения произошла после вызова создания. Это проверка оркестрации, не запись в Oracle.
- OR-Tools в доступном Python не установлен. В _solve_ortools статически найдено обращение к неопределённому n_orders; реальный OR-Tools путь не запускался. Нельзя считать его прошедшим тест.

API 127.0.0.1:8088 не ответил за ограниченный probe. Live Oracle, UI, нагрузочные сценарии и реальные адаптеры NIKORA не проверены. Последние найденные локальные API-audit файлы — июнь 2026, поэтому их показатели нельзя выдавать за сентябрьский замер.

Новых SQL при offline-проверке нет. Slow-SQL review: неприменим к этому запуску; для следующих живых gates обязателен [[runbooks/slow_sql_review]]. Исторические результаты в status wiki не перезапускались.

## Проверка внешнего стандарта

[Официальная страница GS1 XML](https://www.gs1.org/standards/edi/gs1-xml) подтверждает семейство сообщений и независимость от технического транспорта. В NIKORA фиксируется 3.6.0 как выбранная версия контракта, не как «последняя». Пользовательские n:* и их ограничения — решения профиля NIKORA, не универсальные требования GS1. Прямое открытие release URL через веб-инструмент было недоступно; содержимое поставленных XSD проверено локально.
