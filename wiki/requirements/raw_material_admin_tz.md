# Техническое задание: страница администрирования сырья

Дата: 2026-05-17.

Статус: проектирование.

## 1. Назначение

Страница `Сырьё` в админке WMS должна быть отдельным рабочим экраном для управления сырьевыми SKU, складами сырья и остатками сырья на выбранных складах.

Экран не должен быть частью главной страницы. Это отдельный модуль администрирования с собственными правами доступа.

## 2. Основная структура страницы

Страница состоит из трех связанных рабочих зон:

1. `SKU сырья`
   - список артикулов, которые могут использоваться как сырьё;
   - карточка настройки выбранного SKU;
   - признаки ветеринарного учета, партии, сроков годности и производственного применения.

2. `Склады сырья`
   - список складов, у которых включен флаг `RAW_MATERIAL`;
   - склад может иметь и другие роли, но для этой страницы показывается именно сырьевая роль;
   - выбор одного или нескольких складов управляет отображением остатков.

3. `Остатки сырья`
   - остатки по выбранным SKU и складам;
   - разрезы: склад, ячейка, паллета, партия, срок годности, доступный остаток, резерв, статус качества;
   - фильтрация по артикулу, партии, складу, сроку годности и статусу.

## 3. SKU сырья

Для каждого сырьевого SKU нужно хранить и отображать:

- артикул;
- наименование;
- единицу учета;
- признак `является сырьём`;
- сырьевую группу;
- признак необходимости учета в ФГИС `Меркурий`;
- признак обязательной партии;
- признак обязательного срока годности;
- нормативный срок годности;
- минимальный остаток;
- целевой остаток;
- допустимые склады сырья;
- допустимые зоны хранения;
- комментарий технолога или склада;
- активность.

## 4. Склады сырья

Склад попадает на страницу, если у него включен флаг `RAW_MATERIAL`.

Для склада нужно показывать:

- код и название склада;
- роли склада;
- признак MES-доступности;
- ячейку приемки по умолчанию;
- ячейку выдачи в производство по умолчанию;
- количество ячеек;
- количество паллет;
- суммарный остаток;
- доступный остаток без резервов;
- комментарий.

Один склад может одновременно иметь роли `RAW_MATERIAL`, `PRODUCTION`, `PRODUCTION_BUFFER`, `FINISHED_GOODS`; страница `Сырьё` должна использовать только сырьевую роль.

## 5. Остатки сырья

Остатки отображаются после выбора склада или группы складов.

Минимальные поля:

- склад;
- ячейка;
- паллета;
- артикул;
- наименование;
- партия сырья;
- ВСД/Меркурий, если применимо;
- дата производства;
- срок годности;
- количество;
- единица учета;
- резерв;
- доступно;
- статус качества;
- дата последнего движения.

Важно: новая страница не должна напрямую менять старые таблицы остатков WMS. Все изменения остатков должны идти через существующий механизм WMS-движений или отдельные согласованные процедуры.

## 6. Права

Нужны отдельные права:

- `raw_material_view`: просмотр страницы;
- `raw_material_edit`: изменение настроек сырьевых SKU;
- `raw_material_stock_view`: просмотр остатков;
- `raw_material_export`: выгрузка списка и остатков.

Названия прав не должны отображаться на рабочем экране пользователя.
Однако должна быть настройка в блоке, который управляет пользователями, чтобы он мог редактировать данные поля. 

## 7. API

Минимальные endpoints:

- `GET /api/raw-material/skus`
- `PATCH /api/raw-material/skus/{articul}`
- `GET /api/raw-material/warehouses`
- `GET /api/raw-material/remains`

Фильтры для остатков:

- `articul`
- `ware_id`
- `cell`
- `batch_no`
- `expiry_from`
- `expiry_to`
- `quality_status`
- `only_available`

## 8. UI

Рабочий экран должен быть плотным и операционным:

- сверху фильтры;
- слева или сверху список SKU;
- рядом список сырьевых складов;
- основная нижняя/правая зона: остатки;
- без технических строк с названиями прав и без поля `API base`;
- действия доступны или скрыты по правам, но сами названия прав пользователю не показываются.

## 9. MVP

Первый этап:

- создать RAW-страницу `raw-material.html`;
- добавить пункт меню `Сырьё`;
- показать список сырьевых SKU;
- показать список складов с флагом `RAW_MATERIAL`;
- показать остатки по выбранным складам;
- подключить права просмотра.

Второй этап:

- редактирование настроек сырьевых SKU;
- экспорт;
- фильтры по партии, сроку годности и статусу качества;
- связь с Mercury VSD.
