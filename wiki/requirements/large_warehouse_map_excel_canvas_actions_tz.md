## 1. Цель

Нужно расширить управление canvas-картой склада по аналогии с Excel: оператор должен быстро находить основные действия, понимать их по иконке и тексту, и иметь одинаковый доступ к каждой функции:

- в левом меню экрана;
- в контекстном меню внутри подходящего дерева.

Это правило вводится как обязательное для текущего экрана:

```text
Каждая рабочая функция имеет два входа:
1. действие в левом меню;
2. дубликат в context menu в соответствующем дереве.
```

Если функция пока будущая, она может отображаться в сером/заштрихованном виде с tooltip, но не должна выглядеть рабочей.

## 2. Обязательное Текущее Изменение

На экране должна быть явная кнопка:

```text
Сохранить канвас
```

Назначение:

- сохраняет текущий canvas/draft payload выбранного склада в Oracle;
- если API draft еще не создан, команда создает draft автоматически;
- пишет состояние canvas в DB-backed модель склада;
- не публикует topology/route автоматически.

Где должна быть команда:

- левое меню: подраздел `Действия`;
- context menu: `Действия -> Сохранить канвас`;
- блок Oracle workflow может также содержать эту команду, но подпись должна быть понятной оператору, а не только `Save canvas DB`.

Иконка:

- `💾` / diskette / save icon.

## 3. Дерево Контекстного Меню

Минимальная структура:

```text
Действия
  Сохранить канвас

  Сохранить route
  Опубликовать Oracle

Камера
  Создать камеру
  Клонировать камеру
  Архивировать камеру
  Связать камеры

Отбор
  Полноразмерный отбор
  Дробление 2/1
  Дробление 2/2
  Дробление 2/3
  Дробление 3/1
  Дробление 3/2
  Дробление 3/3
  Дробление 3/4
  V/G...

Хранение
  Полноразмерное хранение
  1 / без дробления
  2 по горизонтали
  3 по горизонтали

Формат
  Скопировать формат
  Вставить формат
  Отменить кисть

  LINEAR

  П-образно
```

Пункты верхнего уровня открывают боковое подменю по hover и по click.

## 5. Приоритет Реализации

### P0

- `Сохранить канвас` в левом меню и context menu.
- Единое правило: каждая функция имеет левое действие и context-tree действие.
- Undo/redo, copy/paste format, find, zoom, filters, role fill.
- Validation/conditional highlighting для ошибок карты.

### P1

- Clear selected area.
- Replace role in selected area.
- AutoFill адресов и route sequence.
- Counters/Σ для выделения.
- Sort/filter списков route rows, камер, slots.

### P2

- Print/export canvas.
- Insert/delete aisle/row/column with validation.
- Command palette / formula-like generation.
- Pivot-like warehouse summary.
- Chart/report for map completeness and validation problems.

## 6. Критерии Приемки

- Команда `Сохранить канвас` видна без долгой прокрутки.
- Та же команда доступна в `context menu -> Действия`.
- Каждая новая рабочая функция имеет запись в левом меню и в context menu tree.
- Иконка соответствует Excel-подобной метафоре и не заменяет tooltip/help.
- Disabled команды объясняют причину недоступности.
- Context menu не превращается в длинный плоский список: вложенные группы открываются боковым flyout.
- После сохранения canvas warehouse state reload показывает сохраненный canvas для выбранного склада.
