# NICORA: задание на доработку

Минимум 80% ресурсов на функционал. Дополнительные тестовые прогоны остановлены. Задание — один законченный сценарий на существующем коде.

- Требование: исходный пункт редакции 57; постоянный ID NS01 назначается по ходу функции.
- Уже есть: текущие файл/метод, таблицы, установленный Oracle-контракт и границы найденного.
- Доработка: конкретное действие пользователя и сохранённый результат.
- Изменения: обычно 3–8 связанных implementation файлов; module owner, публичный контракт, единственное место правила, transaction owner.
- Совместимость: прежние документы/остатки/идентификаторы, права и состояния.
- Маркировка: применимость по SKU/профилю, точные единицы и агрегации без двойного количества.
- Результат: функционал, инструкция действия и ограничения. Не заменять функцию расширением стенда/аудита/тестов.

Сохранённые сценарии описывают ожидаемое поведение; новые прогоны не назначаются автоматически. Нагрузки/recovery/pilots — после рабочего функционала. GitHub только по прямому поручению.
