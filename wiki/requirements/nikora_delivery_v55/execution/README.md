# NICORA: исполнение доработок существующего кода

Редакция 5, 7 октября 2026 года. [Источники утверждены владельцем](../../../sources/nicora_code_baseline_proposal_20261007.md). [Анализ WMS/TMS](../../../components/nicora_approved_code_analysis.md) — основа карточек. Сохранены 68 ID и 363 сценария, включая маркировку редакции 57. Сценарии не объявлены пройденными.

Минимум 80% ресурсов на функционал; дополнительные тесты и Oracle-эксперименты остановлены. Старые test-first/model gates не возобновлять вопреки этому поручению. Выполняются доработки существующих WMS/TMS в RABAEV.

[Основной план NI01–NI08](../implementation_plan.md) · [Каталог NS](../sprint_plan.md) · [Порядок](schedule.md) · [Метаданные](execution_plan.json) · [Контракты](interfaces.json) · [Режим проверок](test_contract.md).

Текущая очередь — основной план revision 10: NI01 baseline с пробелами; NI02 manual SAP–СТ bridge реализован; следующая функция NI03 — товарные эффекты существующих заданий. NI04 завершает существующую вложенность SSCC. Карточки NS сохраняют требования/363 сценария; старые порядки не запускаются автоматически. NS01–NS04 ведутся с функцией, NS05 отложен.

В карточке: существующие исходники, изменение и сохраняемый бизнес-результат. Перед изменением дочитать реальный путь; наличие метода не выдаётся за готовность NICORA. Постоянные ID требований назначаются NS01 по ходу функции. Старые часы/бюджеты/календарь сохранены в архиве plan_before_reuse и не являются текущими оценками.
