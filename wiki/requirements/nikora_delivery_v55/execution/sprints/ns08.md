## Конкретная доработка

Использовать gateway.transaction с общим cursor для составной команды; убрать отдельные commit и защитить повтор адресно.

## Сохраняемый бизнес-результат

Общая транзакционная граница для составных команд, ключ операции, сверка после тайм-аута; Атомарность товарного эффекта, состава кодов, истории и обязательств каждой системы

## Реализация

Дочитать изменяемый сценарий. Использовать существующие документы, таблицы, API и экраны. Реализовать одну связанную функцию, показать действие пользователя и сохранённый результат. Новая логика — в предметном модуле с явной транзакционной границей; данные — RABAEV. Не переписывать готовую подсистему и не перестраивать соседний код.

Зависимости: NS04. NS01–NS04 ведутся вместе с функцией; завершение всего проекта анализа не является prerequisite.

## Требования к результату

Исходные сценарии сохранены полностью. Перечисление не означает назначения новых прогонов или прохождения проверок.

### NS08-TC01

Исходные данные: K1

Действие: Выполнить дважды

Результат: Остаток 7, один факт отбора 3

### NS08-TC02

Исходные данные: После commit потерян ответ

Действие: Повторить K1

Результат: Возвращён первоначальный результат, остаток 7

### NS08-TC03

Исходные данные: До commit авария

Действие: Восстановить

Результат: Остаток 10, частичного факта нет

### NS08-TC04

Исходные данные: V1 устарела

Действие: Отправить изменение

Результат: Конфликт, новая версия и остаток не перезаписаны

### NS08-TT01

Исходные данные: Одна единица, два параллельных отбора

Действие: Подтвердить оба запроса

Результат: Успешен один допустимый отбор; единица и количество не использованы дважды

### NS08-TT02

Исходные данные: Операция с несколькими профилями

Действие: Вызвать отказ перед сохранением outbox; затем повторить успешный факт

Результат: Нет частичного эффекта; после успеха один товарный факт и по одному обязательству применимой системе

Маркировка редакции 57 сохраняется для применимых SKU: табак, CRPT/Честный знак, ЕГАИС и другие профили. Одна физическая единица с несколькими профилями не увеличивает товарное количество.
