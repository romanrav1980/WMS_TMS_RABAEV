# F2.2. Начальник склада: смена и назначения

Дата: 15.09.2026. Статус: DRAFT к реализации, не выполнено. Тип: functional; родитель прежнего плана: F2.2. Обязателен [[requirements/nikora_sprint_contract]]. Общий план: [[roadmap/nikora_agent_delivery_plan]].

## 1. Результат и границы

**Законченный проверяемый результат:** Начальник видит отстающую волну, назначает существующее задание и передаёт пополнение без имитации сборки.

Входит:

- Один экран UI-03 на существующих PICK_WAVE/resources: deadline, план/факт, контроль, дефицит.
- Переиспользовать существующие launch/assign/short commands, добавить только недостающие read fields.
- Таблица/детали и оперативная доска на одной проекции; никаких новых физических команд.

Не входит: Локальному агенту нельзя менять миграции, права на сервере и semantics launch; при нехватке API выделить H-ticket из резерва.

Зависимости для READY: [F2.1](f2-1.md), [A3.2](a3-2.md). Требуются решения бизнес-владельцев и реальные контрагенты/устройства, указанные ниже. BLOCKED/CONTRACT_READY не превращается в ACCEPTED по эмулятору.

## 2. Интерфейс и данные

Reuse wave/resource GET + existing launch/assign; read fields: deadline, pickedQty, missingQty, qualityStatus, readyToShip, actor/resource. Новая команда backend не входит в local scope.

Все новые URL/имена — предложение к согласованию с действующим API, не описание уже реализованного endpoint. Любая write-команда сохраняет expectedVersion, correlation и аудит. Контракт не ослабляется ради удобства UI.

Точки расширения (перед ticket выбрать точный allowlist, не переписывать папку целиком):

- wiki-raw/wms_admin_ui_reference/shift-supervisor-wave.html (образец)
- admin/wms_admin_frontend/src/components/
- tests/ui/
- tests/nikora/

## 3. Ограниченные шаги реализации

1. L1: таблица смены и индикаторы из утверждённого API.
2. L2: детали/доска и существующие действия.
3. T3: независимый UI/rights/contract regression.

Каждый шаг — отдельный handoff с patch/test evidence. Local подзадачи только по готовому контракту; изменение инварианта/миграции переводится в H/X. Максимальный scope и stop-rule — в общем контракте.

## 4. Проверки и критерий приёмки

1. view/edit rights, concurrent assignment conflict, stale/empty/error.
2. Сборка 100% при HOLD не отображается как readyToShip.
3. Регресс текущего launch/assign API; изменение его инвариантов эскалируется H.

Дополнительно обязательны права/дубли/ошибка связи/конкурентная версия, legacy regression и SQL review по общему контракту. Приёмку подтверждают независимый reviewer и владелец сценария; авторский summary недостаточен.

Целевые test artifacts после реализации: tests/nikora/test_f2_2.py и, если UI входит в scope, tests/ui/nikora_f2_2.cjs; плюс Oracle verify SQL и reports/nikora/F2.2/<run>/. Это **планируемые** файлы, их наличие/прохождение сейчас не заявляется.

## 5. Кто программирует и тестирует

Профиль **L — Локально, облачная приёмка**.

- Основной исполнитель: Aider + Qwen2.5-Coder-14B Q4 / Qwen3-Coder-30B Q4.
- Независимая проверка/тесты: Codex GPT-5.6 Terra medium + pytest/Playwright.
- Локальные помощники: только утверждённые механические/изолированные patches и fixtures. Детерминированные pytest/Playwright/SQL runner не расходуют LLM-токены сами по себе.
- Установка и параметры: [[runbooks/nikora_agent_launch]]. Для решения нового класса сначала S0/shadow test, затем повторное использование профиля.

## 6. Время и стоимость — оценка, не обещание

Рабочие дни: **2 / 3 / 5** (нижняя / базовая / верхняя оценка). Базовое окно в последовательном плане: дни **60–62** от готовности ресурсов. Внешнее ожидание не включено. Спринт включает создание тестов, review, исправления и техническую приёмку.

Ориентиры: 12.00 агент-часов (включая tool/test ожидание), 10.00 локальных server-hours, 8.00 часов техлида/QA. Эти часы **не суммируются** в календарную длительность: часть работы идёт параллельно, время людей уже учтено в базовых днях.

| Роль | Модель | Вход, млн | Выход, млн | API $, базовая cache-модель |
|---|---|---:|---:|---:|
| узкие правки и тестовые fixtures | Локальная Qwen | 4.000 | 0.400 | 0.00 |
| независимый обзор и приёмочные тесты | gpt-5.6-terra | 0.600 | 0.060 | 1.32 |

**API: $1.32**. Локальное электричество: $0.80. **Денежные расходы всего: $2.12; бюджет с резервом 50%: $3.18.** Консервативный вариант без cache hits, с платной записью cache и тем же резервом: $4.53.

Параметры: 60% cache read / 15% cache write / 25% uncached; токены указаны суммарно по всем сессиям этого спринта, не размер одного контекста. Output включает оплачиваемое рассуждение, если провайдер его учитывает. Смета API Standard, без подписок/налогов/инструментальных cloud fees/внешних подрядчиков. Ваше время показано в часах, без перевода в доллары. Для локальной модели учитывается только электричество; покупка и амортизация не учитываются. Цены и формулы: [[roadmap/nikora_agent_delivery_plan]]; исходные данные [budget.json](../../../wiki-raw/nikora_agent_plan_20260915/budget.json).

## 7. Условия остановки и передачи

Остановить ticket при повторяющемся дефекте, выходе за контракт/allowlist, нарушении баланса/прав, отсутствии обязательного внешнего факта или исчерпании бюджета. Не ставить зелёный статус и не менять тест под ошибочный код. Handoff: сделанное, diff, failing case, израсходованные токены/деньги, следующий ограниченный шаг. Новый функционал сверх scope — отдельная карточка с пересчётом.
