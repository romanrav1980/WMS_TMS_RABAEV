# NI04.3: принадлежность сканов задания

14 октября2026. [Отчёт](../../reports/retailcase/2026-10-13/codex/NI043/report.md).

Существующая общая admin/ТСД панель warehouse-task-scans.js теперь связывает каждый запрос с API base/actor/task/generation. Поздние ответы не меняют новый экран. draftId проверяет актуальную принадлежность и отсутствие pending; для ТСД проверка действует даже без события выбора.

Сохранение использует прежний серверный scan-draft и actor/task проверки. Exact-ID ответ, readback локального intent и повторное чтение контекста/набора предшествуют выдаче подтверждённого draft. Смена пользователя очищает видимую форму, не уничтожает старый запрос. Нового товарного writer нет.

Шесть моделируемых browser race/recovery кейсов PASS. Реальные GET564 HTTP200, SQL17–77мс, безDDL/товарных записей. Физический scanner и реальный lost-response POST отдельно; quality/encoding принимает ведущий.
