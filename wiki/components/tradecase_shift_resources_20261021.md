## Проверка доступа

До исправления сотрудник без доступа к собственнику не мог открыть CASE1159, но видел его в Ганте. Чтение CASE для Ганта теперь использует тот же native predicate, что карточка задания. Фильтр применяется в SQL до ограничения страницы. Новых правил доступа и миграций нет.

На Oracle RABAEV/orcl проверены четыре состояния: отсутствие доступа к собственнику скрывает задание в обоих экранах; выдача просмотра открывает оба; отзыв снова скрывает; отзыв складского назначения возвращает403. Тестовый пользователь отключён, назначение и доступ к собственнику отозваны. Остаток склада219023232 сохранён:10штук, HARD0; INVALID0.

## 22.10: рабочая смена вместо демонстрационного экрана

В кнопках «Панель смены» обнаружен переход на raw shift-supervisor-wave.html с фиксированным массивом этапов. Эти переходы из карточек волны, рисков, восстановления запуска и рабочего места директора теперь открывают настоящее рабочее место со складом и wave_id. Общий адаптер ссылок распознаёт прежнее имя экрана; сам демонстрационный источник не переписывался.

Переход выполняется внутри приложения через history/popstate: полная перезагрузка в первой версии теряла вход, и проверка это обнаружила. Теперь роль рабочего места и выбор волны следуют за адресом без повторного входа. Адрес волны меняется при выборе/закрытии. Если волны нет в ограниченных списках PREVIEW/LAUNCHED, читается её существующий native header. В bulk shift-overview попадают только волны выбранного склада; другой склад или403 очищают выбранную карточку.

Две тестовые отгруженные волны603/604 штатно завершены через finish-execution и точный повтор. Native execution показывает DONE/completed=true, две APPLIED; оба склада0/HARD0. Доказательства: `runtime/test-evidence/tradecase/2026-10-22/T07/waves-before-finish.json` и `waves-finished.json`, `T10/shift-sql.json`. Это завершение конкретных волн, не всей программы.

Архивные DONE/CANCELLED вынесены в отдельный этап изометрической схемы. Они не получают предупреждения о подготовке нового запуска; карточка показывает сохранённое исполнение и понятное состояние вместо внутренних enum. Подсказка больше не обещает команды запуска/переназначения на обзорном экране.

`T10/wave-navigation-ui.json`:10проверок1440/390, реальный DONE604 вне активного списка, сохранение входа/склада/волны, переход директора, другой склад и fixture403. Ноль товарных POST/JSerrors; четыре READ ONLY overview POST. Полезная карточка1877/1846мс на локальном сервере, assetDqjEM9IM. Мобильный PNG перечитан. ### SQL и следующий шаг

Native header читает одну волну по PK; существующий overview остаётся bounded READ ONLY. Нового индекса для deep link не вводили. Но реальные переходы выявили повторные транзакции CASE queue1033–1417мс, recovery851мс, timeline502/872мс. `shift-sql.json` сохраняет последние20записей. Это длительность транзакций, не доказательство отдельного плохого SQL. Следующий Codex/T12 шаг — воспроизвести тот же CASE queue с фиксированными ware/scope/limit, разделить SQL/права и проверить план; затем сравнить равные результаты до/после. Скорость этих очередей ещё не исправлена.
