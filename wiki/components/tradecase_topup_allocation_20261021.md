# СНС/BLC: распределение свободного места

В карточке рейса диспетчер добавляет снимки потребностей получателей и задаёт их порядок стрелками. Кнопка «Распределить место» сверяет основной подвоз в каждом снимке с заказами выбранного рейса. Затем расчёт выделяет место под целые короба последовательно по указанному приоритету. Экран показывает предложенное количество и непокрытый остаток каждого получателя.

Оператор указывает допустимый возраст снимков для расчёта. Устаревшие данные, повтор получателя/товара, несовпадение основного подвоза, выезд вне периода и начатая погрузка останавливают расчёт. Для разных геометрий коробов результат не выдаётся без подтверждённой схемы размещения. Основные заказы сохраняются.

Перед согласованием диспетчер должен проверить пригодный запас отправителя, маршрут, укладку и сроки доставки. Этот экран не создаёт заказ SAP, не резервирует запас или вместимость и не согласует добивку. T08/T09 остаются частично выполненными.

## Техническое приложение

POST `/api/tradecase/warehouses/{warehouse}/trips/{trip}/topup-preview` выполняет одну Oracle READ ONLY транзакцию. Вход:1–20уникальных `need_ids` в порядке приоритета и явный `max_age_minutes`1–1440. Существующие читатели потребности/вместимости используют те же выделенные функции; права склада/собственника проверяются до выдачи расчёта. Новых таблиц/DDL нет.

В результате сохранены версии рейса/заказов/профиля/снимков, подпись входов и флаги отсутствия физического исполнения/approval/заказа. Подпись учитывает порядок, геометрию и массу упаковок; меняющийся возраст отображается отдельно. Она не является разрешением на отгрузку.
