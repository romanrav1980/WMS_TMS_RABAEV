# Выработка: два подтверждённых временных знаменателя

15.10.2026. Владелец утвердил два варианта: фактическая сборка без явно зарегистрированных пауз и фактическая смена с паузами. На каждом основании показываются отдельные строки/час и коробки/час. [[../concepts/retailcase_kpi_passports_20261015]].

## Реализованная граница

Модуль resources/domain/picker_time_denominators.py предоставляет чистый расчёт через resources/public.py. Вход — один оператор, aware окно отчёта, явный as_of, подтверждённые WORK/PAUSE/ACTUAL_SHIFT интервалы и отдельное подтверждение полноты каждого потока на том же снимке. Эти данные должен предоставить проверенный серверный адаптер; операторский флаг confirmed не является доказательством.

- Времена нормализуются в UTC до сравнения/вычитания. Проверяется несуществующее локальное время; интервалы полуоткрытые, дубли/пересечения объединяются.
- Сборка — union(WORK) минус union(PAUSE). Смена — union(ACTUAL_SHIFT), паузы остаются. Подтверждённая внеплановая сборка не исчезает из-за отсутствующей записи смены: знаменатели независимы.
- Расчёт ограничен окном отчёта и as_of. Будущая часть не считается; возвращается effective_window. Максимум366дней/5000интервалов/5000свидетельств полноты.
- Нужна полнота WORK и PAUSE для сборки; отдельная полнота ACTUAL_SHIFT для смены. Явно подтверждённый пустой PAUSE поток отличается от отсутствующих сведений о паузах.
- При неизвестном времени возвращается NO_DATA/hours=null с причиной; при доказанной нулевой длительности также не выполняется деление. AVAILABLE содержит целые микросекунды и Decimal часы. Версия формулы PICKER_TIME_V1.
- Один fact_id с разными данными, чужой оператор, naive время, неподтверждённый интервал и превышение границ отклоняются.

## Проверки и ограничения

24 focused unit cases и независимый тест100 наборов интервалов против дискретного секундного эталона PASS. Ночь, оба DST перехода, повтор одного физического интервала в разных offset, перекрытия, паузы, пропуски полноты и as_of проверены. Это offline software evidence; SQL/товарных эффектов нет.

Runtime-адаптер подтверждённых aware интервалов ещё не реализован. Legacy heartbeat/online, план смены, APPLIED clock и интервалы между сканами не подставляются вместо фактического рабочего времени. Числители строк/коробок, атрибуция частичной сборки, KPI API и экран не реализованы этим модулем. Общий ресурсный Гант использует прежние источники, а не новый ledger времени.
