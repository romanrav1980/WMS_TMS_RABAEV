# Простое решение и стоимость разработки

16.10.2026. После замечания владельца о лишней публикации справки через API.

Для обычной пользовательской инструкции по умолчанию использовать файл и
стабильную локальную ссылку. Не добавлять API-запись, таблицы или отдельный
процесс публикации только потому, что такой механизм уже есть в проекте.

Перед усложнением назвать конкретное требование, которое простой вариант
не выполняет: например, редактирование из приложения или ограничение доступа.
Если такого требования нет, реализовать простой вариант. Существование
редактора знаний не делает его обязательным для каждой инструкции.

Сохранять локальные help_id, связи статей и действующие ограничения доступа.
Не открывать весь wiki произвольным URL. Переход к файловой справке не требует
удаления существующей истории Oracle или повторной публикации всех статей.

Историческая ошибка: инструкция консолидации прошла ARTICLE_SAVE/PUBLISH
и отдельные проверки API вместо выбора простой ссылки. История Oracle сохранена.

Следующий инкремент16.10 исправляет путь новой обычной справки: отдельная папка
docs/help/public, static `/help/manual-weight.html` и `/help/consolidation-plan.html`.
Оба URL live200, API-публикация не нужна. Существующий закрытый reader/editor
Oracle не подменяется файловой выдачей; весь wiki наружу не открывается.
