# Данные для тестирования NICORA

Все значения синтетические; использовать в production запрещено. base.json задаёт общий набор. nsXX.json содержит точные условия каждого сценария и ожидаемый результат; это декларативная фикстура, а не уже исполняемый SQL. Роль подготовки данных из карточки превращает её в загрузчик через реальный контракт стенда, проверяющий валидирует количество, единицы, партии и изоляцию.

Каждый сценарий начинается со своего чистого namespace DS-NSxx-TCyy. Повторы внутри сценария используют тот же ключ операции. После сценария сверяется баланс, затем очищается только этот namespace. Числа массы и денег в машинных данных представлены десятичными строками. Фото создаются как валидные тестовые файлы с контрольной суммой; физические испытания используют реальные снимки и измерения.

[Базовый набор](base.json). Схема seed/reset, API URLs и SQL-проверки закрепляются в NS00/NS04, а не угадываются из имён доменных команд.
