# NICORA: основания предложенного плана

7 октября 2026 года. Прочитаны проектные синтезы и перечисленные исходные файлы. Серверные команды, Oracle и модели в рамках подготовки плана не запускались. Статический просмотр не является полным GAP или актом готовности системы.

| Область | Основание текущего кода | Что проверяется в плане |
|---|---|---|
| Резервы | stock_reservation_service.py: create_reservation, promote_to_hard, release_reservation, consume_reservation | Свободный пул заказов, кратности дефицита, преобразование без двойного удержания и конкуренция волн — NS21, NS22, NS26 |
| Волны и пополнение | picking_service.py: create_wave, preview_wave, launch_wave, release_minimax_replenishment, очередь и get_wave_readiness | Управление транспортным заданием, совместный расчёт подач, полная обеспеченность и мониторы — NS25–NS33 |
| Задания | warehouse_task_service.py: assign_task, start_task, complete_task, cancel_task | Права, допущенный ресурс, безопасное переназначение, срочные цепочки и фактические движения — NS31, NS38, NS39, NS46 |
| Ресурсы | resource_management_service.py: сотрудники, оборудование, shifts, sessions, heartbeat | Один фонд времени, совмещение ролей, начало смен ричтраков и дежурные водители — NS30–NS33 |
| Транспорт | transport_service.py, vrp_solver.py, архитектурная карта ТМС-2 | Выполнимое задание на сборку, каталог вместимости, факты погрузки и многоплечевое движение — NS24, NS47, NS48, NS51, NS60 |
| Заказы | customer_order_service.py: заказы, адреса, import_legacy_order и fulfillment | Потребность ERP по правилам NICORA, исходные времена и запрет изменений — NS16, NS17; наличие production_exchange_service.py не доказывает розничный ERP-контракт |
| Oracle | db.py: пул max=12 на процесс; oracle_gateway.py: отдельные методы фиксации | Общий бюджет соединений и транзакционная граница составной операции — NS07, NS08 |
| Аудит | middleware/api_audit.py и api_audit_service.py: синхронные Oracle/JSONL-вызовы из async middleware | Устранение блокирования без потери обязательного аудита — NS07 |
| Обмен | outbox_worker.py, outbox_service.py: последовательный процессор и MockRegulatoryAdapter по умолчанию | Рабочий NICORA-контракт, надёжные повторы и восстановление исполнителя — NS09, NS10 |
| Рабочие места | package.json административного интерфейса и терминала: React/TypeScript/Vite, Playwright | Переиспользование имеющихся интерфейсов и проверка реального потока, а не картинок |
| Развёртывание | serv.bat: Uvicorn с reload; requirements.txt без закреплённых версий | Воспроизводимый промышленный запуск — NS06 |

Перечисление функции означает найденную основу, а не соответствие конкретному правилу редакции 55. После NS02/NS03 у каждого правила должны быть версия реализации, сценарий и фактическое доказательство. Прежние отчёты о прохождении транспортных тестов подтверждают прежние проверки, но не проверяют новые требования автоматически.
