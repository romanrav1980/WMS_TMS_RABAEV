# NS59. Рекомендации динамических диапазонов

Статус: предложен. Основание: требования редакции 55; уточнение состава после NS02–NS04. Предварительная оценка: 3–5 рабочих дней.

## Законченный результат

Статистика и прогноз без повторного спроса, расчёт количества ячеек, сравнение затрат отбора и пополнения, утверждение и вымывание старого диапазона.

## Вход и зависимости

[NS19](ns19.md), [NS33](ns33.md), [NS34](ns34.md), [NS58](ns58.md). До начала разработки фиксируются требования NK-Pxx-nnn/NK-Mxx-nnn, установленные NS01, версия кода, схема Oracle и исходные данные. Номера правил не придумываются исполнителем заново.

Бизнес-источники: [dynamic_slotting.md](../../nikora_business_processes/dynamic_slotting.md). Наличие кода в файле не означает соответствие. Исходные точки обследования: [oracle_gateway.py](../../../../api/wms_api_server/app/oracle_gateway.py), [db.py](../../../../api/wms_api_server/app/db.py); точный список разрешённых файлов устанавливается по GAP.

## Разработка и независимая проверка

## Проверяемое поведение

1. Дефицит не трактуется как нулевой спрос.
2. Рекомендованная ёмкость учитывает паллетную кратность.
3. Активные задания не меняются.
4. Новый диапазон пополняется лишь при недостатке старого.

Проверка проводится на API и Oracle; для рабочего места также через интерфейс. Независимый проверяющий заранее задаёт исходные количества и ожидаемые товарные балансы. Для изменяющей состояние команды проверяются права, дубликат, конфликт и прерывание между шагами.

## Условия приёмки

- Выполнены все конкретные случаи выше, результаты приложены к номеру требования.
- Проверены затронутые штатные сценарии и отсутствие регрессии.
- Oracle-изменения имеют SQL применения и проверки, актуальное описание схемы и проверку установленного стенда; SQLite не заменяет Oracle.
- Для API, SQL и функциональных испытаний разобраны самые долгие запросы и принято решение по каждому существенному отклонению. Для чисто документальной карточки этот пункт не применяется.
- Русские файлы прошли scripts/check-encoding.ps1.
- Рабочий результат показан владельцу; неизвестные ограничения записаны, обязательные условия не скрыты.

Тесты и пути evidence определяются до исполнения карточки; план не утверждает, что они уже существуют или пройдены.
