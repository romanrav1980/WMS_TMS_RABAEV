# NS20. Размещение и выбор источника пополнения

Статус: предложен. Основание: требования редакции 55; уточнение состава после NS02–NS04. Предварительная оценка: 2–4 рабочих дней.

## Законченный результат

Прямой отбор для подходящей партии, FEFO/FIFO с экспедицией приёмки, свободное хранение, приоритет высоты либо расстояния и допустимое удаление.

[NS19](ns19.md). До начала разработки фиксируются требования NK-Pxx-nnn/NK-Mxx-nnn, установленные NS01, версия кода, схема Oracle и исходные данные. Номера правил не придумываются исполнителем заново.

Бизнес-источники: [03_warehouse_receipt.md](../../nikora_business_processes/03_warehouse_receipt.md), [14_pickface_replenishment.md](../../nikora_business_processes/14_pickface_replenishment.md). Наличие кода в файле не означает соответствие. Исходные точки обследования: [picking_service.py](../../../../api/wms_api_server/app/services/picking_service.py), [stock_reservation_service.py](../../../../api/wms_api_server/app/services/stock_reservation_service.py); точный список разрешённых файлов устанавливается по GAP.

## Разработка и независимая проверка

Автор: **OpenAI Codex**. Подготовка приёмочных сценариев и независимая проверка: **Claude Code**. Владелец принимает результат. 

## Проверяемое поведение

1. Ранняя подходящая партия с приёмки выбрана раньше хранения.
2. Произвольное совпадение срока не меняет стратегию.
3. Неподходящий объём отклонён.
4. Назначенная подача учитывает вместимость.

Проверка проводится на API и Oracle; для рабочего места также через интерфейс. Независимый проверяющий заранее задаёт исходные количества и ожидаемые товарные балансы. Для изменяющей состояние команды проверяются права, дубликат, конфликт и прерывание между шагами.

## Условия приёмки

- Выполнены все конкретные случаи выше, результаты приложены к номеру требования.
- Проверены затронутые штатные сценарии и отсутствие регрессии.
- Oracle-изменения имеют SQL применения и проверки, актуальное описание схемы и проверку установленного стенда; SQLite не заменяет Oracle.
- Для API, SQL и функциональных испытаний разобраны самые долгие запросы и принято решение по каждому существенному отклонению. Для чисто документальной карточки этот пункт не применяется.
- Русские файлы прошли scripts/check-encoding.ps1.
- Рабочий результат показан владельцу; неизвестные ограничения записаны, обязательные условия не скрыты.
