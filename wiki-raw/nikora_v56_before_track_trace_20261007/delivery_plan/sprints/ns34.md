# NS34. Стеллажная комплектация и состав места

Статус: предложен. Основание: требования редакции 55; уточнение состава после NS02–NS04. Предварительная оценка: 3–5 рабочих дней.

## Законченный результат

Односторонний маршрут, скан SKU, источника и количества, этапы укладки, партия и фиксация состава по грузовому месту.

## Вход и зависимости

[NS32](ns32.md), [NS23](ns23.md), [NS19](ns19.md). До начала разработки фиксируются требования NK-Pxx-nnn/NK-Mxx-nnn, установленные NS01, версия кода, схема Oracle и исходные данные. Номера правил не придумываются исполнителем заново.

Бизнес-источники: [04_storage_replenishment_picking.md](../../nikora_business_processes/04_storage_replenishment_picking.md), [dynamic_slotting.md](../../nikora_business_processes/dynamic_slotting.md). Наличие кода в файле не означает соответствие. Исходные точки обследования: [picking_service.py](../../../../api/wms_api_server/app/services/picking_service.py), [stock_reservation_service.py](../../../../api/wms_api_server/app/services/stock_reservation_service.py); точный список разрешённых файлов устанавливается по GAP.

## Разработка и независимая проверка

Автор: **OpenAI Codex**. Подготовка приёмочных сценариев и независимая проверка: **Claude Code**. Владелец принимает результат. 

## Проверяемое поведение

1. Нет возврата назад.
2. Ошибка ячейки отклонена.
3. Изменение будущего слотирования не меняет выданное задание.
4. При смешении фактическая маркированная партия сохранена, неизвестная учётно списана со старой партии.

Проверка проводится на API и Oracle; для рабочего места также через интерфейс. Независимый проверяющий заранее задаёт исходные количества и ожидаемые товарные балансы. Для изменяющей состояние команды проверяются права, дубликат, конфликт и прерывание между шагами.

## Условия приёмки

- Выполнены все конкретные случаи выше, результаты приложены к номеру требования.
- Проверены затронутые штатные сценарии и отсутствие регрессии.
- Oracle-изменения имеют SQL применения и проверки, актуальное описание схемы и проверку установленного стенда; SQLite не заменяет Oracle.
- Для API, SQL и функциональных испытаний разобраны самые долгие запросы и принято решение по каждому существенному отклонению. Для чисто документальной карточки этот пункт не применяется.
- Русские файлы прошли scripts/check-encoding.ps1.
- Рабочий результат показан владельцу; неизвестные ограничения записаны, обязательные условия не скрыты.
