# Raw Sources

This directory is reserved for immutable or append-only source material used by the root wiki.

Examples:

- imported notes
- exported transcripts
- selected logs
- screenshots chosen as canonical evidence
- external documents copied for synthesis

Rules:

1. Do not rewrite raw sources during wiki maintenance.
2. The wiki may summarize, compare, and cross-link raw sources.
3. Existing repository files also count as raw sources when cited from the wiki.
4. If a raw source contains secrets, create a redacted copy before linking it from synthesis pages.
