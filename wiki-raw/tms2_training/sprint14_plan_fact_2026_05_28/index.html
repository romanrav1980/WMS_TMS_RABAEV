ТМС-2 Sprint 14: План-фактный анализ

Контроль отклонений по операциям рейса и экспорт результата.

Зачем этот блок

План-факт показывает, где транспортный процесс расходится с нормативом: погрузка, ожидание, отдых, разгрузка. Руководитель видит системные задержки и может менять процесс или нормативы.

Вход
Плановые и фактические времена операций рейса.
Процесс
Расчет дельт, подсветка отклонений, контроль нарушений отдыха.
Результат
Сводка по рейсам, таблица операций и CSV для разбора.

Структура данных

ОбъектПоляНазначение
Рейсtt_id, vehicle, status, total_delta_min, rest_violationsСводка исполнения.
Операцияduration_min, plan_start/end, fact_start/end, delta_minПлан-факт по шагу рейса.

Как работать

Бизнес-процессы

  1. Фиксация факта: операции получают фактическое начало/окончание.
  2. Контроль исполнения: система считает дельты по операциям и суммарно по рейсу.
  3. Контроль отдыха: нарушения режима отдыха поднимаются в строку рейса.
  4. Разбор причин: диспетчер/руководитель смотрит повторяющиеся задержки и корректирует процесс.
  5. Выгрузка: CSV используется как доказательная таблица для анализа.
