# NIKORA: кроссдокинг первым

Новый порядок исполнения: [план раннего выпуска](../../wiki/roadmap/nikora_crossdock_first.md). Планирование от 16.09.2026, не факт реализации.

plan.json хранит дни, зависимости, доли исходных карточек и приёмку. report.py пересчитывает затраты из снимка тарифов 15.09.2026 и проверяет покрытие всех 41 карточки остаточным backlog. Дополнительный ранний пилот учитывается отдельно; двойного сложения всей старой сметы с ранней частью нет.

Для локальных моделей учитываются только электричество и часы владельца. Покупка и амортизация исключены. Доли — предположение о трудоёмкости, а не доказанная экономия; после CD04 пересчитать по реальному accepted work.
