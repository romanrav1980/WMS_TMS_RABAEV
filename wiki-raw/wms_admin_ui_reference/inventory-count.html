Пересчёт конкретных партий

Загрузите ячейку, введите фактически измеренное количество отдельно для каждой паллеты и укажите причину. В обычном пересчёте проводятся изменённые строки. Для задания пустой ячейки подтверждаются все партии указанного артикула, включая неизменённые; отсутствие зарегистрированных партий подтверждается отдельно той же командой.

Резерв сохраняется. При недостаче ниже резерва сначала согласуйте его снятие. Для маркированного товара отсканируйте коды всех фактически найденных единиц. Их количество должно совпасть с пересчётом. Увеличение без подтверждённого состава недоступно.

После потери связи повторяйте сохранённую команду. До ответа сервера пересчёт не подтверждён.
