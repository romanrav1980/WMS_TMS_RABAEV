Пригодная тара для сборки

Потребность существующей волны

Прогноз самостоятельных CASE. Для вложенных мест закрепите тару верхнего контейнера; для FULLPAL явно выберите тип поддона. Ожидаемые возвраты не увеличивают доступность.

Закрепить физическую тару

CASE использует тип из существующего задания. Верхнее место — поддон, ролл-кейдж или самостоятельная товарная паллета FULLPAL. Для товарной паллеты выберите тип поддона. Вложенные коды не увеличивают количество закреплённой тары.

Закрепления

Освобождение допустимо только для пустого места, не погруженного в машину. Пригодная тара остаётся на складе; товарный остаток не меняется.
