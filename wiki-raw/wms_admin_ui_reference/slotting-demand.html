Потребность для диапазона

Сценарный расчёт по открытым заказам, пригодному старому запасу и назначенным подачам. Сам расчёт не меняет размещение и задания.

Заказы этого периода заменяют соответствующую часть общего прогноза. При отсутствии прогноза отображается только известный минимум. Заказы без даты показываются отдельно.

Маршрут ограничивает новые ячейки-кандидаты. Спрос, старый запас и прежний диапазон учитываются по всему артикулу на складе.

Рекомендация использует не более одной дополнительной целой паллеты на ячейку. Нормативы — ваши допущения для сравнения; геометрия и утверждение проверяются отдельно.

Предложение диапазона

Сохранение создаёт черновик с исходными данными и автором. Слотирование и действующие задания пока не изменяются.

Утверждение активирует новый диапазон. Старый остаётся для завершения прежних заданий и вымывания запаса; новые пополнения туда не назначаются.
