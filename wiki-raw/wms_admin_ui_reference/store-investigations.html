Расследование недостачи поставки

Назначение поиска

Срок задаёт диспетчер. Его наступление не списывает товар и не запускает новую доставку.

Результат назначенного расследования

Отчёт может записать только назначенный участник соответствующей роли.

Решение KRO

Требуются результаты экспедиции и безопасности. Решение относится к исходной недостаче; уже отгруженный товар не списывается со склада повторно.

Завершить разбирательство

Незавершённые количественные обязательства блокируют закрытие. Исходные документы сохраняются; запас повторно не изменяется. Решение принимает другой сотрудник.
