- Diff не выходит за разрешённые файлы и scope.
- Все критерии выполнены наблюдаемым поведением, а не названием функции/скриншотом заглушки.
- Негативные случаи, права, дубли, потеря ACK, устаревшие версии, параллельные операции.
- Денежные/товарные балансы, HU hierarchy, качество по contentVersion, реальные точки ERP-событий.
- Oracle-транзакция и outbox атомарны там, где это требуется.
- UI соответствует роли и количеству переходов; права проверяет сервер.
- Долгие SQL/SKV измерены в соответствующем gate; решение по каждой проблеме явно записано.
- Обязательные реальные интеграции/весы не подменены mock.
- Нет секретов, production-подключений, изменённых чужих файлов.

## Выход

Verdict: ACCEPT / REQUEST_CHANGES / BLOCKED_EXTERNAL.
Для каждого замечания: severity, файл/строка, воспроизведение, ожидаемое/фактическое, риск.
Перечислить реально выполненные команды и результаты, пропущенные gates, usage и время человека.
ACCEPT не разрешает автоматически merge/deploy и не означает завершения пилота.
