Операции: 
1) оприходование. Означает оприходование Беса брутто поддона (в кг.). Без веса поддона, без веса 
При изменении веса, меняется и количество товар в паллете.
При изменении количества товар в паллете, меняется и вес.

2) Списание.
3) Увеличение процента отхода по паллету, списку паллет.
4) Усушка ( уменьшение веса паллета  )

Отчеты:
) Товарный остаток без веса отхода, Вес отхода, итого.
)  

Сборка: 
1) Формирование сборочного листа, автоматическое формирование вычерков под контролем оператора
2) сборщик получает задание, начинает натаскивать паллет строго по сборочному листу.
при очередном изменении веса: 
Программа определяет сколько коробок доложили, фиксирует количесто коробок очередного 
товара.
3) Сборщик может поправить компъютер, указав, что последнее изменение веса соответствует другому 
артикулу
4) Проведение СТ:
	Для каждой строчки  СТ, проведение означает списание веса БРУТО (в кг.) 
	без веса поддона из ячейки отбора.
