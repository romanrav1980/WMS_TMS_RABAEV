# График поставок: интерфейс

Откройте приложение через штатный сценарий запуска проекта. На главной странице выберите нужное направление и откройте «График клиентов».

В графике можно выбрать неделю, найти адрес и отметить строки для работы. Для выделенных адресов доступны предложения частоты, дней, источника и минимальной партии. Дни можно проставить по факту выбранной недели.

В таблице показаны фактические и рекомендуемые дни. Расхождения и причины переговоров помогают проверить предложение. Полный текст причины отображается при наведении на ячейку.

Над таблицей расположен график недельной нагрузки. Сплошная линия показывает факт, пунктирная — прогноз. При нажатии открывается увеличенный график с днями недели и объёмами. Зелёный цвет обозначает равномерную нагрузку, красный — неравномерную. Звёздочка у факта обозначает неполные данные.

Статус рядом с заголовком показывает состояние сохранения. Для обмена данными доступны команды выгрузки и загрузки XML; таблицу можно выгрузить в Excel.
