# SNS — график поставок

Отдельный подпроект ТМС для анализа заказов СНС, плановых дат поставки, операций BLC и транспортировок.

В репозитории находятся исходный Python-сервис, веб-интерфейс, расчёты, отчёты, скрипты обмена и wiki-контекст проекта. Рабочие SAP-выгрузки, база, runtime и установочные архивы намеренно остаются локальными; правила публикации описаны в корневом `AGENTS.md`.

Основная документация:

- [Контекст передачи](wiki/TRANSFER_CONTEXT.md)
- [Источники и структура данных](wiki/sources.md)
- [Требования к выгрузке SAP](wiki/sap_export_requirements.md)
- [Развёртывание](wiki/deployment.md)

Локальный запуск выполняется через `start_sns.bat`.
