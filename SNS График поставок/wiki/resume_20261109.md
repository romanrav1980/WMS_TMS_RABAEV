# SNS «График поставок»: контекст для продолжения — 09.11.2026

## Проект и запуск

Рабочая папка: `C:\projects\TMS\SNS График поставок`. Это отдельный локальный подпроект, не WMS и не ТМС-2. Сервер `server.py` запускается через `start_sns.bat`, приложение: `http://127.0.0.1:4179/site/`. Сайт и логика находятся в `site/`, подготовленные исходные данные — в `data/`, база рекомендаций — `runtime/schedule.sqlite3`. Для деталей см. [перенос и запуск](deployment.md), [решения по интерфейсу](visualization_and_decisions.md).

## Текущий результат

- Окно графика поставок: выбор недели, факт и рекомендуемые дни, частота, партия и источник. Рекомендации сохраняются на сервере в SQLite; роль и защита от одновременной перезаписи пользователем не требуются.
- Факт календаря графика — дата окончания BLC. Плановые и фактические даты не сравниваются на предмет своевременности. При необходимости показываются ноябрьские даты.
- В меню «Дни» доступны автопредложение и замена выбранных строк фактическими днями выбранной недели. Попутчики определяются по совместным рейсам и району, их общий предел задаётся в шапке. При клике по фактическому объёму подсвечиваются все видимые общие рейсы того же города, независимо от района.
- Заполненная строка тёмно-зелёная; салатовая, если выбран хотя бы один день, которого не было в факте. Превышение выбранных дней относительно фактических отмечено оранжевым. Подробные критерии — в решениях по интерфейсу.
- В шапке раздельные прогнозы нагрузки по рекомендуемым хабам и филиалам; невыбранный или неуточнённый источник не учитывается. Экспорт таблиц в XLSX содержит цвета, шрифты и числовые значения.
- Кнопки выгрузки и загрузки базы используют XML: рекомендации обеих цепей и общая настройка. Импорт с подтверждением полностью заменяет эти данные; исходные операции и адреса в XML не входят. Код: `database_xml.py`, API `/api/database.xml`.

## Установщик

Последняя сборка после прямого поручения пользователя — `installer/SNS-Setup.exe`. Это автономный Windows x64 установщик с Python, SQLite, интерфейсом, подготовленными JSON и снимком базы на момент сборки. Он не содержит исходные Excel и не перезаписывает существующую базу при повторной установке. Установленная копия работает на `127.0.0.1:4379`. Проверены установка, повторная установка с сохранением базы и XML-перенос в установленной копии.

**Не пересобирать установщик автоматически при последующих правках приложения: пользователь попросил обновлять его только по отдельному поручению.** Последнее такое поручение выполнено 09.11.2026, до сохранения этого контекста.
