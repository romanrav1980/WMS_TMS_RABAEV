## Результат

Расширь существующий page=tradecase: «Запас» и «Поставки». Поток: поставка → проверить основание/состав → сканировать идентификатор паллеты → привязать собственника/МРЦ/срок к принятому товару → проверить запас и статус кодов. Не создавай второе приложение и не имитируй складскую операцию. Эта команда не принимает товар физически, не подтверждает СКМ, не выкупает товар. Не добавляй кнопку ручного подтверждения кодов: это API интеграционной службы.

Запас: серверные группы паллета/адрес/SKU/собственник/МРЦ/срок, количество и единица, резерв, подтверждено/ожидает/отклонено. Все количества десятичные строки, не округлять и не смешивать единицы. Итоги страницы не называть общим остатком склада. Один идентификатор может иметь несколько групп; не склеивать их, не считать число строк количеством паллет. По смыслу показывать имя товара/собственника из уже доступной НСИ; хеши и внутренние версии — в технических сведениях. Поле называется «Идентификатор паллеты», допускает legacy значения. При смене склада, 403 и отозванном доступе старые данные очищаются. Склад брать из capability=tradecase.

В поставке показывать документ, паллету, товар, собственника, МРЦ, партию/срок и размер состава. Сами коды/JSON скрыть в технических сведениях. В привязке брать supply_id и текущую версию из открытого документа, operator_id не спрашивать. Скан работает как клавиатурный ввод с Enter; перед записью показать конкретные данные и действие. Генерировать operation_id один раз для неизменного намерения. После потери связи сохранять тело и тот же идентификатор; повтор не должен становиться новой операцией. Пока результат неизвестен — не разрешать редактировать тело с прежним operation_id. Восстановление после перезагрузки привязывать к пользователю/складу; не воспроизводить намерение другого пользователя. Не хранить пароль. Сервер сам проверяет права; отказ 403 не заменять успехом.

Используй стиль текущего рабочего места, плотную desktop/390 раскладку и локальную справку с подсказкой каждой кнопки. В схеме процесса «Склад» может открывать реальный запас; не рисуй несуществующие координаты или фактические операции. Справка объясняет сканирование, подтверждение, неизвестный результат, отказ прав и статусы СКМ. Каждый абзац описывает действие или результат. Источники — действующая wiki/Google Docs по кейсу; RETAILCASE не смешивать.
