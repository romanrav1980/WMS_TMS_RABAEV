# Менеджер перевозчиков

`carrier_manager` · Транспорт · группа доступа (предложение): `RL_CARRIER`
Область назначения: перевозчик · устройства: desktop · рабочее место: **основного экрана нет**

## 1. Место в организации

- **Руководитель:** Директор транспорта
- **Подчинённые роли:** —
- **Заместитель:** Ответственный за автопарк и ремонт
- **Передача смены / замещение:** Открытые претензии и договоры.
- **Эскалация:** Директору транспорта — конфликт с перевозчиком.

**Отвечает за:**
- Перевозчики, договоры, закрепление машин/водителей

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Новый перевозчик
- Претензия

**Решения:**
- Подключить перевозчика

**Сценарии:**

1. *обычный* — **Подключение.** Карточка перевозчика → машины → водители.
2. *дефицит/конфликт* — **Претензия.** Расходы и доплаты по рейсам перевозчика.
3. *отказ/потеря связи* — **Нет модуля.** Решения вне системы до реализации.
4. *передача* — **Передача.** Претензии.
