# Оператор SAP и документов

`sap_doc_operator` · Складское исполнение · группа доступа (предложение): `RL_SAP_DOC`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Руководитель складских операций
- **Подчинённые роли:** —
- **Заместитель:** Специалист интеграций
- **Передача смены / замещение:** Незагруженные файлы шлюза и поставки без основания передаются с причиной.
- **Эскалация:** Специалисту интеграций — ошибки шлюза/outbox; старшему приёмки — поставка изменена после начала приёмки.

**Отвечает за:**
- Загрузка ARTMAS10, поставок, заказов магазинов, решений и возвратов SAP через файловый шлюз
- Контроль, что приёмка идёт только по разрешённому основанию

**Не вправе:**
- Не принимает паллеты
- Не правит справочник SKU вручную вне ARTMAS

## 2. События, решения, смена

**Смена:** Дневная; пик — до отсечки заказов сети.

**Входящие события:**
- Новый файл в шлюзе
- Ошибка разбора файла
- Поставка изменена после начала приёмки

**Решения:**
- Повторить загрузку исправленного файла
- Отклонить файл с причиной

**Сценарии:**

1. *обычный* — **Поставка SAP.** Файл поставки → импорт → поставка доступна приёмке; заказы магазинов → заказы клиентов.
2. *дефицит/конфликт* — **Изменение поставки после начала приёмки.** Принятые паллеты не меняются; расхождение уходит в сверку старшему приёмки.
3. *отказ/потеря связи* — **Файл не разобран.** Ошибка с кодом строки; повторная загрузка идемпотентна по идентификатору сообщения.
4. *передача* — **Конец дня.** Список незагруженных/отклонённых файлов с причинами.

## 4. UI

- **Первый экран:** Входящие сообщения шлюза за день: тип, статус, ошибки
- **Главное действие:** Повторить загрузку исправленного сообщения
- **Таблица:** Сообщение · тип · получено · статус · ошибка · объект
- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Импорт идемпотентен по идентификатору сообщения
