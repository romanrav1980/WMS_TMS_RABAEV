# Управляющий магазином

`store_director` · Магазины · группа доступа (предложение): `RL_STORE_DIR`
Область назначения: магазин · устройства: планшет, телефон, desktop · рабочее место: **основного экрана нет**

## 1. Место в организации

- **Руководитель:** Региональный руководитель магазинов
- **Подчинённые роли:** Приёмщик магазина
- **Заместитель:** Приёмщик магазина
- **Передача смены / замещение:** Открытые кейсы и возвраты магазина.
- **Эскалация:** Региональному руководителю — повторные расхождения; диспетчеру — опоздание.

**Отвечает за:**
- Приёмка поставки магазином (ТЗ процесс 10) — ответственный
- Утверждение потерь по кейсам своего магазина
- Утверждение возвратов магазина

**Не вправе:**
- Не утверждает потерю по акту, который подписал сам

## 2. События, решения, смена

**Смена:** Рабочее время магазина.

**Входящие события:**
- Поставка принята с расхождением
- Кейс расследования
- Возврат к вывозу

**Решения:**
- Утвердить потерю
- Утвердить возврат

**Сценарии:**

1. *обычный* — **Поставка без расхождений.** Акт приёмщика с водителем; управляющий видит итог.
2. *дефицит/конфликт* — **Недостача.** Кейс: расследование РЦ → решение о потере (store_loss_confirm).
3. *отказ/потеря связи* — **Нет связи в магазине.** Акт сохраняется на устройстве водителя/приёмщика до подтверждения.
4. *передача* — **Замещение.** Временное назначение приёмщику с ограниченным сроком.

## 3. Рабочее место

| Раздел | Пункт | Источник / команда |
|---|---|---|
| Главная | Поставки моего магазина | **GAP** — рабочего места магазина нет (акт сейчас в странице водителя) |
| Очереди и приоритеты | Кейсы магазина | `GET /api/delivery/case-work/mine` |
| Очереди и приоритеты | Возвраты магазинов | Возвраты магазинов (`store-returns.html`) |
| Фильтры | Дата | **GAP** — нет |
| Карточка объекта | Кейс | `GET /api/delivery/case-work/mine` |
| Допустимые команды | Утвердить потерю | `POST /api/delivery/case-work/{case_id}/loss` · право `store_loss_confirm` · вход: кейс, решение о потере · результат: потеря утверждена · повтор: operation_id обязателен в теле: при потере ответа — повтор тем же operation_id и телом; отдельной GET-квитанции нет, исход также виден чтением объекта |
| Допустимые команды | Утвердить возврат | `POST /api/delivery/store-returns/{receipt_id}/approve` · право `store_return_approve` · вход: возврат магазина · результат: возврат утверждён к вывозу · повтор: operation_id обязателен в теле: при потере ответа — повтор тем же operation_id и телом; отдельной GET-квитанции нет, исход также виден чтением объекта |
| История и документы | Акты | **GAP** — чтение актов магазина нет |
| Уведомления и эскалации | Новый кейс | **GAP** — нет |
| Отчётность | Расхождения магазина | **GAP** — нет |

## 4. UI

- **Первый экран:** Сегодняшние поставки и открытые кейсы
- **Главное действие:** Решить кейс
- **Таблица:** Поставка · рейс · мест · расхождение · кейс
- **Массовые операции:** Нет
- **Ввод:** Планшет/телефон
- **Ошибки, нет данных, нет связи:** operation_id
