# Контролёр качества, веса и маркировки

`qc_controller` · Складское исполнение · группа доступа (предложение): `RL_QC` · действующие legacy-группы: `VESOV`
Область назначения: подсклад/участок склада · устройства: ТСД, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Старший участка контроля (руководитель качества)
- **Подчинённые роли:** —
- **Заместитель:** Старший участка контроля (руководитель качества)
- **Передача смены / замещение:** Открытая проверка — с результатами, паллетой и оставшимися действиями.
- **Эскалация:** Старшему контроля — ошибка не исправляется, рейс ждёт.

**Отвечает за:**
- Проверка состава и веса мест (аудитор собранного товара)
- Исправление: возврат излишков, докомплектация, повторный контроль (ТЗ)
- Проверка кодов маркировки по настройке SKU

## 2. События, решения, смена

**Смена:** Вечерняя смена.

**Входящие события:**
- Место на контроль (выборка/100%/ошибка веса)
- Красный тег

**Решения:**
- Допустить место
- Направить на исправление

**Сценарии:**

1. *обычный* — **Проверка места.** Скан места → состав (коробки/коды) → устойчивое взвешивание → допуск.
2. *дефицит/конфликт* — **Ошибка веса.** Красный тег → проверка коробок → исправление → повторный контроль; запрет отгрузки до допуска.
3. *отказ/потеря связи* — **Весы не ответили.** Повтор измерения; ручной вес не принимается.
4. *передача* — **Передача проверки.** Результаты и паллета — следующему контролёру.

## 4. UI

- **Первый экран:** Текущее место: что проверить, сколько коробок, ожидаемый вес
- **Главное действие:** Отсканировать место
- **Таблица:** ТСД: место · коробок проверено/всего · вес ожидаемый/факт
- **Массовые операции:** Нет
- **Ввод:** Сканер + весы
- **Ошибки, нет данных, нет связи:** Каждый скан — команда с operation_id, сохранённая до отправки; потеря ответа → «результат неизвестен», повтор того же скана; перезагрузка ТСД восстанавливает незавершённую команду; чужая/неверная ячейка — отказ сервера с кодом, крупным текстом
