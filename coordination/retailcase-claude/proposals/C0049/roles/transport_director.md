# Директор транспорта

`transport_director` · Руководство сети и РЦ · группа доступа (предложение): `RL_TR_DIR`
Область назначения: вся сеть · устройства: desktop, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Директор логистики сети
- **Подчинённые роли:** Экономист / транспортный биллинг, Менеджер перевозчиков, Ответственный за автопарк и ремонт, Ответственный за оборотную тару, Руководитель транспортного планирования
- **Заместитель:** Руководитель транспортного планирования
- **Передача смены / замещение:** Замещает руководитель транспортного планирования по временному назначению.
- **Эскалация:** Директору логистики — срыв доставок сети, потеря машины/груза, конфликт с перевозчиком.

**Отвечает за:**
- Автопарк, перевозчики, оборотная тара (по ТЗ права на тару — у транспорта)
- Доставка в окна и соблюдение ограничений машин
- Политика сроков возврата тары

**Не вправе:**
- Не ставит ставки и не решает стадии расходов
- Не выполняет диспетчерские команды

## 2. События, решения, смена

**Смена:** Рабочий день.

**Входящие события:**
- Рейсы дня с задержкой выше порога
- Машина недоступна (ремонт)
- Тара на руках магазинов сверх срока
- Доплаты выше порога

**Решения:**
- Привлечь перевозчика или перенести доставки
- Изменить срок возврата тары
- Эскалировать конфликт с перевозчиком

**Сценарии:**

1. *обычный* — **Обзор доставок.** Ганта и KPI транспорта по складу: рейсы с задержкой, свободный парк. Переход к рейсу и окнам магазина.
2. *дефицит/конфликт* — **Нехватка машин.** План требует больше машин, чем свободно. Модуля перевозчиков нет — решение фиксируется вне системы; руководителю планирования — перенос части доставок.
3. *отказ/потеря связи* — **Нет позиции машины.** Рейс без GPS: решение о замене принимает диспетчер; директору — эскалация только при угрозе окна.
4. *передача* — **Замещение.** Временное назначение руководителю планирования.

## 4. UI

- **Первый экран:** Задержки дня, свободный парк, тара сверх срока по магазинам
- **Главное действие:** Перейти к рейсу/машине
- **Таблица:** Рейс · машина · окно · статус · задержка, мин
- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Только чтение; политика тары — отдельная команда с версией
