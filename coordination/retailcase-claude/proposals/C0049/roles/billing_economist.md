# Экономист / транспортный биллинг

`billing_economist` · Финансы, аналитика, ИТ и контроль · группа доступа (предложение): `RL_BILLING`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Директор транспорта
- **Подчинённые роли:** —
- **Заместитель:** Согласующий затрат
- **Передача смены / замещение:** Расходы на стадии LOGIST, неначисленные рейсы.
- **Эскалация:** Согласующему — спорный расход.

**Отвечает за:**
- Регистрация дополнительных расходов (edit_bill_tt)
- Логистическая стадия решения чужого расхода (expense_logist_approve)
- Расчёт стоимости рейсов

**Не вправе:**
- Не решает стадии по расходу, который зарегистрировал сам (native guard)

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Новый расход
- Рейс закрыт

**Решения:**
- Решение стадии LOGIST
- Рассчитать стоимость рейса

**Сценарии:**

1. *обычный* — **Расход.** Регистрация → решение LOGIST другим экономистом → FINANCE у согласующего.
2. *дефицит/конфликт* — **Стадия уже решена.** 409 EXPENSE_PHASE_ALREADY_DECIDED — перечитать.
3. *отказ/потеря связи* — **Неизвестный исход.** Повтор тем же operation_id.
4. *передача* — **Передача.** Расходы по стадиям.
