# Старший участка контроля (руководитель качества)

`lead_qc` · Управление складскими операциями · группа доступа (предложение): `RL_ST_QC` · действующие legacy-группы: `KLADOVSHIK`
Область назначения: подсклад/участок склада · устройства: desktop, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Начальник смены
- **Подчинённые роли:** Контролёр качества, веса и маркировки
- **Заместитель:** Контролёр качества, веса и маркировки
- **Передача смены / замещение:** Открытые проверки с паллетой, результатами и оставшимися действиями; запрет отгрузки сохраняется.
- **Эскалация:** Начальнику смены — рейс ждёт проверку; руководителю операций — систематические ошибки веса.

**Отвечает за:**
- Операции аудиторов (ТЗ процесс 6)
- Доля выборочного/100% контроля по подскладу (настройку вводит руководитель операций)
- Сроки вылежки партий

## 2. События, решения, смена

**Смена:** Вечерняя смена.

**Входящие события:**
- Ошибка веса
- Красный тег
- Брак/маркировка при приёмке

**Решения:**
- Распределить аудиторов по запасу времени до рейса
- Предложить изменение доли контроля

**Сценарии:**

1. *обычный* — **Выборочный контроль.** Правило подсклада → проверка состава и веса → допуск в экспедицию.
2. *дефицит/конфликт* — **Ошибка веса на месте рейса.** Проверка → исправление → повторный контроль; аудиторы по запасу времени до выезда.
3. *отказ/потеря связи* — **Весы не передали измерение.** Повтор с весов; ручной ввод не подменяет устойчивое измерение.
4. *передача* — **Передача проверок.** С результатами и паллетой; запрет отгрузки сохраняется.

## 4. UI

- **Первый экран:** Проверки по запасу времени до рейса
- **Главное действие:** Назначить аудитора
- **Таблица:** Место · рейс · запас времени · причина · аудитор · этап
- **Массовые операции:** Нет
- **Ввод:** Планшет
- **Ошибки, нет данных, нет связи:** Снятие запрета только после подтверждённого повторного контроля
