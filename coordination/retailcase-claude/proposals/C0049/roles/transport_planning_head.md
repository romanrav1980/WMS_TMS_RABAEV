# Руководитель транспортного планирования

`transport_planning_head` · Транспорт · группа доступа (предложение): `RL_TR_PLAN_HD` · действующие legacy-группы: `LOGIST`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Директор транспорта
- **Подчинённые роли:** Транспортный диспетчер, Маршрутный планировщик
- **Заместитель:** Маршрутный планировщик
- **Передача смены / замещение:** План следующего дня: утверждённые/черновые рейсы, нераспределённые СТ.
- **Эскалация:** Директору транспорта — машин меньше потребности; директору РЦ — склад не успевает к плану.

**Отвечает за:**
- Транспортный план и задание на сборку (ТЗ процесс 1)
- Утверждение маршрутов и времени рейсов
- Распределение маршрутных планировщиков

## 2. События, решения, смена

**Смена:** Дневная; план на вечерний цикл после отсечки заказов.

**Входящие события:**
- Заказы сети приняты
- Решение VRP готово
- Изменение заказа после плана

**Решения:**
- Применить решение VRP
- Перенести СТ в другой рейс/день

**Сценарии:**

1. *обычный* — **План дня.** Планировщик VRP → решение → применение → рейсы с СТ, воротами и сроками → склад получает план.
2. *дефицит/конфликт* — **Не хватает машин.** Нераспределённые СТ; перенос на следующий цикл или привлечение машины (директор транспорта).
3. *отказ/потеря связи* — **Решение не применилось.** Перечитать рейсы дня; команда apply без operation_id — повтор только после чтения.
4. *передача* — **Передача плана.** Рейсы и нераспределённые СТ.

| Раздел | Пункт | Источник / команда |
|---|---|---|
| Главная | Планировщик маршрутов (VRP) | Планировщик маршрутов (VRP) (`planner`) |
| Очереди и приоритеты | Диспетчеризация рейсов | Диспетчеризация рейсов (`transport`) |

GAP: нет контракта идемпотентности; читать рейсы дня |

## 4. UI

- **Первый экран:** Нераспределённые СТ и рейсы дня
- **Главное действие:** Применить решение
- **Таблица:** Рейс · машина · СТ · окна · вес/объём · статус
- **Массовые операции:** Применение решения VRP целиком
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** apply без operation_id: при сбое перечитать рейсы, не повторять вслепую
