# Старший участка отбора

`lead_picking` · Управление складскими операциями · группа доступа (предложение): `RL_ST_PICK`
Область назначения: подсклад/участок склада · устройства: desktop, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Начальник смены
- **Подчинённые роли:** Комплектовщик
- **Заместитель:** Комплектовщик
- **Передача смены / замещение:** Незавершённые задания сборки, открытые недостачи, комплектовщики с простоем.
- **Эскалация:** Начальнику смены — недостачи, остановки, нехватка людей.

**Отвечает за:**
- Темп комплектации обеспеченных волн
- Первичный разбор недостач и простоев

## 2. События, решения, смена

**Смена:** С начала комплектации по профилю РЦ до закрытия волн.

**Входящие события:**
- Пустая ячейка
- Недостача
- Простой комплектовщика

**Решения:**
- Передать неначатое задание другому комплектовщику
- Передать недостачу на подтверждение

**Сценарии:**

1. *обычный* — **Комплектация.** Задания по маршруту и порядку укладки; комплектовщики на ТСД сборки; старший следит за темпом.
2. *дефицит/конфликт* — **Недостача.** Недостача → проверка ячейки → подтверждение начальником смены.
3. *отказ/потеря связи* — **ТСД без связи.** Задание остаётся за комплектовщиком; повтор шага — тем же operation_id.
4. *передача* — **Конец смены.** Незавершённое задание передаётся с подтверждённым количеством в грузовом месте.

## 4. UI

- **Первый экран:** Комплектовщики зоны: задание, строк выполнено/всего, простой с причиной
- **Главное действие:** Передать задание
- **Таблица:** Комплектовщик · задание · волна · строк · простой · причина
- **Массовые операции:** Нет
- **Ввод:** Планшет
- **Ошибки, нет данных, нет связи:** Передаётся только неначатое
