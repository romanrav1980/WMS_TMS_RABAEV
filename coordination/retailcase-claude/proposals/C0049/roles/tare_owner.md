# Ответственный за оборотную тару

`tare_owner` · Запас, качество, возвраты и тара · группа доступа (предложение): `RL_TARE`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Директор транспорта
- **Подчинённые роли:** —
- **Заместитель:** Транспортный диспетчер
- **Передача смены / замещение:** Открытые недостачи и повреждения тары.
- **Эскалация:** Директору транспорта — систематическая недостача у магазина/перевозчика.

**Отвечает за:**
- Баланс тары по контрагентам (права на тару — у департамента транспорта по ТЗ)
- Бронирование тары под сборку
- Регистрация недостач и повреждений

**Не вправе:**
- Не списывает недостачу, которую сам зарегистрировал

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Тара не возвращена в срок
- Повреждение
- Пересчёт расходится с балансом

**Решения:**
- Зарегистрировать недостачу
- Забронировать тару

**Сценарии:**

1. *обычный* — **Баланс.** Оборотная тара: выдано/возвращено по магазинам и типам.
2. *дефицит/конфликт* — **Недостача.** Регистрация недостачи; списание решает другой сотрудник с tare_writeoff.
3. *отказ/потеря связи* — **Неизвестный исход.** Повтор тем же operation_id.
4. *передача* — **Передача.** Открытые недостачи с основаниями.
