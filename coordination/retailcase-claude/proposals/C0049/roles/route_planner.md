# Маршрутный планировщик

`route_planner` · Транспорт · группа доступа (предложение): `RL_ROUTE_PLAN` · действующие legacy-группы: `LOGIST`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Руководитель транспортного планирования
- **Подчинённые роли:** —
- **Заместитель:** Транспортный диспетчер
- **Передача смены / замещение:** Черновые рейсы и задачи VRP.
- **Эскалация:** Руководителю планирования — нарушение окон/ограничений машины.

**Отвечает за:**
- Состав рейсов: СТ, порядок адресов, окна магазинов, ограничения машины, перерывы водителя

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Новые СТ
- Окно магазина изменилось

**Решения:**
- Добавить СТ в рейс
- Изменить порядок

**Сценарии:**

1. *обычный* — **Рейс.** Добавить СТ → порядок → проверка окон и расчётного маршрута сервера.
2. *дефицит/конфликт* — **Окно не выполняется.** Расчётный маршрут показывает пропуск строгого окна; перестановка или другой рейс.
3. *отказ/потеря связи* — **Сбой сохранения.** Перечитать состав рейса перед повтором.
4. *передача* — **Передача.** Черновые рейсы руководителю.

## 4. UI

- **Первый экран:** Черновые рейсы и СТ без рейса
- **Главное действие:** Добавить СТ в рейс
- **Таблица:** Рейс · СТ · адреса · окна · вес
- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Перечитать рейс перед повтором
