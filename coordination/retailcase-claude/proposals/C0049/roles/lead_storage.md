# Старший участка хранения и пополнения (диспетчер ричтраков)

`lead_storage` · Управление складскими операциями · группа доступа (предложение): `RL_ST_STOR`
Область назначения: подсклад/участок склада · устройства: desktop, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Начальник смены
- **Подчинённые роли:** Водитель ричтрака
- **Заместитель:** Водитель ричтрака
- **Передача смены / замещение:** Закрепления водителей за техникой; незавершённые подачи; остаточный мини-макс.
- **Эскалация:** Начальнику смены — подача не успевает к волне; руководителю операций — неисправность техники.

**Отвечает за:**
- Закрепление водителей за ричтраками
- Размещение, мини-макс, пополнение волн, срочные подачи
- Смена ричтраков со сдвигом к комплектации по профилю РЦ

## 2. События, решения, смена

**Смена:** Старт смены ричтраков по профилю РЦ; один-два водителя до конца основной смены.

**Входящие события:**
- Потребность пополнения волны
- Срочная подача (пустая ячейка)
- Ричтрак неисправен

**Решения:**
- Назначить ближайший ресурс
- Поднять приоритет подачи под ближайшую волну
- Закрепить водителя за техникой

**Сценарии:**

1. *обычный* — **Пополнение под волну.** Пополнение волны → задания подачи → исполнение на ТСД → прогресс 100% до запуска.
2. *дефицит/конфликт* — **Две волны.** Подачи ближайшей волны получают её срок; мини-макс 4-го уровня ждёт; действующие задания учитываются (нет двойной подачи).
3. *отказ/потеря связи* — **Ричтрак сломался во время подачи.** Подтвердить фактическое положение паллеты → передать задание другому водителю; техника исключена.
4. *передача* — **Конец смены ричтраков.** Незавершённые подачи и остаточный мини-макс передаются с причинами.

## 4. UI

- **Первый экран:** Подачи по волнам с таймером до запуска и исполнителем
- **Главное действие:** Назначить ближайший ресурс
- **Таблица:** Задание · волна · срок · откуда→куда · SKU · водитель · техника · этап
- **Массовые операции:** Нет
- **Ввод:** Планшет
- **Ошибки, нет данных, нет связи:** Отказ dispatch-nearest показывает причину (нет кандидата, позиция устарела) — решение вручную
