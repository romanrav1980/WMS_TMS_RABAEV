# Директор распределительного центра

`dc_director` · Руководство сети и РЦ · группа доступа (предложение): `RL_DC_DIR`
Область назначения: склад · устройства: desktop, планшет · рабочее место: **реализуется в C0056 (блок 4)**

## 1. Место в организации

- **Руководитель:** Директор логистики сети
- **Подчинённые роли:** Согласующий затрат, Контролёр остатков (КРО), Руководитель складских операций
- **Заместитель:** Руководитель складских операций
- **Передача смены / замещение:** Замещает руководитель складских операций по временному назначению. Передаются открытые исключения с ответственными.
- **Эскалация:** Директору логистики — дефицит, который РЦ не закрывает сам; срыв доли рейсов дня выше порога. Директору транспорта — нет машин/ворот.

**Отвечает за:**
- Выполнение складом транспортного плана РЦ
- Персонал, техника, нормативы РЦ (через руководителя операций)
- Сохранность запаса: результаты пересчётов и расследований

**Не вправе:**
- Не выполняет задания
- Не подтверждает недостачи и расхождения сам — это начальник смены и КРО

## 2. События, решения, смена

**Смена:** Рабочий день и контроль вечернего цикла по профилю РЦ.

**Входящие события:**
- Прогноз: выход меньше потребности на смену
- Волна не обеспечена к сроку профиля
- Рейс не будет готов к плановому выезду
- Остановка отбора дольше предела профиля

**Решения:**
- Перенести комплектацию/рейс (с логистом)
- Поручить замену выхода
- Принять передачу смены

**Сценарии:**

1. *обычный* — **Подготовка вечернего цикла.** Около отсечки заказов открывает главную: прогноз выхода по часам и подскладам, волны смены, рейсы с риском. Дефицит людей поручает руководителю операций (замена выхода в «Нагрузке»).
2. *дефицит/конфликт* — **Рейс под угрозой.** Исключение: рейс 33564 — 3 места под красным тегом за 40 мин до выезда. Видит ответственного (старший контроля) и этап проверки; при невозможности — поручает диспетчеру отвязку части груза с назначением дальнейшей доставки.
3. *дефицит/конфликт* — **Расхождение пересчёта.** Не корректирует запас: открывает расследование, требует повторный пересчёт другим инвентаризатором. Утверждение — у роли с stock_adjust_approve (сейчас утверждения нет — GAP).
4. *отказ/потеря связи* — **Нет связи с ТСД зоны.** Сессии без heartbeat отмечены на главной; ресурсы сохраняют последнее состояние. Директор ждёт сверку начальника смены, не переназначает сам.
5. *передача* — **Отпуск.** Временное назначение руководителю операций на период; состав прав групп не меняется.

## 4. UI

- **Первый экран:** Три блока: (1) исключения смены с ответственным и сроком; (2) волны: обеспечено/нет и время до срока профиля; (3) выход vs потребность по часам
- **Главное действие:** Открыть исключение у владельца процесса
- **Таблица:** Исключение · объект · влияние на рейсы · ответственный · срок · возраст
- **Массовые операции:** Нет
- **Ввод:** Мышь/планшет
- **Ошибки, нет данных, нет связи:** Каждый блок — своё время чтения; ошибка одного источника не обнуляет остальные; команды только в экранах-владельцах
