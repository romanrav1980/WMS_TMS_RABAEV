# Специалист брака, карантина и возвратов

`returns_specialist` · Запас, качество, возвраты и тара · группа доступа (предложение): `RL_RETURNS`
Область назначения: склад · устройства: desktop, ТСД · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Руководитель складских операций
- **Подчинённые роли:** —
- **Заместитель:** Контролёр остатков (КРО)
- **Передача смены / замещение:** Возвраты в работе: принято/размещено/к поставщику/утилизация.
- **Эскалация:** Руководителю операций — нет места карантина; оператору SAP — возврат без основания.

**Отвечает за:**
- Складская приёмка возвратов магазинов
- Размещение, возврат поставщику, утилизация
- Карантин через недоступные ячейки

**Не вправе:**
- Не утверждает возврат магазина, который сам принял от водителя

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Возврат прибыл на склад
- Брак при приёмке
- Решение поставщика

**Решения:**
- Принять возврат
- Разместить в карантин/годный запас
- Передать поставщику/утилизировать

**Сценарии:**

1. *обычный* — **Возврат магазина.** Приёмка возвратов → размещение → передача поставщику или утилизация.
2. *дефицит/конфликт* — **Карантин.** Ячейка становится недоступной — сейчас только через warehouse_topology_edit (GAP узкого права cell_availability_edit).
3. *отказ/потеря связи* — **Неизвестный исход приёмки.** Повтор той же команды.
4. *передача* — **Передача.** Список возвратов по этапам.
