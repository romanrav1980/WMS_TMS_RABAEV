# Водитель погрузчика

`forklift_driver` · Складское исполнение · группа доступа (предложение): `RL_FORK`
Область назначения: подсклад/участок склада · устройства: ТСД · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Старший участка экспедиции
- **Подчинённые роли:** —
- **Заместитель:** Водитель ричтрака
- **Передача смены / замещение:** Как у ричтрака: начатое — после подтверждения положения груза.
- **Эскалация:** Старшему экспедиции — ворота заняты, груз повреждён.

**Отвечает за:**
- Выгрузка межскладских машин, подвоз к воротам, перемещения в экспедиции

## 2. События, решения, смена

**Смена:** Смена экспедиции.

**Входящие события:**
- Межскладская машина у ворот
- Подача к воротам рейса

**Решения:**
- Принять задание
- Сообщить о повреждении

**Сценарии:**

1. *обычный* — **Выгрузка межсклада.** Выгрузка мест → каждый SSCC принимается отдельно → развозка к воротам целевого рейса.
2. *дефицит/конфликт* — **SSCC не из плана.** Отказ с кодом; несоответствие передаётся начальнику кросс-дока и логисту.
3. *отказ/потеря связи* — **Нет связи.** Повтор того же подтверждения.
4. *передача* — **Конец смены.** Невыгруженные места — старшему.

## 4. UI

- **Первый экран:** Текущая машина/ворота и места к выгрузке
- **Главное действие:** Отсканировать место
- **Таблица:** ТСД: место · откуда · куда
- **Массовые операции:** Нет
- **Ввод:** Сканер
- **Ошибки, нет данных, нет связи:** Каждый скан — команда с operation_id, сохранённая до отправки; потеря ответа → «результат неизвестен», повтор того же скана; перезагрузка ТСД восстанавливает незавершённую команду; чужая/неверная ячейка — отказ сервера с кодом, крупным текстом
