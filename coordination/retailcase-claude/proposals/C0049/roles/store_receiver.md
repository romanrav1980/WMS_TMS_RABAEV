# Приёмщик магазина

`store_receiver` · Магазины · группа доступа (предложение): `RL_STORE_RECV`
Область назначения: магазин · устройства: телефон, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Управляющий магазином
- **Подчинённые роли:** —
- **Заместитель:** Управляющий магазином
- **Передача смены / замещение:** Незавершённая приёмка остаётся на устройстве до подтверждения.
- **Эскалация:** Управляющему — расхождение, повреждение.

**Отвечает за:**
- Приёмка мест своей поставки с водителем, фото, весы
- Подпись акта

**Не вправе:**
- Видит только свою поставку, не весь рейс

## 2. События, решения, смена

**Смена:** Окна приёмки магазина.

**Входящие события:**
- Машина прибыла

**Решения:**
- Принять место
- Зафиксировать расхождение

**Сценарии:**

1. *обычный* — **Приёмка.** Разгрузка → места по одному → акт.
2. *дефицит/конфликт* — **Недостача места.** Расхождение с фото → кейс.
3. *отказ/потеря связи* — **Нет связи.** Акт не подтверждён до ответа; повтор тем же operation_id.
4. *передача* — **Смена приёмщика.** Незавершённая приёмка — управляющему.
