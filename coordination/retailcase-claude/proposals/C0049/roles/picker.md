# Комплектовщик

`picker` · Складское исполнение · группа доступа (предложение): `RL_PICKER` · действующие legacy-группы: `SBORSHIK`
Область назначения: свои объекты (проверенная серверная привязка) · устройства: ТСД · рабочее место: **реализуется в C0056 (блок 4)**

## 1. Место в организации

- **Руководитель:** Старший участка отбора
- **Подчинённые роли:** —
- **Заместитель:** Старший участка отбора
- **Передача смены / замещение:** Конец смены/перерыв: текущее грузовое место закрывается или передаётся с подтверждённым количеством; неначатые задания возвращаются в очередь.
- **Эскалация:** Старшему отбора — пустая ячейка, повреждённый товар, неисправный ТСД.

**Отвечает за:**
- Отбор по заданию в порядке маршрута и укладки
- Закрытие грузового места с этикеткой и передача на контроль
- Сообщение о недостаче (по настройке — инвентаризация пустой ячейки)

**Не вправе:**
- Не подтверждает свою недостачу
- Не выбирает задания вне выданных

## 2. События, решения, смена

**Смена:** С начала комплектации по профилю РЦ; задания выдаются только по обеспеченной волне.

**Входящие события:**
- Выдано задание
- Ячейка пуста
- Тара закончилась
- Вес строки вне допуска

**Решения:**
- Принять задание
- Подтвердить строку
- Сообщить недостачу
- Закрыть грузовое место

**Сценарии:**

1. *обычный* — **Строка за строкой.** Принять задание → ячейка (скан) → товар (скан EAN/DataMatrix) → количество → подтверждение; следующий адрес — по ходу маршрута, адрес позади не назначается.
2. *дефицит/конфликт* — **Пустая ячейка.** «Недостача» с фактическим количеством и причиной → проверка ячейки (сам по настройке или аудитор) → срочное пополнение; комплектовщик остаётся занятым с причиной простоя.
3. *дефицит/конфликт* — **Весовой товар.** Взвешивание строки/коробки; вне допуска — отказ с кодом, повторное взвешивание.
4. *отказ/потеря связи* — **Потеря связи после скана.** Экран: «результат не подтверждён»; кнопка «Повторить» отправляет тот же скан с тем же operation_id; после перезагрузки команда восстанавливается из памяти устройства.
5. *передача* — **Перерыв/конец смены.** Закрыть место (этикетка) или передать старшему с подтверждённым количеством; неначатые строки возвращаются в очередь.

## 4. UI

- **Первый экран:** Одна строка на экран: адрес крупно, SKU и фото/название, количество и единица, прогресс задания
- **Главное действие:** Отсканировать ячейку, затем товар
- **Таблица:** ТСД: адрес · SKU · кол-во · ед. · место (тара) · строк осталось
- **Массовые операции:** Нет
- **Ввод:** Сканер; цели касания ≥ 48 px; ручной ввод количества — только цифровая клавиатура
- **Ошибки, нет данных, нет связи:** Каждый скан — команда с operation_id, сохранённая до отправки; потеря ответа → «результат неизвестен», повтор того же скана; перезагрузка ТСД восстанавливает незавершённую команду; чужая/неверная ячейка — отказ сервера с кодом, крупным текстом
