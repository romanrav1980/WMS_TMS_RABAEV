# Администратор доступа

`access_admin` · Финансы, аналитика, ИТ и контроль · группа доступа (предложение): `RL_ACCESS_ADM`
Область назначения: вся сеть · устройства: desktop · рабочее место: **реализуется в C0056 (блок 4)**

## 1. Место в организации

- **Руководитель:** Директор логистики сети
- **Подчинённые роли:** Специалист интеграций, Редактор базы знаний
- **Заместитель:** Специалист интеграций
- **Передача смены / замещение:** Открытые запросы на назначение.
- **Эскалация:** Владельцу роли — запрос вне мандата.

**Отвечает за:**
- Назначения пользователей с областью и сроком, отзыв (access_assign_manage)
- Группы объектов (access_group_manage)
- Legacy группы/права (rights_admin_edit) — без массовых изменений

**Не вправе:**
- Не назначает сверх собственного мандата
- Не меняет состав ролей, если назначает (PERSON)

## 2. События, решения, смена

**Смена:** Рабочий день.

**Входящие события:**
- Запрос доступа
- Истекает назначение
- Изменился состав группы объектов

**Решения:**
- Назначить роль на область и срок
- Отозвать
- Изменить группу объектов (с preview затронутых назначений)

**Сценарии:**

1. *обычный* — **Назначение.** Пользователь → роль → область → срок → основание → explain → сохранить (ASSIGN).
2. *дефицит/конфликт* — **Версия изменилась.** 409 → перечитать; новая команда с новым operation_id; старая не меняется.
3. *отказ/потеря связи* — **Неизвестный исход.** GET /api/access/commands/{operation_id}; до ответа новая команда по объекту блокирована.
4. *передача* — **Передача.** Запросы и истекающие назначения.

## 4. UI

- **Первый экран:** Пользователь: legacy-группа, назначения, срок; поиск
- **Главное действие:** Назначить роль
- **Таблица:** Назначение · роль · область · с · до · основание · кто назначил · версия
- **Массовые операции:** Нет (каждое назначение — отдельная команда)
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** operation_id; 409 не меняет payload под тем же ключом

## 6. Права

| Уровень | Право | Статус |
|---|---|---|
| read | `access_admin_view` | проверяется native/Oracle (реализовано) |
| read | `rights_admin_view` | API, выдано группам |
| execute | `access_assign_manage` | проверяется native/Oracle (реализовано) |
| execute | `access_group_manage` | проверяется native/Oracle (реализовано) |
| admin | `rights_admin_edit` | API, выдано группам |

**Разделение обязанностей:** Мандат назначающего проверяет сервер: нельзя выдать больше своих прав, области и срока
