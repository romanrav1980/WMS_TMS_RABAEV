# Транспортный диспетчер

`dispatcher` · Транспорт · группа доступа (предложение): `RL_DISPATCH`
Область назначения: именованная группа объектов одного вида · устройства: desktop, планшет · рабочее место: **реализуется в C0056 (блок 4)**

## 1. Место в организации

- **Руководитель:** Руководитель транспортного планирования
- **Подчинённые роли:** Водитель автомобиля, Координатор двора и ворот
- **Заместитель:** Маршрутный планировщик
- **Передача смены / замещение:** Рейсы смены: выехал/у ворот/в пути/задержан, открытые решения по отвязке груза, водители без связи. Принимающий подтверждает.
- **Эскалация:** Руководителю планирования — рейс не выполним; директору транспорта — авария/потеря груза.

**Отвечает за:**
- Подготовка и выпуск рейса со склада (ТЗ процесс 7) и доставка (процесс 9) в разрешённых РЦ
- Машина, водитель, ворота, время рейса
- Решение по непоместившемуся/задержанному грузу: отвязка только с назначением дальнейшей доставки
- Подтверждение выезда и закрытие рейса

**Не вправе:**
- Не подтверждает погрузку мест (это экспедиция)
- Не меняет ставки

## 2. События, решения, смена

**Смена:** Смена выпуска рейсов; доставки — до закрытия рейсов дня.

**Входящие события:**
- Рейс готов к погрузке/погружен
- Машина не прибыла
- Место не помещается
- Водитель без связи
- Окно магазина под угрозой

**Решения:**
- Заменить машину/водителя/ворота
- Отвязать СТ с дальнейшей доставкой
- Подтвердить выезд
- Закрыть рейс

**Сценарии:**

1. *обычный* — **Выпуск рейса.** Рейс в статусе погрузки: места погружены, температура и тара подтверждены → диспетчер подтверждает выезд → контролирует доставку по операциям водителя → закрывает рейс.
2. *дефицит/конфликт* — **Машина не прибыла.** Замена машины в рейсе (проверка ограничений магазинов и физического профиля в preflight) → новые ворота → склад видит изменение.
3. *дефицит/конфликт* — **Не помещается.** Экспедиция внесла место в реестр; диспетчер отвязывает СТ и назначает дальнейшую доставку; без назначения отвязка запрещена.
4. *отказ/потеря связи* — **Водитель без связи.** Последняя операция и время; окно под угрозой — звонок, при необходимости замена. Не закрывает рейс без операций водителя.
5. *передача* — **Передача смены.** Список рейсов по статусам и открытых решений; принимающий подтверждает.

## 4. UI

- **Первый экран:** Рейсы смены колонками статусов (к погрузке · погрузка · выехал · в пути · задержан · доставлен) с риском окна и последней операцией водителя
- **Главное действие:** Открыть рейс с риском и принять решение
- **Таблица:** Рейс · РЦ · машина · водитель · ворота · мест погружено/всего · план выезда · след. окно · последняя операция · риск
- **Массовые операции:** Нет
- **Ввод:** Мышь/планшет
- **Ошибки, нет данных, нет связи:** Выезд — operation_id; правка рейса без operation_id — перечитать перед повтором; нет связи с API — баннер, последние данные помечены временем
