# Водитель автомобиля

`driver` · Транспорт · группа доступа (предложение): `RL_DRIVER`
Область назначения: свои объекты (проверенная серверная привязка) · устройства: телефон · рабочее место: **реализуется в C0056 (блок 4)**

## 1. Место в организации

- **Руководитель:** Транспортный диспетчер
- **Подчинённые роли:** —
- **Заместитель:** Транспортный диспетчер
- **Передача смены / замещение:** Рейс не передаётся другому водителю без решения диспетчера; незавершённые операции остаются за рейсом.
- **Эскалация:** Диспетчеру — магазин закрыт, авария, неисправность, расхождение при приёмке.

**Отвечает за:**
- Операции своего рейса: старт/завершение этапов
- Совместная приёмка в магазине (акт с приёмщиком)
- Тара и возвраты магазина под подпись

**Не вправе:**
- Не видит чужие рейсы (SELF по привязке учётной записи к водителю)
- Не утверждает возврат, который принял

## 2. События, решения, смена

**Смена:** Рейсы назначенного дня.

**Входящие события:**
- Рейс назначен
- Прибытие в магазин
- Магазин закрыт/нет приёмщика

**Решения:**
- Начать/завершить операцию
- Сообщить проблему диспетчеру

**Сценарии:**

1. *обычный* — **Доставка.** Мой рейс → операции по порядку: выезд, прибытие, разгрузка с приёмщиком (акт), тара, возвраты, возврат на базу.
2. *дефицит/конфликт* — **Магазин закрыт.** Звонок диспетчеру; операция не завершается фиктивно; решение — ожидание или перенос.
3. *отказ/потеря связи* — **Нет мобильной связи.** Нажатие сохраняется как неподтверждённое; после связи — повтор той же операции (повтор безопасен).
4. *передача* — **Замена водителя.** Только решением диспетчера в рейсе; новый водитель видит рейс после привязки.

## 4. UI

- **Первый экран:** Текущий рейс: следующая операция крупно, адрес, окно, кнопка действия
- **Главное действие:** Начать/завершить текущую операцию
- **Таблица:** Телефон: список операций рейса с отметкой выполнено
- **Массовые операции:** Нет
- **Ввод:** Касание, цели ≥ 48 px; звонок диспетчеру одной кнопкой
- **Ошибки, нет данных, нет связи:** Нет связи — плашка, нажатие помечено «не подтверждено» до ответа сервера; повтор безопасен
