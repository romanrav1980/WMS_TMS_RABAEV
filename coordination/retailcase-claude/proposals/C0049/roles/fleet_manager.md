# Ответственный за автопарк и ремонт

`fleet_manager` · Транспорт · группа доступа (предложение): `RL_FLEET`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Директор транспорта
- **Подчинённые роли:** —
- **Заместитель:** Транспортный диспетчер
- **Передача смены / замещение:** Машины в ремонте и сроки готовности.
- **Эскалация:** Директору транспорта — машина надолго выбыла.

**Отвечает за:**
- Карточки машин и водителей, физический/температурный профиль, варианты тары

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Неисправность
- Истёк допуск

**Решения:**
- Вывести машину из работы
- Обновить профиль

**Сценарии:**

1. *обычный* — **Карточка машины.** Профиль: габариты, температура, тара; версия.
2. *дефицит/конфликт* — **Машина в рейсах завтра.** Вывод из работы — диспетчер переназначает рейсы.
3. *отказ/потеря связи* — **Сбой сохранения.** Перечитать карточку.
4. *передача* — **Передача.** Ремонты и сроки.

## 4. UI

- **Первый экран:** Машины и готовность
- **Главное действие:** Открыть карточку
- **Таблица:** Машина · тип · статус · профиль · водитель
- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Версия профиля
