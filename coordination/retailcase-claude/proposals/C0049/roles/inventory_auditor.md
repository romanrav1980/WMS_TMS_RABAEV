# Инвентаризатор

`inventory_auditor` · Запас, качество, возвраты и тара · группа доступа (предложение): `RL_INV_AUD` · действующие legacy-группы: `REVIZOR`
Область назначения: подсклад/участок склада · устройства: ТСД · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Контролёр остатков (КРО)
- **Подчинённые роли:** —
- **Заместитель:** Контролёр остатков (КРО)
- **Передача смены / замещение:** Незавершённый пересчёт сохраняется в команде; передаётся старшему.
- **Эскалация:** Контролёру остатков — расхождение, повреждение.

**Отвечает за:**
- Срочные проверки ячеек (пустая ячейка у комплектовщика)
- Плановые пересчёты

## 2. События, решения, смена

**Смена:** По заданиям; срочные — первый приоритет.

**Входящие события:**
- Срочная проверка ячейки
- Плановое задание

**Решения:**
- Подтвердить остаток или расхождение

**Сценарии:**

1. *обычный* — **Плановый пересчёт.** Задание → скан ячейки → скан партий/единиц → отправка.
2. *дефицит/конфликт* — **Пустая ячейка у отбора.** Срочная проверка: подтверждённое отсутствие запускает срочное пополнение; лимит профиля.
3. *отказ/потеря связи* — **Нет связи после отправки.** Повтор тем же operation_id; двойная проводка невозможна.
4. *передача* — **Конец смены.** Незавершённое задание — старшему.

## 3. Рабочее место

| Раздел | Пункт | Источник / команда |
|---|---|---|
| Главная | Пересчёт | Пересчёт (`inventory-count.html`) |
| Очереди и приоритеты | Мои задания | `GET /api/inventory/tasks` |
| Фильтры | Нет | **GAP** — фильтры ТСД не нужны |
| Карточка объекта | Пересчёт | Пересчёт (`inventory-count.html`) |
| Допустимые команды | Отправить пересчёт | `POST /api/inventory/stock-posting/inventory/counts` · право `stock_inventory_count` · вход: ревизия/задание, партии и ячейки, сканы единиц · результат: результат проведён через ядро (без второго подтверждения) · повтор: operation_id обязателен в теле: при потере ответа — повтор тем же operation_id и телом; отдельной GET-квитанции нет, исход также виден чтением объекта; ответ RESULT_UNCERTAIN требует повтора тем же operation_id |
| История и документы | Операция ядра | `GET /api/inventory/stock-posting/operations/{operation_id}` |
| Уведомления и эскалации | Срочная проверка | **GAP** — звук ТСД нет |
| Отчётность | Мои пересчёты | **GAP** — отчёта нет |

## 4. UI

- **Первый экран:** Текущая ячейка и что сканировать
- **Главное действие:** Отсканировать партии/единицы
- **Таблица:** ТСД: ячейка · партия · кол-во
- **Массовые операции:** Нет
- **Ввод:** Сканер
- **Ошибки, нет данных, нет связи:** Скан сохраняется до отправки; повтор тем же operation_id
