# Старший участка экспедиции

`lead_expedition` · Управление складскими операциями · группа доступа (предложение): `RL_ST_EXP` · действующие legacy-группы: `STOPPER`
Область назначения: подсклад/участок склада · устройства: desktop, планшет, ТСД · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Начальник смены
- **Подчинённые роли:** Водитель погрузчика, Грузчик / оператор погрузки
- **Заместитель:** Грузчик / оператор погрузки
- **Передача смены / замещение:** Рейсы у ворот: погружено/осталось, места под запретом, консолидации в работе.
- **Эскалация:** Диспетчеру — машина не прибыла/не помещается; начальнику смены — места не допущены.

**Отвечает за:**
- Распределение сотрудников экспедиции
- Консолидация, подача, погрузка, выгрузка межсклада
- Реестр непоместившегося/задержанного товара

## 2. События, решения, смена

**Смена:** Вечерняя смена и выпуск рейсов.

**Входящие события:**
- Рейс готов к погрузке
- Место не помещается
- Межскладская машина прибыла

**Решения:**
- Порядок погрузки
- Передать непоместившееся диспетчеру
- Распределить людей по воротам

**Сценарии:**

1. *обычный* — **Погрузка.** Допущенные места → подтверждение каждого идентификатора в машину → температура/тара → выезд (выезд подтверждает диспетчер).
2. *дефицит/конфликт* — **Не помещается.** Место в реестр; диспетчер решает отвязку с дальнейшей доставкой.
3. *отказ/потеря связи* — **Сбой подтверждения.** Неизвестный исход — повтор тем же operation_id; повторного списания нет.
4. *передача* — **Рейсы у ворот.** Погружено/осталось по рейсу, запреты, консолидации.

## 4. UI

- **Первый экран:** Ворота × рейсы: машина, погружено/всего, запреты, время до выезда
- **Главное действие:** Подтверждать места в машину
- **Таблица:** Ворота · рейс · машина · мест погружено/всего · под запретом · плановый выезд
- **Массовые операции:** Нет — каждое место отдельно (ТЗ)
- **Ввод:** ТСД: сканирование
- **Ошибки, нет данных, нет связи:** operation_id на каждое место
