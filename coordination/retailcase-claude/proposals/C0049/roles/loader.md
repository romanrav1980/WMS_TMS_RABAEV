# Грузчик / оператор погрузки

`loader` · Складское исполнение · группа доступа (предложение): `RL_LOADER` · действующие legacy-группы: `STOPPER`
Область назначения: подсклад/участок склада · устройства: ТСД · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Старший участка экспедиции
- **Подчинённые роли:** —
- **Заместитель:** Водитель погрузчика
- **Передача смены / замещение:** Погружено/осталось по рейсу.
- **Эскалация:** Старшему экспедиции — место не помещается, место под запретом.

**Отвечает за:**
- Подтверждение каждого места в конкретную машину
- Закатывание ролл-кейджей, тара рейса

## 2. События, решения, смена

**Смена:** Смена экспедиции.

**Входящие события:**
- Рейс у ворот
- Место под запретом

**Решения:**
- Подтвердить место
- Сообщить, что не помещается

**Сценарии:**

1. *обычный* — **Погрузка.** Скан машины/рейса → скан каждого места → подтверждение.
2. *дефицит/конфликт* — **Место под красным тегом.** Отказ сервера с причиной; место не грузится.
3. *отказ/потеря связи* — **Нет связи.** Повтор того же скана; списание один раз.
4. *передача* — **Смена.** Погружено/осталось старшему.

## 4. UI

- **Первый экран:** Рейс у ворот: мест погружено/всего
- **Главное действие:** Отсканировать место
- **Таблица:** ТСД: место · статус
- **Массовые операции:** Нет
- **Ввод:** Сканер
- **Ошибки, нет данных, нет связи:** Каждый скан — команда с operation_id, сохранённая до отправки; потеря ответа → «результат неизвестен», повтор того же скана; перезагрузка ТСД восстанавливает незавершённую команду; чужая/неверная ячейка — отказ сервера с кодом, крупным текстом
