# Руководитель складских операций

`wh_ops_head` · Управление складскими операциями · группа доступа (предложение): `RL_WH_OPS`
Область назначения: склад · устройства: desktop, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Директор распределительного центра
- **Подчинённые роли:** Начальник кросс-дока, Специалист справочников, Специалист брака, карантина и возвратов, Оператор SAP и документов, Начальник смены
- **Заместитель:** Начальник смены
- **Передача смены / замещение:** Замещает начальник смены по графику; передаются открытые решения по выходу и нормативам.
- **Эскалация:** Директору РЦ — нехватка ресурса, которую не закрыть заменой; повторяющиеся остановки отбора.

**Отвечает за:**
- Нормативы, правила назначения, допуски и графики (ТЗ: начальник склада обеспечивает персонал, технику и правила)
- План выхода на смены
- Профиль РЦ: часы смен, предел восстановления отбора

**Не вправе:**
- Не выполняет задания
- Не утверждает расхождения запаса

## 2. События, решения, смена

**Смена:** Дневная смена; присутствует на передаче вечерней.

**Входящие события:**
- Прогноз потребности выше выхода
- Техника неисправна
- Работа 3–4 уровня ждёт дольше нормы

**Решения:**
- Утвердить/заменить план выхода
- Изменить квалификацию сотрудника
- Изменить норматив

**Сценарии:**

1. *обычный* — **План выхода на завтра.** «Нагрузка и выход»: прогноз по подскладам и способам отбора → план выхода → сохранение с версией. Совмещение ролей не увеличивает фонд времени сотрудника.
2. *дефицит/конфликт* — **Потребность выше выхода.** Замена выхода с причиной; при невозможности — согласование с логистом переноса части комплектации.
3. *отказ/потеря связи* — **Неисправен ричтрак.** Техника исключается из назначения (Ресурсы → техника); очередь и прогноз пересчитываются.
4. *передача* — **Передача смены.** Проверяет у начальника вечерней смены список: волны, красные теги с владельцем, начатые задания с подтверждённым грузом.

## 4. UI

- **Первый экран:** Потребность vs выход по часам и подскладам с подсветкой дефицита
- **Главное действие:** Сохранить план выхода
- **Таблица:** Подсклад · способ · потребность, чел · выход · дефицит · техника
- **Массовые операции:** План выхода сохраняется одной командой с версией
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Конфликт версии — перечитать и создать новую команду; повтор неизвестного исхода — тем же operation_id
