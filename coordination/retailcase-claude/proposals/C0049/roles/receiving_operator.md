# Оператор приёмки

`receiving_operator` · Складское исполнение · группа доступа (предложение): `RL_RECV`
Область назначения: подсклад/участок склада · устройства: ТСД, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Старший участка приёмки
- **Подчинённые роли:** —
- **Заместитель:** Старший участка приёмки
- **Передача смены / замещение:** Незавершённая паллета: отсканированные данные сохранены в команде; передаётся старшему.
- **Эскалация:** Старшему приёмки — расхождение, брак, нет маркировки.

**Отвечает за:**
- Паллетная приёмка по основанию SAP: SSCC/внутренний код, SKU, количество, партия, срок, коды маркировки
- Вложенность HU/CASE

**Не вправе:**
- Не закрывает поставку
- Не сторнирует

## 2. События, решения, смена

**Смена:** По графику поставок.

**Входящие события:**
- Назначена поставка
- Паллета без этикетки
- Код маркировки не принят

**Решения:**
- Принять паллету
- Отложить паллету с причиной

**Сценарии:**

1. *обычный* — **Паллета.** Скан основания → скан SSCC (или печать внутренней этикетки) → SKU, количество, партия, срок → коды по настройке SKU → подтверждение.
2. *дефицит/конфликт* — **Срок годности ниже допустимого.** Сервер отказывает с кодом; паллета откладывается старшему.
3. *отказ/потеря связи* — **Связь пропала после отправки.** «Результат неизвестен»; повтор той же команды; дубль паллеты невозможен.
4. *передача* — **Конец смены.** Незавершённые паллеты — старшему с сохранёнными данными.

## 4. UI

- **Первый экран:** Текущая поставка и следующая паллета
- **Главное действие:** Отсканировать паллету
- **Таблица:** ТСД: одна паллета на экран — SSCC · SKU · кол-во · партия · срок · коды
- **Массовые операции:** Нет
- **Ввод:** Сканер; крупные цели касания ≥ 48 px; ручной ввод только с причиной
- **Ошибки, нет данных, нет связи:** Каждый скан — команда с operation_id, сохранённая до отправки; потеря ответа → «результат неизвестен», повтор того же скана; перезагрузка ТСД восстанавливает незавершённую команду; чужая/неверная ячейка — отказ сервера с кодом, крупным текстом
