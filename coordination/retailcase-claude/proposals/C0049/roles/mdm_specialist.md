# Специалист справочников

`mdm_specialist` · Складское исполнение · группа доступа (предложение): `RL_MDM`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Руководитель складских операций
- **Подчинённые роли:** —
- **Заместитель:** Оператор SAP и документов
- **Передача смены / замещение:** Незавершённые изменения справочников с версией.
- **Эскалация:** Руководителю операций — изменение влияет на волны/укладку; оператору SAP — расхождение с ARTMAS.

**Отвечает за:**
- Склады, ячейки отбора, маршруты, клиенты и правила, профили магазинов, типы машин
- Маркировка по настройкам SKU и профилям Track&Trace (ведётся в WMS)

**Не вправе:**
- Не публикует топологию без права публикации
- Не меняет SKU, которые ведёт SAP

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Новый магазин/адрес
- Новый SKU из ARTMAS без складских настроек
- Изменение маршрута отбора

**Решения:**
- Сохранить профиль магазина
- Изменить ячейку отбора/маршрут

**Сценарии:**

1. *обычный* — **Новый магазин.** Карточка магазина → профиль приёмки (окна, подсобка, ограничения машины) с версией.
2. *дефицит/конфликт* — **Одновременная правка.** Версия устарела → 409 VERSION_CHANGED, перечитать и повторить новой командой.
3. *отказ/потеря связи* — **Справочник не установлен.** Профиль недоступен (503) — показывается причина, форма заблокирована.
4. *передача* — **Незавершённые правки.** Передаются с номером версии и причиной.

## 4. UI

- **Первый экран:** Поиск магазина/SKU и карточка с источниками данных
- **Главное действие:** Сохранить изменение с версией
- **Таблица:** Объект · источник · версия · изменил · когда
- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Повтор тем же operation_id; конфликт версии — перечитать
