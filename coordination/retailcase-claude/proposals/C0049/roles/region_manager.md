# Региональный руководитель магазинов

`region_manager` · Магазины · группа доступа (предложение): `RL_REGION`
Область назначения: регион магазинов · устройства: desktop, планшет · рабочее место: **основного экрана нет**

## 1. Место в организации

- **Руководитель:** Директор логистики сети
- **Подчинённые роли:** Управляющий магазином
- **Заместитель:** Управляющий магазином
- **Передача смены / замещение:** Открытые расследования поставок ветви.
- **Эскалация:** Директору логистики — систематические недостачи/опоздания в регион.

**Отвечает за:**
- Качество поставок магазинам ветви: опоздания, недостачи, возвраты

**Не вправе:**
- Не подписывает акты и не утверждает потери магазинов

## 2. События, решения, смена

**Смена:** Рабочий день.

**Входящие события:**
- Расследование поставки открыто
- Опоздание доставки

**Решения:**
- Эскалировать проблему РЦ/транспорту

**Сценарии:**

1. *обычный* — **Обзор ветви.** Поставки магазинов ветви: приняты/с расхождением/расследования.
2. *дефицит/конфликт* — **Повторные недостачи магазина.** Переход к расследованиям; эскалация директору РЦ.
3. *отказ/потеря связи* — **Нет данных.** Область REGION ещё не реализована — экран недоступен.
4. *передача* — **Замещение.** Временное назначение управляющему крупного магазина.
