# Контролёр остатков (КРО)

`stock_controller` · Запас, качество, возвраты и тара · группа доступа (предложение): `RL_STOCK_CTL` · действующие legacy-группы: `STOCK_MANAGER`
Область назначения: склад · устройства: desktop · рабочее место: **основного экрана нет**

## 1. Место в организации

- **Руководитель:** Директор распределительного центра
- **Подчинённые роли:** Инвентаризатор
- **Заместитель:** Инвентаризатор
- **Передача смены / замещение:** Открытые расследования и ревизии с результатами пересчётов.
- **Эскалация:** Директору РЦ — расхождение выше порога, признаки хищения.

**Отвечает за:**
- Ревизии и планы пересчётов (ТЗ: КРО отвечает за инвентаризацию, расследование потерь, утверждение корректировок)
- Утверждение расхождений выше порога
- Расследования недостач с камерами

**Не вправе:**
- Не утверждает расхождение, которое сам пересчитывал

## 2. События, решения, смена

**Смена:** Дневная; ночные ревизии по плану.

**Входящие события:**
- Расхождение пересчёта
- Недостача комплектации подтверждена
- Расхождение межсклада/магазина

**Решения:**
- Назначить повторный пересчёт другим инвентаризатором
- Утвердить расхождение
- Закрыть расследование

**Сценарии:**

1. *обычный* — **Плановая ревизия.** Ревизия склада/зоны → задания инвентаризаторам → результаты → разбор расхождений.
2. *дефицит/конфликт* — **Расхождение выше порога.** Повторный пересчёт другим сотрудником; утверждение — stock_adjust_approve (сейчас результат проводится сразу — GAP, второго подтверждения нет).
3. *отказ/потеря связи* — **Ядро вернуло RESULT_UNCERTAIN.** Результат пересчёта неизвестен; повтор тем же operation_id; новая ревизия не создаётся.
4. *передача* — **Передача расследования.** Результаты пересчётов, фрагменты камер, выводы.

## 4. UI

- **Первый экран:** Расхождения по ключу (SKU, партия, ячейка) в базовой единице с автором пересчёта
- **Главное действие:** Назначить повторный пересчёт / утвердить (после реализации)
- **Таблица:** Ключ · учёт · факт · Δ (базовая ед.) · кто считал · когда · статус
- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Неизвестный исход — повтор, не новая ревизия
