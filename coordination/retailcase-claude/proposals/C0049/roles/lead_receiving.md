# Старший участка приёмки

`lead_receiving` · Управление складскими операциями · группа доступа (предложение): `RL_ST_RECV` · действующие legacy-группы: `ST_PRIEMO_SD`
Область назначения: подсклад/участок склада · устройства: desktop, планшет, ТСД · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Начальник смены
- **Подчинённые роли:** Оператор приёмки
- **Заместитель:** Оператор приёмки
- **Передача смены / замещение:** Открытые поставки: частичный факт, этикетки, размещения без исполнителя.
- **Эскалация:** Начальнику смены — ворота/люди; оператору SAP — нет основания; старшему контроля — брак/маркировка.

**Отвечает за:**
- Приёмка только по разрешённому основанию SAP
- Сверка и закрытие поставки (факт в SAP через outbox)
- Перепланирование размещения

**Не вправе:**
- Не сторнирует приёмку, в которой сам подтверждал паллеты

## 2. События, решения, смена

**Смена:** По графику поставок.

**Входящие события:**
- Поставка SAP разрешена/изменена
- Машина поставщика прибыла
- Расхождение количества/партии/срока
- Нет обязательной маркировки

**Решения:**
- Закрыть поставку с расхождением
- Переоткрыть поставку
- Перепланировать размещение

**Сценарии:**

1. *обычный* — **Поставка.** Поставка SAP → приёмщики принимают паллеты (SSCC/внутренний код, количество, партия, срок, коды) → старший закрывает поставку → задания размещения.
2. *дефицит/конфликт* — **Недопоставка.** Факт меньше основания: закрытие с расхождением; подтверждение SAP уходит через outbox асинхронно.
3. *отказ/потеря связи* — **Факт не ушёл в SAP.** Ошибка в «Внешних отправках»; повтор — у специалиста интеграций; проводка не дублируется.
4. *передача* — **Передача поставок.** Список поставок с частичным фактом и паллетами без размещения.

## 4. UI

- **Первый экран:** Поставки дня: ворота, принято/ожидается, расхождения, статус SAP
- **Главное действие:** Закрыть сверенную поставку
- **Таблица:** Поставка · поставщик · ворота · паллет принято/ожидается · расхождение · статус SAP
- **Массовые операции:** Нет
- **Ввод:** Планшет/ТСД: сканирование
- **Ошибки, нет данных, нет связи:** Повтор закрытия тем же operation_id; outbox-ошибка не отменяет проведённый факт
