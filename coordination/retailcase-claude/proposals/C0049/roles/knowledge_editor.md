# Редактор базы знаний

`knowledge_editor` · Финансы, аналитика, ИТ и контроль · группа доступа (предложение): `RL_KNOWLEDGE`
Область назначения: вся сеть · устройства: desktop · рабочее место: **реализуется в C0056 (блок 4)**

## 1. Место в организации

- **Руководитель:** Администратор доступа
- **Подчинённые роли:** —
- **Заместитель:** —
- **Передача смены / замещение:** Черновики с причиной.
- **Эскалация:** Публикатору — статья с изменением прав чтения.

**Отвечает за:**
- Черновики пользовательских статей (knowledge_edit)
- Публикация/архив и права чтения — у роли с knowledge_publish

**Не вправе:**
- Редактор не расширяет права чтения статьи

## 2. События, решения, смена

**Смена:** Рабочий день.

**Входящие события:**
- Новое действие UI без статьи
- Изменение процесса

**Решения:**
- Сохранить черновик
- Опубликовать (publisher)

**Сценарии:**

1. *обычный* — **Статья.** Черновик → preview безопасного текста → публикация publisher-ом.
2. *дефицит/конфликт* — **Версия изменилась.** 409 → перечитать; черновик в браузере не теряется.
3. *отказ/потеря связи* — **Неизвестный исход.** Квитанция по operation_id.
4. *передача* — **Передача.** Черновики.

## 4. UI

- **Первый экран:** Список статей по пространствам и статусам
- **Главное действие:** Сохранить черновик
- **Таблица:** Статья · пространство · статус · версия · изменил
- **Массовые операции:** Нет
- **Ввод:** Мышь/клавиатура
- **Ошибки, нет данных, нет связи:** Локальный черновик сохраняется до подтверждения сервера
