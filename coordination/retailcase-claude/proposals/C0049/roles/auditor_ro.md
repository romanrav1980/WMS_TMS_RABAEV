# Аудитор (только чтение)

`auditor_ro` · Финансы, аналитика, ИТ и контроль · группа доступа (предложение): `RL_AUDITOR`
Область назначения: именованная группа объектов одного вида · устройства: desktop · рабочее место: **основного экрана нет**

## 1. Место в организации

- **Руководитель:** Директор логистики сети
- **Подчинённые роли:** —
- **Заместитель:** —
- **Передача смены / замещение:** Не сменная.
- **Эскалация:** Владельцу процесса — найденное отклонение.

**Отвечает за:**
- Чтение документов, журналов и истории в назначенной области

**Не вправе:**
- Не выполняет команды
- Не видит конфигурацию доступа других (кроме объяснения своего)

## 2. События, решения, смена

**Смена:** По плану аудита.

**Входящие события:**
- Плановая проверка

**Решения:**
- Зафиксировать отклонение

**Сценарии:**

1. *обычный* — **Проверка.** История операций и документов в области назначения.
2. *дефицит/конфликт* — **Чтение под правом изменения.** Часть GET сейчас требует edit-права (findings §4) — аудитор их не получит до исправления.
3. *отказ/потеря связи* — **Нет доступа.** Explain показывает причину.
4. *передача* — **Передача.** Отчёт аудита.
