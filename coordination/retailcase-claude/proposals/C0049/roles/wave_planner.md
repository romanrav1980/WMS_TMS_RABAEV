# Планировщик волн и обеспечения

`wave_planner` · Складское исполнение · группа доступа (предложение): `RL_WAVE_PLAN`
Область назначения: склад · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Начальник смены
- **Подчинённые роли:** —
- **Заместитель:** Начальник смены
- **Передача смены / замещение:** Волны в черновике/рассчитанные, необеспеченные строки.
- **Эскалация:** Начальнику смены — волна не обеспечивается; логисту — нужно изменить рейс.

**Отвечает за:**
- Формирование и расчёт волн по транспортному плану
- Анализ дефицита и резервов

**Не вправе:**
- Не запускает волну — запуск у начальника смены

## 2. События, решения, смена

**Смена:** До старта ричтраков по профилю РЦ.

**Входящие события:**
- Транспортный план готов
- Дефицит запаса по строкам
- Изменение рейса

**Решения:**
- Создать и рассчитать волну
- Отменить волну
- Предложить перенос строк

**Сценарии:**

1. *обычный* — **Волна по плану.** Создать волну → расчёт → план отбора и потребность пополнения → передача начальнику смены на запуск.
2. *дефицит/конфликт* — **Дефицит.** Необеспеченные строки показаны с причиной; решение — пополнение или перенос с логистом.
3. *отказ/потеря связи* — **Расчёт не завершён.** Неизвестный исход — повтор тем же operation_id; дубль волны не создаётся.
4. *передача* — **Передача.** Волны и их статусы начальнику смены.

## 4. UI

- **Первый экран:** Волны смены и их обеспеченность
- **Главное действие:** Рассчитать волну
- **Таблица:** Волна · рейсы · заказов · строк · обеспечено · дефицит · статус
- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Расчёт — команда с operation_id; повтор без дубля
