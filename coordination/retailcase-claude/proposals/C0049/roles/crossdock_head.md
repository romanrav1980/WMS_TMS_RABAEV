# Начальник кросс-дока

`crossdock_head` · Запас, качество, возвраты и тара · группа доступа (предложение): `RL_XDOCK`
Область назначения: склад · устройства: desktop, планшет · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Руководитель складских операций
- **Подчинённые роли:** —
- **Заместитель:** Старший участка экспедиции
- **Передача смены / замещение:** Межскладские машины: выгружено/принято/развезено, несоответствия.
- **Эскалация:** Логисту/диспетчеру — несоответствие SSCC, место без целевого рейса.

**Отвечает за:**
- Приёмка и консолидация межскладского подвоза (ТЗ процесс 8)
- Несоответствия по SSCC

## 2. События, решения, смена

**Смена:** По графику межскладских рейсов.

**Входящие события:**
- Межскладская машина прибыла
- SSCC не из плана
- Недостача по плану

**Решения:**
- Принять место
- Зарегистрировать недостачу/несоответствие

**Сценарии:**

1. *обычный* — **Межсклад.** Выгрузка → приёмка каждого SSCC → развозка к воротам целевого рейса.
2. *дефицит/конфликт* — **Недостача по плану.** Отчёт о недостаче; подтверждение — по межскладскому сценарию.
3. *отказ/потеря связи* — **Нет связи.** Повтор приёмки тем же operation_id.
4. *передача* — **Передача.** Статус каждой машины.
