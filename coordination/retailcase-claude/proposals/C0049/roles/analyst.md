# Аналитик

`analyst` · Финансы, аналитика, ИТ и контроль · группа доступа (предложение): `RL_ANALYST`
Область назначения: именованная группа объектов одного вида · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Директор логистики сети
- **Подчинённые роли:** —
- **Заместитель:** —
- **Передача смены / замещение:** Не сменная.
- **Эскалация:** Владельцу показателя — расхождение источников.

**Отвечает за:**
- Подготовка паспортов KPI и проверка источников (KPI не утверждены)

**Не вправе:**
- Только чтение

## 2. События, решения, смена

**Смена:** Дневная.

**Входящие события:**
- Запрос показателя

**Решения:**
- Предложить паспорт KPI

**Сценарии:**

1. *обычный* — **Паспорт KPI.** Поля, период, область, знаменатель 0 → предложение владельцу.
2. *дефицит/конфликт* — **Источники расходятся.** Фиксирует оба источника, не усредняет.
3. *отказ/потеря связи* — **Нет агрегата.** GAP фиксируется, значение не подставляется.
4. *передача* — **Передача.** Паспорта и статусы.

## 4. UI

- **Первый экран:** Показатели и их источники
- **Главное действие:** Открыть источник

- **Массовые операции:** Нет
- **Ввод:** Мышь
- **Ошибки, нет данных, нет связи:** Только чтение
