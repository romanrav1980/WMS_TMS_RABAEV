# Водитель ричтрака

`reach_driver` · Складское исполнение · группа доступа (предложение): `RL_REACH` · действующие legacy-группы: `SHTABELER`
Область назначения: подсклад/участок склада · устройства: ТСД · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Старший участка хранения и пополнения (диспетчер ричтраков)
- **Подчинённые роли:** —
- **Заместитель:** Водитель погрузчика
- **Передача смены / замещение:** Начатое задание: подтвердить положение паллеты, затем передача.
- **Эскалация:** Диспетчеру ричтраков — неисправность, адрес занят/недоступен.

**Отвечает за:**
- Размещение, мини-макс, пополнение волн, срочные подачи, перемещения
- Подтверждение физических этапов: взял/поставил

## 2. События, решения, смена

**Смена:** Смена ричтраков по профилю РЦ.

**Входящие события:**
- Новое задание (приоритет)
- Адрес назначения занят
- Неисправность техники

**Решения:**
- Принять задание
- Сообщить о препятствии

**Сценарии:**

1. *обычный* — **Подача под волну.** Принять задание → скан исходной ячейки и паллеты → скан целевой ячейки → подтверждение.
2. *дефицит/конфликт* — **Целевая ячейка занята.** Препятствие с причиной; старший перепланирует.
3. *отказ/потеря связи* — **Потеря связи на подтверждении.** Повтор того же скана; ресурс в последнем состоянии до сверки.
4. *передача* — **Конец смены.** Начатое — только после подтверждения положения паллеты.

## 4. UI

- **Первый экран:** Текущее задание крупно: откуда → куда, SKU, паллета
- **Главное действие:** Отсканировать ячейку/паллету
- **Таблица:** ТСД: одно задание на экран
- **Массовые операции:** Нет
- **Ввод:** Сканер, цели ≥ 48 px
- **Ошибки, нет данных, нет связи:** Каждый скан — команда с operation_id, сохранённая до отправки; потеря ответа → «результат неизвестен», повтор того же скана; перезагрузка ТСД восстанавливает незавершённую команду; чужая/неверная ячейка — отказ сервера с кодом, крупным текстом
