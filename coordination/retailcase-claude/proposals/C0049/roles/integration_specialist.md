# Специалист интеграций

`integration_specialist` · Финансы, аналитика, ИТ и контроль · группа доступа (предложение): `RL_INTEGR`
Область назначения: вся сеть · устройства: desktop · рабочее место: **работает на существующих экранах без ролевой главной**

## 1. Место в организации

- **Руководитель:** Администратор доступа
- **Подчинённые роли:** —
- **Заместитель:** Оператор SAP и документов
- **Передача смены / замещение:** Сообщения outbox в ошибке.
- **Эскалация:** Администратору — сбой внешней системы.

**Отвечает за:**
- Асинхронный inbox/outbox, повтор отправок
- Журнал API

## 2. События, решения, смена

**Смена:** Рабочий день.

**Входящие события:**
- Сообщение outbox в ошибке

**Решения:**
- Повторить отправку

**Сценарии:**

1. *обычный* — **Outbox.** Сообщения отправлены; ошибки — разбор.
2. *дефицит/конфликт* — **Повтор с изменённым содержимым.** Не допускается; повтор исходного сообщения.
3. *отказ/потеря связи* — **SAP недоступен.** Сообщения ждут; товарный факт уже проведён.
4. *передача* — **Передача.** Сообщения в ошибке.
