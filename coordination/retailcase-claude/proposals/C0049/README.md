## Как собирается

`python tools/catalog/build.py` из этой папки. Источник — `tools/catalog/roles_*.py`; Markdown и JSON генерируются, руками не правятся. Генератор отказывает, если:
- экран или маршрут не существует;
- у команды право не совпадает с маршрутом;
- изменяющий маршрут указан не как команда;
- нет одного из восьми разделов рабочего места или четырёх типов сценариев;
- право неизвестно;
- у KPI нет единицы, полей, периода, области или правила нулевого знаменателя;
- одна роль нарушает правило SoD человека.

## Итог на 15.10.2026

- 41 роль: все обязательные из TASK_C0049, плюс начальник кросс-дока и редактор знаний.
- 168 сценариев; у каждой роли есть обычный, конфликт/дефицит, отказ связи и передача.
- 42 команды: путь, право, вход, результат и правило повтора сверены с маршрутами.
- 131 явный GAP.
- Права: 164 упоминания действующих прав API, 12 — прав API без групп, 29 — legacy, 10 — новых.
