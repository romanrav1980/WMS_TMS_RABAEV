## Ограничения и точные пробелы

- **Магазин:** новая полная приёмка с сохранением ручного веса на сервере не проверялась — по контракту это задача Codex. Мои проверки — только UI fixtures.
- **Dev-адрес справки:** на порту 3010 путь `/help/*` не проксируется на API и отдаёт оболочку приложения. В production (`8088/store/`, same origin) справка отвечает 200. Нужен прокси `/help` в `terminal/wms_terminal_web/vite.config.ts` (файл root).
- **Экран погрузки на 390 px** шире экрана на 22 px из-за давней формы входа `adminLoginForm` (`admin-auth`), не из-за новой группы.
- **Консолидация:**
  - живые PUT и cancel не выполнялись (запрещены live-мутации), формат и семантика проверены на перехвате;
  - отмена плана в UI есть, но перехватом проверено только сохранение;
  - тексты отказов знают только `CONSOLIDATION_VERSION_CONFLICT` — остальные коды показываются как есть, с просьбой перечитать план;
  - `WarehousePicker` выбирает склады по возможности `warehouse_tasks` из `/api/access/workspaces`: отдельной возможности «консолидация» в контракте навигации нет, права всё равно проверяет сервер.
- Физические весы, телефон и SHIPPING_GROSS не заявляются.
