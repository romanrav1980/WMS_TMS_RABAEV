## Ограничения (по контракту, не скрыты в UI)

- Не больше 50 строк, без `has_more`/cursor/total: при 50 полнота неизвестна.
- Без `ware_id` сервер читает все разрешённые склады — так работает только обзор директора, и он так подписан. Сменный обзор всегда передаёт выбранный склад.
- Недоступный склад — 403 (не 404). Даты без пояса и без `time_status`. `remaining_seconds`/`age_seconds` — значения снимка, не живой SLA. Опроса и автоматических команд нет.
- На живом стенде открытых недостач нет: положительные состояния проверены только на UI fixtures.
- Общая плавающая кнопка «? Справка» (фиксированный угол экрана) при прокрутке может перекрывать край правой колонки. Это давнее поведение общей панели справки, не новой разметки.
- Для задания сборки и волны нет внешнего экрана с точным параметром: показан идентификатор, волна открывается на рабочем месте старшего смены.
