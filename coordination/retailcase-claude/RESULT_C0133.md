## Что сделано (расширение `page=tradecase`, без второго приложения)

- **Вкладки «Поставки» и «Запас».** На схеме этап «Склад» теперь открывает реальный запас. На 390 px схему скрыл стилем Codex, там запас открывается вкладкой.
- **Запас** — серверные группы `stock/pallets` с курсором.
  - Колонки: «Идентификатор паллеты», адрес, товар, собственник, МРЦ, срок, количество с единицей, резерв, коды «подтверждено / ожидает / отклонено».
  - Группы одного идентификатора не склеиваются.
  - Итог посчитан точной суммой десятичных строк через BigInt, без округления, отдельно для каждой единицы. Подпись: «Итого на этой странице … Это не общий остаток склада; групп: N».
  - Названия товара и собственника берутся из уже прочитанной НСИ, иначе показывается исходный код.
- **Карточка поставки:** паллета, товар, собственник, МРЦ, партия, срок, заказ и строка SAP, «N кодов маркировки». Сами коды и JSON — только в технических сведениях.
- **Привязка** (`Bind.tsx` и `bindIntent.ts`):
  - **Ввод скана:** поле «Идентификатор паллеты» (допускает legacy), сканер вводит текст и Enter, или кнопка «Проверить».
  - **Проверка перед записью:** экран показывает конкретные данные — паллета, товар, собственник, МРЦ, срок, партия, поставка и версия. Отдельно: «не принимает товар физически, не подтверждает коды в СКМ и не выкупает». Если паллета не совпадает с поставкой, будет предупреждение; решает сервер.
  - **Тело команды:** `supply_id` и `expected_supply_version` берутся из открытой карточки, `operator_id` не спрашивается. `operation_id` (`TC.BIND.UI:<uuid>`) создаётся один раз и сохраняется вместе с телом **до** отправки.
  - **Где хранится намерение:** ключ — API + пользователь (`/api/access/navigation`) + склад, поэтому чужое намерение не воспроизводится. Пароль не хранится.
  - **Неизвестный результат** (сеть или 5xx): команда сохранена, тело не редактируется, новая привязка на складе не начинается. После перезагрузки — «Сохранённая команда привязки» и «Повторить ту же команду» с тем же телом и тем же `operation_id`; повтор с `replayed` засчитывается.
  - **Отказ 403/409/422 на первой отправке:** понятная причина (`TRADE_OWNER_ACCESS_DENIED`, `TRADE_SITE_DISABLED`, `VERSION_CONFLICT`, `OPERATION_CONFLICT`; неизвестный код — в технических сведениях), команда снята, возврат к скану.
  - **403 после неизвестного исхода:** команда сохраняется, повторить её можно после восстановления прав.
  - **Повреждённая запись** не перезаписывается и блокирует новую привязку.
  - **Двойной клик** отсекается синхронной блокировкой через `ref`.
  - Кнопки ручного подтверждения кодов СКМ нет.
- **Справка `/help/tradecase-documents.html`.** Новые разделы: запас (группы, итог страницы, статусы СКМ), поставка и привязка (скан, проверка, результат), неизвестный результат, отказ и права. Схема и список вкладок обновлены. Каждый абзац описывает действие или результат; источники — wiki и Google Docs по кейсу.
- **Подсказки:** у каждой кнопки есть `title`, `data-help-id` и `data-help-url`.
