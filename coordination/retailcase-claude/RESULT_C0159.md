# RESULT C-0159 — готовность волн и риски смены (Claude). Checkpoint `b664f757`

Только read-only UI рабочего места старшего смены. Backend и native не менялись, BACKEND_READY не требуется: используются существующие API. Весь T10 этим пакетом не закрывается.

## Матрица требований и существующего обзора
Источник: программа rev27, строка 41 («управление сменой — допуски, приоритеты, очереди, производительность, готовность заказов, причины задержек»), а также TASK_C0159: обеспечение, пополнение, ресурсы, контроль, сроки рейса.

| Требование | До C-0159 | Сейчас |
|---|---|---|
| Обеспечение | missing_base pick-readiness; блокировки SHORTAGE/STAGING/CASE_PICK/DOMAIN_SYNC | без изменений |
| Пополнение | блокировка REPLENISHMENT; ожидание с wait_reason (DONE/CANCELLED не считаются) | без изменений |
| Отбор разрешён | риск «отбор не разрешён» | без изменений |
| Контроль | **не было** | `Ждут контроля: N коробов` — видимые WAIT_CONTROL/CONTROL_IN_PROGRESS запущенной волны |
| Назначение ресурсов | остановленная сборка, недостачи; назначения без времени не объявлялись свободными | `Задания без исполнителя: N` — NEW без assigned_to в волне с разрешённым отбором; во «влиянии» указано число открытых сессий CASE_PICKER (факт входа, не свободность); при отказе или обрезке списка сессий — «не проверены полностью» и пробел проверки |
| Сроки | только «время не утверждено» | по **утверждённому** плану (APPROVED, моменты с поясом) против `observed_at` сервера: окончание прошло у LAUNCHED (блокирует), начало прошло у PREVIEW (внимание); без плана или без часов сервера опоздание не вычисляется |
| DONE/CANCELLED | рисков подготовки нет | новые риски тоже только для LAUNCHED (сроки начала — для PREVIEW) |
| Скрытые задания | фильтр сервера до лимита | счёт только по видимым; при обрезанной выборке (200) — «не меньше N» |

Сроки рейса как таковые (выезд транспорта) отдельным источником в обзоре волны не читаются. Используется утверждённое время волны: по источникам оно рассчитывается от времени отгрузки.

## Ограничения
- Кнопки действий рисков открывают legacy raw-экраны (`case-pick-management.html`, `wave-replenishment.html`, `resource-workload.html`). Эти страницы не читают параметры адреса, поэтому выбранную волну открывает кнопка «Волна» (карточка волны в приложении). Это существующее ограничение, оно касается и прежних рисков.
- Список сессий читается с лимитом API 100, включая закрытые. При 100 строках наличие открытых сессий не утверждается.
- Производительность, приоритеты и полный набор ресурсов (техника, прочие роли) не добавлены: подтверждённых источников норм нет. Проверено на имеющихся CASE-данных, все ресурсы этим не проверены.
- SQL не добавлялся. Смена со всеми чтениями готова за 2.5 с на 1440 (вход и живые чтения локального API; не SLA).
