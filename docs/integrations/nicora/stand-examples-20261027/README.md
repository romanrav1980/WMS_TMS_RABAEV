# NICORA: синтетические примеры

Все товары, адреса, заказы и настройки придуманы для проверки формата. Не загружать в продуктивную систему. CSV — предлагаемый нейтральный профиль, а не фиктивный IDoc SAP.

Прочитайте passport.json, manifest.json и field_dictionary.csv. expected_order_import.csv и expected_controls.json — ожидаемые результаты, не вход SAP. Реальные коды единиц сопоставьте через uom_mapping.csv. Массы/габариты неизвестны и не заполнены произвольными числами; для транспортной проверки передайте настоящие настройки отдельно.

Продажи: 31 день [2026-10-28,2026-11-28). Горизонт добивки примера отсчитывается от планового отправления в календаре адреса; подтвердить правило в паспорте реального источника. Прогноз продаж не заменяет прогноз перемещений.
