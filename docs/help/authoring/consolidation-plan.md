# Контекстная помощь: ожидаемый состав

Публикация: `article_id=consolidation-plan`, `/api/help/articles/consolidation-plan`.
Источник: [актуальная карточка](../../../wiki/database/retailcase_consolidation_manifest_20261016.md).
Действующий механизм: штатные ARTICLE_SAVE/PUBLISH → Oracle published revision →
`/api/help/articles` → панель справки. `docs/help/published.json` сохраняет исходный
подготовленный текст; runtime override читает Oracle, изменение файла само не публикует статью.
Это контракт для будущего экрана, не свидетельство готового UI.

| Действие/help_id | Короткая подсказка | Результат |
|---|---|---|
| `consolidation-plan.save` | Сохранить ожидаемые сборки и целевую ячейку. Товар не перемещается. | PUT сохраняет версию плана и неизменяемый ACK |
| `consolidation-plan.refresh` | Перечитать план и проверить, все ли сборки находятся в нужной паллете. | GET возвращает план и readiness |
| `consolidation-plan.cancel` | Отменить план с сохранением истории. Физическая паллета останется собранной. | POST cancel; обязательна причина |
| `consolidation-plan.help` | Открыть правила консолидации и объяснение проверок состава. | Открыть статью, сохранив рабочий экран и объект |

Все четыре help_id должны вести в эту статью через действующий UI help resolver.
Кнопки пока не созданы; строка таблицы не объявляет существующий binding.

Статусы участника: NOT_PICKED — «Не собрана»; MISSING — «Отсутствует»;
IN_ROOT — «В составе»; SHIPMENT_CHANGED — «Изменилось задание»;
REQUEST_CHANGED — «Изменились строки задания»; NOT_CURRENT_PICKED —
«Сборка больше не готова»; BINDING_CHANGED — «Изменилась привязка сборки».
При location_ready=false показывать целевой склад/ячейку и отсутствие прибытия.
ready=true подписывать «Состав полон». Не выводить «Можно отгружать» по этому полю.

Одна незавершённая команда хранит неизменное тело и operation_id до установления
исхода; uncertain503 предлагает повтор той же команды. После409 версии экран
перечитывает план, показывает конфликт и позволяет подготовить новое изменение.
Автоматическое сохранение поверх чужой версии запрещено.403 очищает закрытые
данные и прекращает повторы; чтение инструкции само не выдаёт складских прав.
