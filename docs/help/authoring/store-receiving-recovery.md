Отправленная команда сохраняется на устройстве до получения ответа сервера. Если ответ не пришёл (обрыв связи, перезагрузка страницы, переход в офлайн), не вводите данные заново: откройте ту же поставку и нажмите «Повторить сохранённую операцию». Команда уйдёт с тем же номером операции, повторной приёмки не будет.

Отказ сервера не всегда означает, что ничего не изменилось. Если сервер прислал подтверждённый структурированный отказ с тем же номером операции, появится пояснение и кнопка «Исправить данные после отказа»: тогда можно поменять количества, фото или сканы и отправить исправленную команду. Если структурированного подтверждения нет (разрыв связи, пустой ответ, ошибка прокси), приложение не считает это отказом — оно хранит исходную команду и предлагает только повтор.

Повреждённая локальная запись (например, испорченное хранилище браузера) блокирует новую отправку. Перечитайте поставку: если сервер сохранил акт, приложение покажет его. Если результат не установлен, обратитесь к диспетчеру; повреждённая запись сама по себе не разрешает создавать новую приёмку.

Если при исправлении после отказа сервер показал другой состав или другую стратегию приёмки, старый ввод не переносится автоматически — он остаётся на экране для сверки, а поставку нужно открыть заново для новой формы.

При отказе доступа (401/403) приложение выходит из сессии и очищает магазины, поставки и просмотренный состав — чужая или просроченная сессия не должна показывать старые данные.
