# RETAILCASE: атлас работы

Локальный статический сайт: сквозной регламент, 43 проекта должностных инструкций,
рабочие дни, экраны, структура подчинения и учебная поставка от рейса до магазина.

## Открыть локально

Запустите `start.bat` из этой папки либо из корня репозитория:

```powershell
python -m http.server 4175 --bind 127.0.0.1 --directory docs/retailcase-guide
```

Адрес: http://127.0.0.1:4175/ . Сервер раздаёт только папку сайта и не обращается к Oracle.
Другие приложения не останавливаются. Если порт занят этим сайтом, откройте существующий адрес.
Можно открыть `index.html` напрямую: все данные, стили, изображения и шрифты локальны.

Главные адреса:

- `#flow` — полный процесс;
- `#roles` — каталог должностей;
- `#role/picker` — комплектовщик;
- `#role/shift_supervisor` — начальник смены;
- `#role/route_planner/instruction/duties` — обязанности маршрутного планировщика;
- `#role/route_planner/screens` и `#role/route_planner/day` — его экраны и рабочий день;
- `#org` — подчинение;
- `#example/0` — сквозной пример;
- `#manual/processes` — полный регламент для печати / PDF;
- `#manual/roles` — полный сборник должностных инструкций для печати / PDF;
- `#sources` — основания и сопоставление TRADECASE / RETAILCASE.

В приложении есть полнотекстовый поиск с Enter, фильтр должностей,
переходы роль → процесс → экран, увеличение снимков, мобильное меню и печать.

Редакция 2.0 (19.10): тёмный изометрический центр процессов. На главной —
интерактивная SVG-проекция склада, процессы слева, карточка этапа справа и
учебный Гант ричтраков/комплектовщиков/ворот/машин снизу. Выбор объекта или
процесса меняет подсветку и карточку; кнопки масштаба изменяют вид схемы.
Схема учебная, реальные координаты, телеметрия и занятость не имитируются.
На телефоне панели идут последовательно; карточка не ограничена высотой экрана.

## Источники и редактура

`СНС/BLC` — **TRADECASE**, торгово-производственный кейс. Он дал общую карту BP01–BP15.
Выкуп BP07, смена owner, время запуска выкупа и специальные правила BLC не являются
автоматически правилами RETAILCASE. Решение владельца об этом принято 18.10.2026.

Каталог C0049 содержит 41 роль. Атлас дополняет его технологом и координатором
консолидации и предлагает отдельные административные линии розницы, ИТ и финансов.
Это проект организационного регламента, а не утверждённое штатное расписание.
Исторические KPI каталога не экспортируются: действуют паспорта V2 от 17.10.

- `content.js` — поддерживаемая редакция процессов, экранных инструкций и источников.
- `job-profiles.js` — профили 43 должностей: назначение, знания, 272 обязанности, результат, риски и партнёры. Не заменять кратким `resp` исторического каталога.
- `job-authority.js` — отредактированные полномочия, ответственность, контроль и передача работы по каждой должности. Служебные имена прав из каталога в инструкциях не отображаются.
- `screen-links.js` — общие адреса экранов для должностных и экранных инструкций.
- `job-instructions.js` — восемь разделов полной должностной инструкции и вкладки инструкции/экранов/дня; один текст для отдельной должности и печатного сборника.
- `app.js` — навигация, рабочие дни, сквозной пример и представление документов.
- `isometric.css` — изометрическая тема, адаптивная и печатная вёрстка; стили навигации ограничены своим контейнером.
- `twin.js` — SVG-сцена, выбор этапа, карточка ответственного, масштаб и учебный график ресурсов.
- `build.py` — локальная сборка `data.js` из каталога и копирование выбранных архивных снимков.
- `data.js` — подготовленные данные для просмотра без Python и API.
- `assets/` — девять архивных скриншотов, значок сайта; иллюстрации также рисуются SVG в коде.

Пересборка из checkout:

```powershell
python docs/retailcase-guide/build.py
```

Не заменяйте текущие статусы непроверенными утверждениями из исторического каталога.
Точные часы смены, KPI вне принятого паспорта и независимые финансовые решения
утверждаются отдельно. Примеры и иллюстрации обозначены учебными, архивные снимки
не выдаются за один исполненный маршрут. Печать показывает весь выбранный сборник.

## Публикация на GitHub Pages

Поручение на публикацию получено 19.10.2026. Адрес сайта:
https://romanrav1980.github.io/WMS_TMS_RABAEV/ .
Для размещения используется ветка `gh-pages`, корень `/`. Загружать только:
`index.html`, `isometric.css`, `twin.js`, `data.js`, `content.js`, `job-profiles.js`, `job-authority.js`, `screen-links.js`, `job-instructions.js`, `app.js`, `.nojekyll`, `assets/`.
Hash-маршруты и относительные пути работают в подкаталоге репозитория.
Сборщик `build.py`, `qa/`, служебный `start.bat` и сырой репозиторий для хостинга не нужны.

Перед внешней публикацией проверить внутренние сведения на архивных скриншотах,
права на их распространение и целевую аудиторию. Raw SAP/SAP_INTEGRATION-проекты,
настройки подключения, пароли, журналы API и сырые Oracle-отчёты не включены в сайт.
Ссылки «Открыть экран» ведут в локально установленную систему. Для размещённого
стенда адреса меняются в `screen-links.js`; публикация описания не выдаёт доступ.

Для обновления документа, читаемого на GitHub, выполните `node docs/retailcase-guide/export-guide.cjs`.
Команда переносит тексты из тех же данных в `WORK-IN-SYSTEM.md`; её запуск не публикует изменения.
