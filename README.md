# NICORA WMS/TMS — описание системы и исходный код

NICORA развивает существующие WMS/TMS для распределительного центра и розничной сети: приёмка по SAP, складское исполнение, транспорт, доставка магазинам, возвраты, тара и расчёты.

- [Новый заказ: роли торговой сети и ролевые UI — Claude Code](coordination/nicora-claude/TASK_C0049.md)

Текущий согласованный кодовый объём 18 спринтов реализован. Реальные внешние интеграции, оборудование, независимая приёмка и промышленный пилот имеют отдельные статусы. Ролевой UX C-0049 — новый объём, не завершённая часть текущего релиза.

В репозитории находятся исходники и SQL. Локальные проекты SAP/SAP_INTEGRATION, секреты, рабочие сообщения, остатки, движения и двоичные дампы не публикуются. Исторические SQL и примеры могут содержать известные dev-значения; для новой установки задайте свои пароли.
