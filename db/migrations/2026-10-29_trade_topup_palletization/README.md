# T08: паллетизация SKU для добивки

Настройка хранит на площадке тип паллеты, число коробов на место и допустимое число слоёв. Расчёт добивки читает только активную строку для каждого SKU. Без строки предложение не создаётся.

Откат разрешён только без строк настройки. Он не меняет предложения, резервы или рейсы.
