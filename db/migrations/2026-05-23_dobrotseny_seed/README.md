# Seed «Добра Цен» — тестовые данные для транспортного модуля

## Что создаётся

| Файл | Данные |
|------|--------|
| `046_apply.sql` | 3 склада, ~36 000 ячеек, ~1 350 артикулов |
| `047_apply.sql` | 77 адресов магазинов, 15 ТС, 15 водителей, ~385 СТ готовых к отгрузке |

## Склады

| ID | Название | Префикс | Город |
|----|---------|---------|-------|
| 9201 | ДЦ-Пермь | ДЦП | Пермь, Пермский край |
| 9202 | ДЦ-Екатеринбург | ДЦЕ | Екатеринбург, Свердловская обл. |
| 9203 | ДЦ-Тюмень | ДЦТ | Тюмень, Тюменская обл. |

**Ячейки:** 60 проходов × 20 позиций × 10 уровней = **12 000 ячеек** на склад.  
Формат: `ДЦП-031-07-3`

## Адреса магазинов (77)

- **29 магазинов** для ДЦ-Пермь: Пермь (15 р-нов), Лысьва, Чусовой, Березники, Соликамск, Кунгур
- **24 магазина** для ДЦ-Екатеринбург: Екатеринбург (15), Н.Тагил, Серов, Каменск-Уральский, Первоуральск
- **24 магазина** для ДЦ-Тюмень: Тюмень (15), Тобольск, Ишим, Ялуторовск, Заводоуковск

Все адреса содержат координаты (SHIROTA/DOLGOTA) для карты и маршрутизатора.

## СТ (сборочные задания)

- **~385 СТ** — 5 СТ × 77 адресов
- **~1 540 паллет** — 4 паллеты на СТ (среднее)
- **~14 000 строк** — 9 строк на паллету (среднее)
- `TRANSTASK_ID = NULL` — все готовы к диспетчеризации
- Дата: завтра (60%) или послезавтра (40%)

## Применение

```sql
-- Порядок важен: сначала 046, потом 047
@046_apply.sql
@047_apply.sql
```

## Откат

```sql
@047_rollback.sql   -- сначала удалить паллеты/адреса
@046_rollback.sql   -- потом склады/ячейки
```

## Идентификаторы для автоматического отката

| Объект | Маска |
|--------|-------|
| Склады | `ID IN (9201, 9202, 9203)` |
| Ячейки | `WARE_ID IN (9201..9203)` |
| Артикулы | `ACTICUL LIKE 'ДЦ-%'` |
| Адреса | `ADDR LIKE 'Добра Цен #%'` |
| ТС | `ID BETWEEN 9201 AND 9215` |
| Водители | `ID BETWEEN 9201 AND 9215` |
| Паллеты | `PALLET_UID LIKE 'ДЦПЛ%'` |
