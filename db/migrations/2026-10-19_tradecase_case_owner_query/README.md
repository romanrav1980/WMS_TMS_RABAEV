# Отбор кандидатов проверки собственника CASE

Подготовлено, НЕ ПРИМЕНЕНО. Три набора физических ключей выбираются по строке сборки, истории возврата и активному резерву. Только затем запрашивается собственник в атрибутах. Результат должен совпасть с прежним OR/EXISTS по общему набору receipt units; fallback собственника и проверка прав не изменяются. Нового индекса и кэша нет.
