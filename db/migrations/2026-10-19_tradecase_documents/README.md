# TRADECASE: приём оснований, версия 1

Migration ID: `2026-10-19-tradecase-documents`. APPLIED: приём, откат пустого инкремента и повторное применение проверены19.10; дальнейшие дополнения перечислены в wiki/database/tradecase_contract_20261019.md.

Добавляет три пустые таблицы документов и пакет RRL_TRADE_DOCUMENT_API. Не переносит остатки и не меняет чужие документы. Площадка включается явно через настройку; для записей требуются warehouse_settings_edit либо tradecase_import, для чтения — tradecase_view в области склада. Пакет проверяет живые права до повтора и удерживает ACCESS_REV от конкурентного отзыва до завершения транзакции.

Приём сериализуется по строке площадки, чтобы ссылки НСИ и суммарное назначение количества рейсам проверялись на согласованном состоянии. Ожидание блокировки ограничено пятью секундами. Сужать блокировку следует по измерениям. Индексы покрывают ключ документа, события и историю документа. Приём сообщения не начинает физическое исполнение.

Перед применением сохранить checkpoint файлов и INVALID. Применить apply.sql через OracleApply UTF-8, проверить verify.sql. Rollback отказывается удалять непустые площадки; сначала требуется экспорт и отдельное решение по рабочим данным. Для пустого инкремента проверяются откат и повторное применение.

Форматы описаны в app/modules/integrations/contracts_tradecase.py. Это внутренний контракт адаптера; соответствие реальному SAP/ITMS SOAP/IDoc подтверждается отдельно.
